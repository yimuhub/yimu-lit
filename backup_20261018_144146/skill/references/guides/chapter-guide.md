# 章节写作指南（v3.0 · 追读动力 + 去机械化）

## 写前检查（每章动笔前必做）
1. 读故事圣经、人物档案、全书大纲和本章大纲卡。
2. 读上章摘要与上章结尾；续写时特别确认最后场景的即时状态。
3. 核对本章涉及的时间线、人物知情范围、未兑现线索、系统/世界规则。
4. 明确本章主角目标、阻力、策略、代价，以及结束后的状态变化。
5. 选一个叙事重点（推进主线/改变关系/揭示线索/造成损失/完成阶段目标/艰难选择），避免一章承担过多任务。

## 撰写正文
1. 直接进入有意义的场景，不重复上章概要，不用长篇说明替代事件。
2. 以具体动作、选择、对话展现人物；只补读者理解此刻所需的信息。
3. 叙述视角稳定：非全知视角下，不得突然透露主角不可能知道的内心或秘密。
4. 让对手有合理回应；允许计划变形、误判与失败。
5. 依场景功能调节长短句、对话、动作、内心；不为固定比例注水。
6. 让本章至少产生一项重要变化；结尾的阅读动力从本章自然生长。
7. 不复制他作的角色/情节组合/标志性语句；参考风格只抽抽象特征（叙述距离、节奏、幽默密度）形成独立表达。

## 去机械化：重点排查的表达（密集/重复/无信息增量时必须重写）
- "她深吸一口气""心中一凛""心头一跳""嘴角勾起一抹弧度"；
- "眼神复杂""意味深长""空气凝固""全场鸦雀无声"；
- "她不知道的是""与此同时""而此时""仿佛预示着一场风暴"；
- "有意思""果然如此""游戏开始了""这才刚刚开始"；
- 反复用"不是…而是…""这哪里是…分明是…"；
- 连续感叹号/省略号/单句独段/三连排比/斜体内心吐槽；
- 每章都是"动作—愣住—眼神一变—沉默—意味深长一笑"同一节拍；每个新线索都"瞳孔骤缩"、每个反派逢秘密就"脸色惨白"。
统计工具只能定位重复，不能独自定好坏；先判断该处有无实际信息/声音/人物特征/节奏作用，再决定保留/压缩/替换。

## 现代语言与古代设定的边界（穿越/吐槽/轻喜剧）
- 现代比喻若是主角内心笑点，明确来自主角的现代认知；古代人物不应无缘无故听懂术语。
- 主角公开说出现代术语，要写听者的真实反应与后果（不能既造笑点又无社会影响）。
- KPI/数据库/系统等术语可作特色但要少而准；古代礼法/权力/交通/信息/医疗/物价须与世界观相容并稳定执行。

## 保留人类创作的不整齐
允许人物误解、判断失误、表达笨拙、做出小气或不体面的选择；允许叙事有疏有密。所谓自然不是随机，而是符合人物与情境的独特节奏。**不靠刻意加错别字/写差句子伪装"人味"。**
