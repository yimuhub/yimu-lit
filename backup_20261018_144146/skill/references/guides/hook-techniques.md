# 悬念设置技巧（v3.0）

## 开篇要先建立"具体问题"，不只是一味用力描写
前几页让读者看见：① 一个能想象出的具体场景；② 一个正在发生的问题或不正常之处；③ 主角与这个问题的直接关系；④ 失败的具体损失；⑤ 主角的第一个有意义选择。
危机不一定是刀光喊叫：被迫签字、一通没接通的电话、一句被听见的话、一件无法解释的遗物……关键是它改变主角处境、让读者形成一个想追答案的问题。开篇别用长篇背景/空泛天气/人物简历/系统说明消耗耐心；设定在角色需要它、它影响选择时再自然出现。

## 章节结尾：留一个"具体的未完成动作或问题"（轮换使用）
- 新证据推翻旧判断。
- 主角作出代价高昂、不可轻易撤回的决定。
- 一个角色说了半真半假的关键话。
- 危险已逼近，且前文交代过危险来源。
- 人物关系发生无法当作没发生的变化。
- 一个看似成功的计划暴露出新的成本。
- 本章问题得到解决，但解法造成一个自然后果。
- 安静而有情绪重量的场景，让读者担心/心疼/期待下次相见。

**禁止**每章都以"一个黑影出现""游戏开始了""更大的风暴即将来临""她不知道的是"收尾；禁止把结尾写成廉价死亡威胁。钩子要与本章内容相关，强度随故事阶段变化。

## 悬念的三层结构（不必同时出现）
- **即时问题**：本场景/本章主角能否完成眼下目标？尽快给阶段性结果。
- **中程问题**：某段关系/阴谋/案件/成长障碍如何发展？持续追加证据与代价。
- **全书问题**：主角真正追求什么、核心谜团是什么、她将成为怎样的人？结局必须明确答复。
不要在即时问题尚未解决时连投大量新谜团，令读者只感混乱。

## 线索纪律
- 没有铺垫时别让新词成万能答案；别让每个神秘人物都暗示"更大的阴谋"；
- 不要把"上一个我/钥匙/守护者/命运"一次全抛却不给理解场景与因果；
- 可留白，但作者自己必须有答案。每新增一条主要悬疑线，问：它强化主线吗？占多少篇幅？此前至少哪条线可阶段性兑现？没空间就合并/删减/降级。
