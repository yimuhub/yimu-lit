# 玄幻 / 仙侠（原创）

## 爽点循环
"金手指/机缘 → 压制境界 → 突破/夺宝 → 更强的敌人/势力"。境界要有名（可数、可比、可越级），打脸靠"越级挑战"。

## 世界观边界（必守）
- 力量体系有天花板与代价（突破要付什么，别白给）。
- 地名/势力/功法命名风格统一；时代考据（年份/年号/历法）在 `timeline` 记。
- 规则"能/不能"写进 故事圣经 硬规则，突破只在"付出代价/特殊机缘"时发生。

## 黄金三章专属
- 第 1 章：主角被判定"废/无灵根/被夺基"，但露出异常（金手指信号）。
- 第 2 章：第一次"越级"小赢，立"他不一样"。
- 第 3 章：夺一个可见资源/身份，引更大世界（宗门/秘境）。

## 常见坑
- 境界膨胀（越写越大失去张力）；天降资源无代价；反派同质（一帮"你必死"的工具人）。
