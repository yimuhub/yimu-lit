## 升级改造方案（v4.8 → v4.12，五个版本递进，全程 v4 内）

GitHub 调研结论：儿童文学借 [MM-StoryAgent](https://zhuanlan.zhihu.com/p/30088075042)（多阶段故事→插图提示词→分级）；新闻稿借 [AI-News-Generator](https://github.com/martinkhristi/AI-News-Generator)（CrewAI 式采编审）与新闻聚合类项目的信源→5 道质量审核思路；文案借 [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo)（口播稿钩子→脚本→字幕结构）与营销自动化 notebook 集（AIDA/PAS 框架）。

探索确认的硬根因（全部 file:line 实锤）：
1. **章节内容重复的根因是 LLM 缓存键截断**：`bot/llm.py:218` 把 prompt 截前 6000 字符再哈希，而章号在 prompt 末尾；并行写作时前 6000 字符（蓝图/文风/人物）几乎相同 → 第 2~6 章**命中同一条缓存，返回逐字相同的正文**。
2. **并行下"前情"必然为空**（第 N-1 章未写出），模型从同样起点写，加剧重复。
3. **杂音进书稿**：`writer.py:1510` 模型返回不经清洗直接落盘；`_clean_chapter_text` 只剥三个小节，漏掉客套开场白（"好的，以下是…"）、`<think>` 思考标签、重复章题行、代码围栏；且 chapter_meta/章摘要吃未清洗文本，杂音回流后续章 prompt。
4. **转短剧假状态实锤**：`app.py` `_novel_to_drama_impl` 场次从没写回 `plan_doc["scenes"]`（永远空数组）、status 永远 "writing" 不置 completed、03-场次清单从不写 → 工作台 0/0、"写作中"永远不变、分镜因无场次数据静默失败。
5. **弹框无法直达**：「查看剧本」按钮解禁依赖轮询成功，异常被吞；toast 组件本就支持 action 按钮但从未使用。

### v4.8.0 —— 长篇质量修复（重复章节 + 杂音，最高优先）

1. **缓存键修复**：`_cache_key` 去掉 `[:6000]` 截断，对完整消息 blob 取 sha1（全链路受益，含剧本/论文）。
2. **并行依赖半序**：并行 worker 领章要求第 N-1 章已 completed 才开写（否则放回队列重取），消除"前情为空"。
3. **防撞车注入**：写作 prompt 注入「最近 3 章开头各 50 字 + 禁止以下列任何文字开头或复述」。
4. **重复检测门禁**：写完一章后与最近 3 章正文做字符 3-gram Jaccard 相似度（零依赖），>0.5 自动带"禁抄清单"重写一次，仍重复则日志告警。
5. **杂音净化 `_strip_chatter`**：剥 `<think>`/思考标签、客套开场白（复用 assist 已有 `_ACK_RE`）、正文中间重复章题行、成对代码围栏；调用点=写盘前、chapter_meta、章摘要、`_clean_chapter_text` 兜底（成书/导出自动受益）。
6. 回归用例：缓存键区分不同章、chatter 剥离各形态、Jaccard 门禁触发。

### v4.8.1 —— 转短剧真实化 + 直达工作台 + 分镜强化

1. **一行根因修复**：`plan_doc["scenes"] = scenes` 回填 + 成功置 `completed` + 写出 03-场次清单.md；`_script_scenes_or_reparse` 加第三层兜底（扫 04-正文 重建场次）。
2. **直达工作台**：toast 带「查看剧本」action 按钮 → navigate 新剧本；弹框内轮询到 completed/failed 才解禁，关框即停轮询；完成后自动跳转剧本工作台。
3. **真实工作状态**：改编完成后工作台场次列表/字数/进度全部真实；分镜自动生成失败不再静默（日志+重试按钮）。
4. **分镜强化（借鉴 reveric 分镜方案）**：剧本工作台顶栏「生成全本分镜」对**所有剧本形式**开放（含普通剧本/剧集，不止短剧）；每场补四字段（短标题/目标时长/情绪/事件）随场次清单生成；分镜表新增单镜「绘画提示词」列（漫剧可直接转绘图提示词）；支持导出 Markdown/CSV 提示词表。

### v4.9.0 —— 右栏按体裁定制 + 技能匹配 + 论文文献专业化

1. **技能按体裁匹配**：skills 页签数据源已按文体过滤（/api/skills/applicable），本版补「本书默认技能」——每个文体预设默认技能包（剧本=场景设计/对白/分镜规范；诗词=格律/意象/炼字；散文=去味/结构；论文=引用规范/降味清单；儿童=分级语言/亲子互动），右栏展示并支持手动增删（复用 /api/book-skills，存计划 meta）。
2. **协作按体裁**：岗位面板按 `medium.agents()` 显示该文体专属岗位（剧本=编剧/场记/审剧人；论文=学术审校…），注册表补充各文体岗位。
3. **规划/状态差异补齐**：论文规划树显示 章→小节 两级；诗词规划显示 I-P-C-K-R 轮次与格律判定；剧本规划显示场次完成态（v4.6.2 已做，本版补各自专有字段）。
4. **论文文献专业化**：T1 引用池生成时用 WebSearch 检索真实文献（标题+作者+来源+URL），refs 带链接；**参考页签展示文献条目**（可点链接跳知网/Scholar/原文）；refs-check 报告标注待核验条目；定稿附查重自检段（重复引注/未引用文献/格式错误统计）。

### v4.10.0 —— 儿童文学（medium=children）

对标 MM-StoryAgent 多阶段流程：C1 选题与分级（3-6/7-9/10-12 岁，主题/价值观红线）→ C2 故事创作（章节=故事单元，语言分级：字词难度/句长/重复句式）→ C3 互动设计（每章亲子问题/知识点/安全提示）→ C4 插图提示词（每故事单元 2-4 张插画描述）→ C5 定稿。工作台页签：分级设定/故事/互动/插图提示词/定稿；向导选项「儿童文学」（类型：寓言/绘本故事/儿童科幻/科学故事）；专属技能（分级语言、安全红线、正面引导）；头像「童」；断点恢复/右栏/对话全链接入。

### v4.11.0 —— 新闻稿（medium=news）

对标新闻聚合+采编审思路：N1 素材与信源（用户给素材/要点，或粘贴原始资料；5W1H 校验表）→ N2 结构撰写（**倒金字塔**：标题（多候选）/导语/主体/引语/背景/结语；类型：产品发布/官方公告/活动通稿/企业动态）→ N3 事实核查（时间/数字/人名一致性 + 引语归属检查）→ N4 多版本（通稿版/社媒短版/标题党候选）→ 定稿。工作台页签：素材/正文/事实核查/多版本/定稿；专属技能（倒金字塔、新闻语体、引语规范）；头像「新」。

### v4.12.0 —— 文案创作（medium=copy）

对标 MoneyPrinterTurbo 口播结构与营销框架：K1 需求与平台（口播/种草/宣传/营销；平台：抖音/小红书/公众号/B站，各自风格参数）→ K2 钩子库生成（前 3 秒钩子 10 候选：悬念/反差/痛点/数字/热点借势）→ K3 正文（口播稿带 [停顿]/[重音]/时长标注；AIDA/PAS 框架）→ K4 标题与标签候选 → K5 平台版本适配。**记忆**：复用已有风格蒸馏（distill）——把对标账号文案蒸馏成风格卡，创作时自动注入；用户反馈经 skill_evo 沉淀。工作台页签：需求/钩子/正文/标题标签/平台版本；头像「案」（或「文」）。
