一幕·YIMU 神笔 桌面版 · 首次启动说明
====================================

【Mac 首次启动】
1. 把「一幕神笔」拖入右侧「Applications」文件夹（DMG 卷名与应用名均为中文）
2. 在 Applications 里右键点击应用 → 选「打开」→ 再点「打开」
   （首次启动因未做公证会有一次安全提示，之后正常）
3. 如果提示「无法验证开发者」：系统设置 → 隐私与安全性 → 底部点「仍要打开」
4. 启动后会自动打开创作窗口（原生窗口，不是浏览器标签页）

【Windows 首次启动】
双击安装包安装即可；需要 Edge WebView2 运行时（Win10/11 一般已内置）。

【数据在哪里】
- Mac: ~/Library/Application Support/YiMuLit
- Windows: %APPDATA%\YiMuLit
作品、配置、评分都在这里；卸载重装不丢失。

【自动更新】
点击左下角版本号 → 确认升级 → 自动下载安装并重启，全程在客户端内完成。

【出问题了？】
数据目录 logs/launcher.log 有完整启动日志，发Issue时附上。
