# 题材 craft · 总则（全平台通配默认）

> 题材未指定时用它。默认**兼顾起点（付费：黄金三章+付费点）与番茄/七猫（免费：爽点密度+追读）**，参数取两者较严。

## 通用节奏参数
- 单章 2000-4000 字；每章末必钩。
- 爽点密度：每章 ≥2、每 1500 字约 1 个。
- 前 3 章：小高潮 ×3，第 3 章末埋付费点前奏。
- 卡点常放第 6-8 章（最想知道答案处）。

## 情绪主副
- 主情绪（爽/燃/虐/暖/恐 之一）+ 副情绪。全篇别换主情绪。

## 选题材套
- 推理 → `mystery.md`（公平游戏）
- 言情 → `romance.md`（节拍）
- 恐怖 → `horror.md`
- 都市爽文 → `urban.md`
- 玄幻仙侠 → `xuanhuan.md`

> 各套只给"题材专属"增量；通用底线见 `SKILL.md` 七条创作底线 + `anti-slop.md`。
