# 系统化升级方案 v5.1–v5.6 · 写作体验全面升级（学习易创 easy-writing）

> 制定日期：2026-11-21 · 基线：v5.0.0（长篇质量内核）
> 对标项目：[yilujian/easy-writing](https://github.com/yilujian/easy-writing)（Vue3 + Tauri 本地优先网文写作台，914★）
> 视角：资深前端 + 资深产品 + 重度写作者 + 小白用户
> 原则：**只学机制与交互设计，不抄一行代码**（对方 AGPL-3.0 传染、本库 BUSL-1.1，实现全部自研）；
> 核心功能只增不删；正文纯净域（铁律 0）在任何新出口继续生效；每版本独立发版可回退。

---

## 0. 调研方法与结论来源

1. 合并远程 main（v4.41.4 → v5.0.0，含九文体从零实测修复）。
2. 三路并行深读 easy-writing 源码（UI/交互、AI 功能、数据工程，共 388 文件 / 107 vue / 136 ts）。
3. 对照本库功能表与静态前端（static/v2，18.6k 行视图代码）逐项差距分析。

**一句话结论**：我们的强项在「生产管线」（九文体引擎、质量内核、交付闸门、反 AI 腔），
易创的强项在「写作者本人在场的每一分钟」（编辑器手感、个性化、数据透明、提示词开放）。
本次升级不碰创作管线，集中补「人在写作台里的体验」。

**不学的（明确取舍）**：
- 本地优先/Tauri/SQLite 架构——我们是服务端作品库（projects/）+ 多端一致口径，架构迁移成本远超收益；
- Vue3 + 构建链重写——本库「无构建原生 ES Module」是既定优势（调试先开新标签页、/v2/js 按 VERSION 重写 import），保持；
- 微信助手/桌宠——与核心写作无关，暂缓；
- 榜单爬虫全量 80 站——反爬合规风险大，v5.6 只做「URL 抓取+手动粘贴+AI 解读」轻量版。

## 3. v5.1.0 写作台编辑器内核（最高优先级）

### 3.1 范围
- **不引入任何 npm 构建依赖**：自研「段落型编辑器」——`contenteditable` 段落块（每段一个 `<p>` 容器，
  输入事件内聚合纯文本），复杂度远低于 ProseMirror，且与纯净域「纯文本正文」天然契合。
  正文数据格式仍是纯文本（\n\n 分段），不引入富文本 JSON——导出/纯净域口径零改动。
- 排版可调：字体（系统 5 种 + 霞鹜文楷 CDN 可选）、字号 12–28、行高 1.4–3.0、行宽 30–100%、
  段间空行开关、首行缩进开关、网格线（无/实线/虚线，`repeating-linear-gradient` 按 --ruler-step）。
  全部经 CSS 变量挂在 bench 纸面容器上，设置存 localStorage（`ew-bench-typography`）。
- 边写边存：输入 → 160ms 防抖 → `POST /api/saveChapter`（保持现接口）；**拼音组词（compositionstart/end）
  期间不落盘**；保存互斥（上一请求未返回则合并脏标记补跑一次）；底部状态栏保存图标
  （硬盘=已存/时钟=待存/叹号=失败）。
- 章节版本历史（服务端）：
  - `bot/chapter_versions.py`：快照节流（距上版 ≥5min 或字数变化 ≥200 才存；首版 ≥50 字），
    落盘 `projects/<key>/versions/ch<N>/<时间戳>-v<N>.txt`（每章上限 20 版，超出删最旧）；
  - `/api/versions?key=&n=` 列表 / `/api/versions/restore` 恢复（恢复前先把当前稿存为 `restore` 来源快照）；
  - bench 侧「历史版本」弹窗：左列表（版本名/字数/来源）+ 右侧 **内容 ⇄ 对比** 双视图；
    diff 用逐行 + 行内字符级双色标记（自研 ~80 行 diff，按最长公共子序列）。
- 划词气泡（编辑器内）：选中文字 → 浮出气泡（润色/扩写/纠错/去AI味/按人物口吻/自定义指令）。
  - 后端 `bot/selection_ai.py`：六动作各一个提示词函数（自研文案：润色「不替用户扩剧情」、
    纠错「只改错别字标点不动剧情」、去AI味带高频套话清单——沿用本库已有三层去味词表）、
    逐动作温度（纠错 0.1 / 润色 0.7 / 扩写 0.85 / 去味 0.75）；
  - 上下文：选区前后各 220 字窗口 + 章题 + 本章概要；
  - **流式预览不落稿**：结果面板逐字显示，完成后一键「替换选区」；
  - **替换前校验**：原选区文本未变才执行（变了提示放弃），替换后本地留痕（版本快照立即 +1）。
- 打字机滚动 + 段落聚焦：光标低于「编辑区高度 × 比例」基准线上滚；章末补空白使末行可停在基准线；
  段落聚焦 = 光标所在段正常，其余段 CSS 反选变淡（开关可关）。
- 手机阅读预览：右侧抽屉手机壳仿真（320–430px 滑杆），排版复用编辑器字体设置，
  滚动位置与编辑器双向同步（同步标志位防回环）。

### 3.2 纯净域合规（P0）
- 编辑器加载章节内容仍经 `core/purity.js` cleanChapterText 同口径；编辑器内**不新增**任何元信息小节；
- 复制走现有 copyTextOf / cleanChapterText 口径；划词替换只动「正文内容」，不动小节结构；
- node 比对测试 `tests/test_v51_editor_purity.mjs` 守住前后端口径。

### 3.3 验收标准
- pytest：`tests/test_v51_chapter_versions.py`（快照节流/上限/恢复前快照/selection_ai 六动作返回结构）；
- E2E：`tests/v51_bench_editor_test.mjs`——进 bench、输入中文触发组词保护模拟、160ms 落盘断言、
  版本列表出现、恢复后正文一致、划词气泡出动作卡、替换后字数变化且纯净域校验通过；
- 手动验收：字体/行高/网格线切换生效、打字机模式末行停基准线、手机预览滚动同步。

## 4. v5.2.0 AI 辅助写作

### 4.1 幽灵字（Tab 采纳）
- 触发（借鉴其节制三件套，参数自定）：光标在**正文末尾**且停顿 1200–1800ms 随机防抖、
  距上次请求 ≥8s、本轮新输入 ≥12 字、限流冷却 60s；
- 渲染：textarea 时代已过——直接在段落编辑器光标后插 `.ghost-text` 灰字 span + 「Tab 采纳」键帽；
- 模式自判：句尾标点收住 → 续一拍（温度 0.8）；逗号句中 → 补半句 ≤25 字（温度 0.3）；
- Tab 采纳=插入文本并记账（场景 `ghost`）；Esc/方向键/任何打字清除建议；
- 请求带：人物卡（按正文命中挑取，复用 canon/角色卡）、场景锚点（末 2 句）、前文（末 3 段）。
- 后端 `/api/ghost`：复用 mini_writer_base 轻量调用，**默认关思考**防思考吃输出。

### 4.2 快捷流式续写（Cmd/Ctrl+/）
- 光标处流式逐字插入；位置追踪用「全文偏移差」；流入期间用户改动即停在当前进度；
- 期间禁划词气泡，切章/批量任务运行中自动掐断。

### 4.3 AI 调用账本面板
- 后端：`llm_calls.jsonl` 落账行增加 `scene` 中文场景标签（写作/评审/续写/幽灵字/划词/蒸馏…）
  与 `duration_ms`、`estimate`（无 usage 时按中文 ≈1.7 字/token 估算）；新增 `/api/ai-ledger`
  （聚合：总次数/成功/失败/token 总量 + 按场景/日期筛选 + 明细分页，读文件流式解析）；
- 前端：settings 新页签「AI 调用账本」：4 统计卡 + 筛选（场景/状态/日期/关键词）+ 明细列表
  （输入输出 80 字预览、可展开）。

### 4.4 敏感词检测
- 本地词库 `data/sensitive-words.txt`（可编辑，默认内置基础词表）；bench 状态栏计数徽标 + 点击定位；
- 纯前端分词匹配，不调 LLM。

### 4.5 验收标准
- pytest：ghost 参数门（末尾判定/限流）、账本聚合口径、估算一致性；
- E2E：幽灵字出现→Tab 采纳字数增加→账本面板计数+1；敏感词徽标计数准确；
- 手动：Esc 取消、打字即清建议、限流冷却提示。

## 5. v5.3.0 主题与个性化

### 5.1 四套主题（CSS 变量扩展）
- 在 `tokens.css` 语义变量基础上扩到 ~90 个：`--ink-*` 文字五档、`--surface-1/2`、
  状态色四件套（本色/浅底/深字/描边）、按钮/输入框/面板/导航/树/滚动条独立变量；
- 主题：`宣纸白`（现 light 增补）、`古韵信笺`（米黄+赭红点缀）、`森系护眼`（豆绿）、`暗夜水墨`（现 dark 增补）；
  `data-theme` 根属性切换（现成机制）；
- 每主题对编辑器专属微调（暗夜下幽灵字降不透明度等）。

### 5.2 背景皮肤
- 内置 6–8 张（山水/宣纸/暗纹，GitHub 仓库 static/v2/img/skins/，每张 ≤300KB webp）；
- 主题与皮肤解耦：皮肤另存（localStorage dataURL 或内置 key），滤镜/透明度随主题类
  （古韵 sepia(0.6)/opacity .15、暗夜 grayscale+brightness .2）；
- 自定义上传 ≤10MB 读 dataURL 落 localStorage；写作台顶栏「背景」下拉就地换。

### 5.3 启动防闪白
- index.html `<head>` 内联 6 行脚本：读 `ew-boot-theme` 在 JS 加载前画底色（现成 data-theme 机制加早执行）。

### 5.4 打字音效 + 光标特效
- WebAudio 合成三款（青轴/茶轴/打字机：噪声脉冲 + 低频闷响，±8% 随机微调防机关枪感）；
  用户手势解锁 AudioContext；听书/静音开关记忆；
- 光标特效四款：挥毫溅墨 / 墨纹涟漪 / 文字鼓励（随机文案「迟早成神」等 emoji 浮起）/ 烈焰；
  Web Animations API 实现，粒子容器 fixed，可全局关闭；
- 自爆挑战（可选彩蛋）：停止输入超时限 → 倒计时 → 粒子「爆炸」+ 随机警示语，任意键入恢复。

### 5.5 验收标准
- E2E：主题切换后 html data-theme 变化 + 关键色变量断言；皮肤持久化重载后仍在；
- 手动：音效随击键、特效渲染帧率（rAF 无卡顿）、防闪白（禁缓存冷启动无白闪）。

## 6. v5.4.0 码字统计与首页

### 6.1 手写/AI 分账（服务端记账，贴合多端架构）
- `bot/writestats.py`：`projects/<key>/` 之外建全局 `data/writestats.json`
  （`days['YYYY-MM-DD'][bookKey] = {manual, ai}` + `chapterBase` 章节基线表）；
- **手写走会话口径**：bench 编辑会话实时净增幂等写入 session 槽位，退出工作台/切章时并入 manual
  （崩溃兜底：下次打开结算遗留 session）；删字不回扣已入账；
- **AI 走基线差**：AI 插字（幽灵字/划词/续写）同步抬高章节基线，落盘求差只剩手写部分，不双记；
- 连续天数：今天没写则从昨天回数；目标：手写/AI 双目标 + 月目标（日目标 × 当月天数）。

### 6.2 统计页（views/stats.js）
- 今日概览双卡（手写/AI + 占比）；7/15/30 天趋势（**SVG 自绘双折线**，颜色读 CSS 变量随主题重绘，
  不引图表库）；码字日历（月格子双行显示双口径）；目标进度环（conic-gradient）+「设置计划」弹窗；
- 新路由 `#/stats`，侧栏「码字统计」入口。

### 6.3 首页改造（welcome.js）
- 时段问候 + 随机诗句（内置 20 句自研文案库）；最近 2 本作品横卡（封面/字数/上次编辑，点进 bench）；
- 码字进度卡（双进度条 + 连续天数胶囊 + 巨型「码字」书法字水印 hover 放大）；
- **灵感速记卡**：常驻单条输入，失焦即存（`data/inspirations.json`），`#标签` 语法提取，300 字上限；
- 工具卡：一键开书/拆书/灵感库/账号设置四入口；容器查询单列重排（≤875px order 重排）。

### 6.4 验收标准
- pytest：分账口径（会话并入/基线差/不双记/崩溃兜底）、连续天数边界（今天未写）；
- E2E：bench 输入 → 统计页今日手写增长；AI 采纳后 AI 口径增长而手写不重复计；
- 手动：日历月切换、目标环动画、首页速记失焦保存。

## 7. v5.5.0 书架与提示词开放

### 7.1 书架升级（library.js）
- 封面：上传（≤5MB）+ AI 生成（走 providers.json 图像模型若配置，否则提示）；
  无封面占位 = 当前主题背景图 + 标题长度分档竖排书名；3D 书脊卡片样式；
- 分组：自定义分组（`data/book-groups.json`），分组 tab 条带计数；移动分组菜单；
- 回收站：软删（projects/<key> 改名 .trash-<ts> 保留 30 天）+ 恢复 + 彻底删除
  （二次确认列出将删数据范围：正文/版本/账本/参考）；
- 网格/列表视图切换 + 排序 6 种（最近更新/创建/字数最多最少/书名）+ 前端本地搜索。

### 7.2 提示词全开放（自研实现，借鉴组织方式）
- 目录 `prompts/`（仓库内置默认 + 用户目录 `data/prompts/` 覆盖层）：
  场景组=md 文件（如 `写作-章节生产.md`），槽=`## 槽名` 段落，段首 `温度：x` 行，变量 `{{}}`；
  **JSON 输出形状也放进槽让用户可改**（改坏解析失败 → 删用户文件回退默认）；
- 首批开放 10 组：章节生产/总规划/章纲/评审/修复/划词六动作/幽灵字/取名/简介/灵感；
  其余仍在 bot/ 内逐步迁移（迁移完一个组即开放一个组，兼容层：运行时优先读 md，缺槽回退代码默认）；
- 指纹机制：文件头 frontmatter 记 `base` 指纹（该槽默认值哈希）；程序默认值换代时，
  用户改过的槽标记「默认值已更新」并在编辑页提供「采用新版」；
- 可视化编辑页 `views/promptedit.js`：分组手风琴 + 变量 chip + 温度滑杆（0–2 步长 0.05）+
  弹窗多行编辑 + 对比分屏；「恢复默认」= 删用户覆盖文件；
- **风险控制**：提示词改动不自动生效到进行中的批量任务（任务启动时快照生效版本）；所有组接入现有
  纯净域/闸门不变。

### 7.3 验收标准
- pytest：md 解析（槽/温度/变量）、指纹升级、覆盖层回退、纯净域对自定义提示词仍生效
  （用户改坏提示词也产不出框外正文——闸门在出口兜底）；
- E2E：编辑某槽温度 → 生成任务走新温度；恢复默认；分组/回收站全流程；
- 手动：JSON 形状改坏 → 报错可读 → 删文件恢复。

## 8. v5.6.0 拆书·榜单·听书·素材库

### 8.1 拆书工作台（views/breakdown.js + bot/breakdown.py）
- 输入：上传 txt/md/docx/epub（复用 ingest.py 白名单与安全校验）或粘贴 URL 抓取；
  自动切章（**防误切规则自研**：序号单调性 + 带句号叹号的行不算标题 + 序号回指排雷）；
- 逐章拆解（每章一次结构化 JSON：梗概/节奏/冲突/钩子/手法标签，段落编号送入）；
  **前三章黄金三章深拆**（追加 golden 字段）；人物名滚动聚合；
- **段落级高亮映射**：outline 节点带 startPara/endPara → 工作台把分析卡锚定到原文段落（点击高亮）；
- 全书报告：聚合 briefs 再一次调用 → 编辑点评/大纲还原/人物弧光/伏笔账本/节奏曲线/可复用手法
  （手法标签可一键存入本库手法账本 lexicon_ledger，与现有体系闭环）。

### 8.2 轻量榜单风向
- 入口：粘贴榜单 URL / 手动粘贴榜单文本 → 结构化解析（名次/书名/作者/分类/数据）→
  `data/rank-snapshots/`（每源每日快照，120 天保留）→ 两次快照自动算升降幅 →
  「AI 解读」按钮（分类分布/标签风向/竞品提示，提示语注明只发送榜单数据不含创作内容）；
- 不做自动爬虫与隐藏窗口渲染（合规与反爬风险），定位是「手动采风 + AI 解读」。

### 8.3 听书（Web Speech API）
- bench/预览态「听本章」：SpeechSynthesis 逐句朗读 + 逐句高亮 + 语速循环切换；
  听书记忆位置（书+章+句）；听书播放时打字音自动静音（联动 v5.3）；
- 浏览器不支持时优雅降级提示。

### 8.4 素材库（灵感速记全页）
- `views/inspiration.js`：瀑布流卡片（置顶/展开/复制/删除/行内编辑）+ 热门标签侧栏；
  数据同 v5.4 灵感速记（`data/inspirations.json`），写作台/bench 面板可引用素材插入。

### 8.5 验收标准
- pytest：切章防误切（给「第五章正文里提第三章」等雷例）、拆解 JSON 容错、榜单快照升降幅；
- E2E：上传样例书 → 拆解 → 段落高亮点击 → 全书报告生成 → 手法入账本；
- 手动：听书逐句高亮、位置记忆恢复。

## 9. 全程通用工程标准（从易创工程实践提炼，自研落地）

1. **章节保存乐观锁 + 写后回读**：saveChapter 带 expectedMtime，落盘后回读比对字数校验，
   不一致报中文错误「保存后读不回，内容可能未真正写入」并提示重试；
2. **写入日志**：`data/write-journal.jsonl`（op/storageKey/chars/ok/reason/at），丢稿可查；
3. **错误全部中文可操作**：401/超时/JSON 解析失败翻译成人话 + 建议动作（沿用 v4.41.4 止损精神）；
4. **降级不静默分叉**：任一新能力（版本/统计/听书）失败不阻塞正文主链路，但必须留下可见状态；
5. **每版本独立可回退**：不改动既有 API 语义，新端点全部增量；发版走 tools/release.sh（tag+push），
   Release body 遵守禁 Agent/@ 词约定；
6. **每版本同步**：功能表.md 对应条目 + CHANGELOG + VERSION + 测试三重（pytest/E2E/node 口径比对）。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 自研段落编辑器在长章（>6000 字）性能 | 段落块按需虚拟化（视口外只留占位高度），性能基准进 E2E |
| contenteditable 中文输入/选区兼容坑 | 组词保护 + selectionchange 统一封装 core/editor.js，E2E 覆盖中文输入法模拟 |
| 提示词 md 化改坏生产管线 | 兼容层回退 + 出口闸门不变 + 首版只开放 10 组低风险组 |
| 主题变量扩散导致回归 | 主题门禁：E2E 断言关键语义变量存在；tokens.css 增量不改既有变量语义 |
| AGPL 合规 | 只学设计不抄码；本方案文档中的机制描述均为自研转述；实现评审时禁止直接对照源码复制 |
