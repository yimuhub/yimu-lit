核心能力
不只生成文本——为长篇的连贯性、创作的掌控感与产出的纯净度而设计。
01 / 百万字引擎

分层规划与滚动重规划

总规划 → 卷 → 弧 → 章卡四层结构，支持 100–1500 章规模；写作中途可重排结构而不失连贯。每章落笔前注入前情摘要、活跃伏笔、人物状态与设定词典。

02 / 节奏自控

批量写作 · 对话控笔

逐章逐场推进，或 5/10/20/50 章为一批；对话里说「再写 N 章」「写完全部」即可。多岗位并行分章齐写，总架构对齐、连续性入库、低分章自动还原。

03 / 连贯保障

一致性纲领与一键修复

人物/事件/世界观/风格四大硬规则贯穿全书；体检扫描设定冲突，单条或全部一键修复——需要改稿的问题自动启动定向重写，无需人工排查。

04 / 反 AI 腔

三层去味 + 相似度门禁

表达/用笔/故事逻辑三层扫描；与近章 3-gram 相似度门禁自动拦截复制粘贴；手法账本强制钩子与情绪换型，拒绝千章一面。

05 / 作者署名

笔名体系与纯净导出

多笔名管理、按文体指定默认、向导就地自定义；成书与 Word/EPUB/Markdown 导出自动署名，概要备注绝不混入正文。

06 / 越写越顺

技能进化 · 参考 RAG · 不限预算

反馈沉淀画像、候选技能评测转正；参考资料按章检索注入（事实/文风两类）；token 预算护栏支持不限制模式。

安装与部署
纯本地运行：数据不出本机，技能库全部内置，解压即跑。
quick-start
# 克隆并启动
git clone https://github.com/yimuhub/yimu-lit.git
cd yimu-lit
pip install -r requirements.txt

# 启动（默认 http://127.0.0.1:46821）
python run.py

# 或使用一键脚本
./start.sh        # macOS / Linux
start.bat         # Windows（双击）
  • 模型接入 —— 首次运行在「设置」填入 OpenAI 兼容接口：DeepSeek / Kimi / 本地 Ollama 均可。
  • 零配置体验 —— 打开 ?mock=1，内置模拟数据，不调模型即可体验全部交互。
  • Docker 部署 —— docker-compose up -d 一条命令起服务。
  • 更新检测 —— 应用内点击版本号，自动检测 GitHub 最新发布。
