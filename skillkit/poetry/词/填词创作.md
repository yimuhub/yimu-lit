# 填词 · 词林正韵 · 词牌

> 填词是**把话塞进一个固定形状的容器**。容器不变，你就得改话。

---

## 一、词与诗的根本差别

| | 近体诗 | 词 |
|---|---|---|
| 句数字数 | 固定（5/7 × 4/8） | **随词牌固定**，长短句参差 |
| 押韵 | 一韵到底（平水韵） | 一韵到底，但**可平仄换韵**（部分词牌） |
| 韵部 | 平水韵 | **词林正韵**（邻韵已合并，比诗宽） |
| 章法 | 起承转合，四句或八句 | **上片 / 下片**，各成一个单元 |
| 对仗 | 律诗必须对仗 | 一般不对仗（长调偶有） |

**填词最难的地方：字数被锁死。** 你的意思必须被压缩或拉长到指定的字数里。

---

## 二、词林正韵 vs 平水韵

| | 平水韵 | 词林正韵 |
|---|---|---|
| 部数 | 106 部 | 106 部（但**邻韵已合并**） |
| 适用 | 近体诗 | 词 |
| 严格度 | 严 | 宽（相邻韵部算同一韵） |

**关键差别**：
- 平水韵里「上平一东」与「上平二冬」是**两个不同韵部**，不能通押
- 词林正韵里这两部**已合并**，可以通押

**所以：用词林正韵填词时，某些在诗里算「出韵」的选择在词里是合规的。**

**本项目说明**：内置的 `data/pingshui.json` 是平水韵。
填词时若用户要求按词林正韵判定，工具会给「按平水韵判定」的说明，需要人工按词林正韵复核。

## 三、词牌的三级选择

### 按字数

| 级别 | 字数 | 特点 | 适合 |
|---|---|---|---|
| **小令** | ≤ 58 字 | 一口气写完，情绪单一 | 绝句式的小景、一瞬之感 |
| **中调** | 59-90 字 | 有两三个层次 | 感怀、宴饮、离别 |
| **长调** | > 90 字 | 层次丰富，可铺叙 | 怀古、说理、叙事 |

### 按情绪

| 词牌 | 韵 | 情绪基调 |
|---|---|---|
| 如梦令 | 仄韵（叠） | 一瞬之感、轻快小景 |
| 长相思 | 平韵 | 相思、行旅、绵绵不绝 |
| 忆江南 | 平韵 | 咏物、怀人、风物速写 |
| 浣溪沙 | 平韵 | 感怀、宴饮、清丽 |
| 菩萨蛮 | 平仄四换 | 曲折深情、闺阁、怀古 |
| 卜算子 | 仄韵 | 咏物言志、孤高自许 |
| 清平乐 | 上仄下平 | 闲适、田园、婉转之思 |
| 忆秦娥 | 仄韵（叠） | 苍凉、怀古、悲慨 |
| 鹧鸪天 | 仄韵 | 羁旅、豪情、感慨 |

### 按结构特点

- **叠句型**（如梦令、忆秦娥）：句式重复产生回环感
- **长短句型**（相见欢、忆江南）：适合口语化叙说
- **四换韵型**（菩萨蛮、减字木兰花）：情绪转折多，适合写纠结
- **长调**（水调歌头、沁园春）：上片叙事下片抒情，中间有过渡

## 四、上下片的分工

**词的上片与下片是**两个独立单元**，各有各的任务。

### 常见配置

| 配置 | 上片 | 下片 | 适合 |
|---|---|---|---|
| **上景下情** | 写景 | 抒情 | 借景抒情（最常见） |
| **上今下昔** | 现在 | 回忆 | 今昔对比 |
| **上实下虚** | 具体场景 | 抽象感慨 | 由景入情 |
| **上问下答** | 设问 | 回应 | 议论、诘问 |

### 上片的结尾要「悬」

**上片最后一句必须留下一个未完成的感觉**，让下片有接的理由。

| 上片末句 | 下片接什么 |
|---|---|
| 问句 | 回答或反问 |
| 写到一个动作中断 | 继续这个动作的结果 |
| 一个疑问或感慨 | 情绪的深化或翻转 |
| 一个画面定格 | 另一个画面呼应 |

**检验**：把上片末句和下片首句并排，如果两句之间没有逻辑缺口，说明上片没收好。

## 五、填词的四个难点

### 1. 字数锁死

**先写意思，再数字数。** 顺序反了会写出一堆废话去凑字数。

**技巧**：写完后用「减字法」和「加字法」调整：
- 减：删修饰语（"孤独的街道" → "街道"）
- 加：把单字扩成双字（"风声" → "窗外的风声"）
- 换：把两个字换成一个同义的词

### 2. 韵脚的语义限制

**同一个韵部里的字，意思往往相近。** 这会限制表达。

**技巧**：
- 选定韵部后，先列出这个韵部里 20 个常用字
- 从中挑出符合语境的
- **反过来用**：故意选一个意想不到的韵脚字，能产生新鲜感

### 3. 词林正韵的「宽」

**相邻韵部通押是允许的**，但要注意：
- 同一首词里最好还是用一个韵部
- 换韵（平换仄）只在词牌允许时用

### 4. 长调的铺陈

长调字数多，容易写成散文流水账。

**长调的结构模板**：
```
上片：起（点题）→ 承（铺开一个场景或一段身世）→ 转（一个转折或一句感叹）
      ‖
下片：另起一层（议论 / 深化 / 反问 / 收束）→ 落到一个具体的画面或情绪
```

**长调必须有「文气」**——上下片之间要有内在的逻辑，不是两段无关的内容。

## 六、写作流程

```
1. 定情绪与题材（决定词牌的级别与情绪匹配）
2. 选词牌（查「词牌格律表.md」：字数 / 句读 / 韵位 / 平仄）
3. 定韵部（按词林正韵；平仄换韵型注意换韵位置）
4. 定上下片分工（上景下情 / 上今下昔 / …）
5. 先写意思（不拘字数）
6. 压字数（逐句对上句读字数）
7. 调平仄（偶数位从严；查表）
8. 核韵（一韵到底；换韵在允许处）
9. 炼字（找那一句「宕出」的）
```

## 七、自检表

- [ ] 词牌与情绪匹配（不是硬套）
- [ ] 逐句字数与句读完全对上
- [ ] 韵位与词牌规定一致（该押的都押了）
- [ ] 一韵到底（换韵型在允许处换）
- [ ] 偶数位平仄分明
- [ ] 上片末句留了钩子
- [ ] 上下片有内在逻辑（不是两段拼贴）
- [ ] 没有凑字数的废话句
- [ ] 有一句是「宕出」的

---

## 八、常见错误

| 错误 | 症状 | 修法 |
|---|---|---|
| **字数凑不齐** | 某句多了两个字 | 用减字法先削修饰语 |
| **韵位错** | 该押的没押 | 查表逐句核对 |
| **上片下片脱节** | 下片像另写一首 | 先写下片的「接句」再写上片 |
| **长调流水账** | 没有层次 | 明确上片叙事、下片议论的分工 |
| **全是套话** | 「月」「柳」「楼」满篇 | 换具体意象 |
| **用典故代替表达** | 看不懂 | 典故要能化成画面 |
