# 现代诗 · 自由诗

> 现代诗的自由不是「随便写」，是**每一处形式选择都要有理由**。

---

## 一、现代诗与古典诗的根本差别

| | 古典诗 | 现代诗 |
|---|---|---|
| 约束来源 | 外部（格律） | 内部（语感） |
| 评价标准 | 合规 + 好 | **只有好** |
| 关键能力 | 遵守规则 | **制造节奏** |
| 最大风险 | 出格 | **松散** |

**自由诗的难点不在于挣脱，在于挣脱之后自己给自己立法。**

---

## 二、诗的核心单位：呼吸

**现代诗的最小单位不是「行」，是「呼吸」。**

一个呼吸 = 一个语意完整的、可以被一次吸气说完的单位。

| 好的呼吸 | 坏的呼吸 |
|---|---|
| 「我把手伸进水里 / 水是温的」 | 「我伸出了我的手 / 然后触碰到水 / 水的温度是温的」 |
| 意思完整，节奏自然 | 碎、拖沓、像散文拆行 |

**检验**：把诗念出来。凡是念着别扭的，一定是断错了地方。

---

## 三、诗行的三种功能

| 功能 | 作用 | 例 |
|---|---|---|
| **推进** | 往前走 | 事实、动作、事件的顺序 |
| **停顿** | 让读者消化 | 一个意象、一句独白 |
| **转折** | 改变方向 | 「但是」「直到」「可是」 |

**一首诗的行序 = 推进 + 停顿 + 转折的编排。**
如果整首诗都是推进，那就是散文。

---

## 四、三种常见诗体

### 1. 自由体（无固定行数）

最常见。行数由内容决定。

**注意**：不是「一句一行」——那是把散文拆行。

### 2. 格律体（诗行有规律）

**限制重复的行长或行数，形成音乐感。**
艾略特的「回旋曲式」结构就是这个意思。

### 3. 变体

在上述基础上局部重复或变奏。

**怎么选**：
- 情绪平静、内省 → 自由体
- 情绪激烈、需要节拍冲击 → 格律体
- 情绪有层次、要推进 → 变体

---

## 五、意象与呈现

### 呈现而非陈述

**现代诗的第一原则：呈现，不陈述。**

| 陈述（散文） | 呈现（诗） |
|---|---|
| 我很孤独 | 冰箱运转了一夜 / 我没关 |
| 她走了 | 她的杯子还在 / 我没洗 |
| 战争很残酷 | 弹片嵌在门框上 / 每天开门都看见 |

### 意象的三个来源

1. **具体物件**（比抽象名词有力十倍）
2. **身体感受**（温度、重量、痛）
3. **动作**（动词是诗的骨骼）

**反模式**：一首诗里如果全是抽象名词（孤独、悲伤、思念、爱），它什么都没说。

**改法**：每个抽象词换成一个具体的物件或动作。

## 六、声音

### 诗是声音的产物

**如果一首诗默读不通、念出来别扭，它就还没成。**

**处理办法**：写完念出声。卡住的地方就是节奏错的地方。

### 声音的三个层面

| 层面 | 决定什么 |
|---|---|
| **语速** | 句子的长短、逗号位置 |
| **重音** | 哪些词要突出 |
| **音色** | 开口呼响亮 / 闭口呼沉闷 |

**技巧**：写完之后，把关键意象所在的句子改短，让它们落下来更重。

---

## 七、常见问题

| 问题 | 症状 | 修法 |
|---|---|---|
| **散文化** | 读起来像分段散文 | 找节拍，断句，长短交错 |
| **意象贫乏** | 全是抽象词 | 换成具体物件 |
| **说教** | 诗人在讲道理 | 删掉所有判断句 |
| **节奏平** | 每行差不多长 | 制造长短落差 |
| **逻辑断裂** | 意象之间没关系 | 找一个隐藏的连接逻辑 |
| **故作高深** | 意象堆砌无情感 | 先问「这首诗让谁难受」 |
| **无结尾感** | 读完还在中途 | 最后一行要「落」下来 |

---

## 八、从零到一首诗

```
1. 找一个具体的场景（不是「一个关于孤独的故事」，是一个具体的时刻）
2. 写下那个场景里最有感受力的 3-5 个意象
3. 只用这些意象，把场景写出来（允许初稿粗糙）
4. 找节奏：断句，把长的断短，把该合的合
5. 找核心：哪一个意象是这首诗的题眼
6. 围绕题眼排序，删掉可有可无的
7. 结尾：让最后一行落下去
8. 念出声：卡住就改
```

**检验**：删掉全诗所有形容词和副词，如果意思还基本成立，说明骨架是好的。
如果删掉之后诗就没了，说明你写的是散文。

## 九、自检表

- [ ] 有一个具体场景，不是抽象主题
- [ ] 3-5 个核心意象，且都是具体物
- [ ] 有推进，也有停顿和转折
- [ ] 长短句有落差
- [ ] 念出来不卡
- [ ] 没有说教的句子
- [ ] 最后一行落得住
- [ ] 删掉形容词后骨架仍在
- [ ] 这首诗让**某个人**难受（不是所有人）
