# 意象与语言密度

> 诗的力量来自「少而准」，不是「多而美」。一个能被看见的意象，胜过三个抽象名词。

## 一、先建意象系统

动笔前列一张小表，只填与本诗场景有关的物件：

| 物件 | 归属 | 可承载的情绪 | 在诗中的位置 |
|---|---|---|---|
| 灯 | 室内/等待 | 未归、守候 | 首句 |
| 雨 | 室外/阻隔 | 延迟、寒意 | 承句 |
| 门 | 边界 | 拒绝/归来 | 转句 |
| 衣 | 身体 | 旧痕、时间 | 合句 |

**规则**：同一首诗里的意象要来自同一场景系统（夜、渡口、旧屋……），不要上半首写海、下半首写沙漠，除非中间有明确的转场。

## 二、语言密度的三条标准

1. **一句一个主要信息**：不要在一句里塞三个比喻。
2. **名词与动词优先**：形容词超过三个，通常有一个可以换成动作。
3. **留白**：读者能补的，不要写满；写满就没有参与感。

**密度检验**：把每句压缩成「谁/什么 + 做什么 + 在哪」，压不出信息的句子删掉。

## 三、抽象词的替换

| 抽象 | 换成可看见的 |
|---|---|
| 思念 | 把杯子摆成两只 / 反复看门口 |
| 孤独 | 一桌菜只摆一副碗筷 |
| 时间流逝 | 墙上的日历停在某页 / 水壶结垢 |
| 悲伤 | 手在抖，火柴划了三次才着 |

**不是禁止抽象**：一首诗可以有一句直说，但其余句子要把它撑住。

## 四、通感与陌生化

- 通感要建立在共同体验上：「冷」可以是颜色、声音、触感。
- 陌生化不是乱搭配：把 A 的感觉给 B，读者要能瞬间懂。
- 一句诗里最多一个陌生化表达，多了会油。

## 五、格律诗与自由诗的密度差异

| | 格律诗 | 自由诗 |
|---|---|---|
| 单位 | 句（五/七字） | 行（可长可短） |
| 密度 | 每句 1 意象 + 1 动作 | 每行 1 个信息单元 |
| 留白 | 靠省略主语/虚词 | 靠断行与空格 |
| 风险 | 堆典故、合掌 | 散文化、口水化 |

## 六、自检表

- [ ] 意象是否来自同一场景系统？
- [ ] 每句是否只有一个主要信息？
- [ ] 形容词是否超过三个？能否换成一个动作？
- [ ] 抽象词是否已替换成可看见的东西？
- [ ] 是否有一句直说情绪？其余句子是否撑住了它？
- [ ] 通感/陌生化是否超过一处？
- [ ] 删掉任意一句，诗是否仍然成立？如果不成立，那句可能是废话。

## 七、反例

- ❌ 「思念如潮水般涌来，孤独像黑夜一样漫长」——两个抽象比喻，没有画面。
- ❌ 上半首写江南、下半首写大漠，没有任何转场。
- ❌ 每句都塞一个典故，读者在查字典而不是读诗。
- ✅ 「她把两只杯子都烫了一遍 / 第二只放回柜子」——不写思念，思念在动作里。
