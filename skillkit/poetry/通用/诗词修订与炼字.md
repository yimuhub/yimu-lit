# 诗词修订与炼字

> 初稿是把话说出来，修订是把话说准。炼字不是找生僻字，是找那个「换掉就疼」的字。

## 一、三稿法

| 稿次 | 只做什么 | 不做什么 |
|---|---|---|
| **一稿** | 把意思写完整，先不管平仄 | 不查韵、不炼字 |
| **二稿** | 定格律：句数、字数、韵部、平仄 | 不追求惊艳 |
| **三稿** | 炼字、调序、删虚词 | 不改主题 |

**顺序不能反**：先炼字再定格律，往往要把好字扔掉。

## 二、炼字五问

对每个可疑的字问五遍：

1. **换一个动词，画面变了吗？**（「看」→「数」「量」「擦」）
2. **这个形容词能否用动作替代？**（「很旧」→「漆掉了三块」）
3. **虚词是否可删？**（「而」「则」「之」多半可省）
4. **这个字是否在本诗重复出现？**（重复要有意，不能是无意识）
5. **读出声，是否打结？**（打结就换）

## 三、动词优先

| 弱 | 强 | 为什么 |
|---|---|---|
| 风吹动窗帘 | 风把窗帘掀到桌上 | 有方向、有结果 |
| 他看着远方 | 他把烟按灭在栏杆上 | 有动作、有情绪 |
| 雨下得很大 | 雨把门槛淹了半寸 | 可测量 |

**原则**：能用一个具体动作说清的，不用形容词。

## 四、对仗调整（律诗）

- 先看词性：名词对名词、动词对动词、数量对数量。
- 再看结构：偏正对偏正、动宾对动宾。
- 最后看意义：不要「合掌」（上下句说同一件事）。
- 对不上时，优先改下句；下句是韵脚所在，改上句更安全。

## 五、韵脚处理

1. 先定韵部，再写句子；不要写完再凑韵。
2. 韵脚字要自然，避免「为了押韵把词序拧断」。
3. 同一韵部里选音色与情绪匹配的字（开口音响亮，闭口音沉）。
4. 首句可借邻韵，但全诗其余韵脚必须同部。

## 六、删的标准

- 删掉解释性的句子（读者能懂，不用再说）。
- 删掉重复意象（同一首诗里两次「月」通常一次就够）。
- 删掉万能形容词（美丽、动人、无限、深深）。
- 删掉凑字数的虚词与领字。

## 七、自检表

- [ ] 是否按「意—律—字」的顺序修订？
- [ ] 每个动词都问过「换一个会不会更好」？
- [ ] 形容词是否已尽量换成动作/物件？
- [ ] 是否有无意识的重复字？
- [ ] 对仗是否词性、结构、意义三层都对？
- [ ] 韵脚是否自然，没有硬凑？
- [ ] 朗读一遍，是否有打结处？

## 八、反例

- ❌ 为了用「绮」字，把整句语序改成文言倒装，读起来别扭。
- ❌ 上下句都写「月光很白」，合掌。
- ❌ 一首诗里出现三次「愁」，且每次都是直说。
- ✅ 「他看远方」→「他把车票折成四折，塞回口袋」——动作替代情绪。
