# 格律自检与常见错误

> 格律不是审美判断，是可核对的硬规则。先跑确定性检查，再谈意境；检查不通过的句子，不要用「意境好」辩护。

## 一、近体诗的基本骨架

以七绝为例，四种基本平仄格式（平 = 平声，仄 = 仄声，⊙ = 可平可仄）：

```
平起首句入韵：⊙平⊙仄仄平平，⊙仄平平仄仄平。
              ⊙仄⊙平平仄仄，⊙平⊙仄仄平平。
平起首句不入：⊙平⊙仄平平仄，⊙仄平平仄仄平。
              ⊙仄⊙平平仄仄，⊙平⊙仄仄平平。
仄起首句入韵：⊙仄平平仄仄平，⊙平⊙仄仄平平。
              ⊙平⊙仄平平仄，⊙仄平平仄仄平。
仄起首句不入：⊙仄⊙平平仄仄，⊙平⊙仄仄平平。
              ⊙平⊙仄平平仄，⊙仄平平仄仄平。
```

五绝/五律按同型减两字；律诗八句按「粘对」规则续排。

## 二、四条硬规则

1. **押韵**：近体诗押平声韵，一韵到底；首句可入韵可不入，其余偶数句必须押。
2. **对**：一联之内，上下句平仄相反（首句入韵时首联例外）。
3. **粘**：下一联上句与上一联下句的第二字平仄相同。
4. **对仗**：律诗颔联（3–4 句）、颈联（5–6 句）必须对仗；绝句不强制。

## 三、常见错误对照表

| 错误 | 表现 | 修法 |
|---|---|---|
| **出韵** | 韵脚不在同一韵部 | 换韵脚字，或整首换韵部 |
| **平仄失替** | 一句内平仄没有交替 | 调整字序或换字 |
| **失对** | 同一联上下句平仄相同 | 改下句 |
| **失粘** | 下联上句与上联下句第二字不同 | 改下联上句 |
| **孤平** | 平收句除韵脚外只有一个平声 | 把其中一个仄声换平 |
| **三平尾** | 句末连续三个平声 | 改末三字之一为仄 |
| **三仄尾** | 句末连续三个仄声 | 同上 |
| **合掌** | 对仗两句意思重复 | 换角度 |
| **四平头** | 相邻四句开头结构相同 | 换句式 |

## 四、拗救（简要）

- **本句自救**：特定位置该平而仄，可在同句另一位置补平。
- **对句相救**：上句该平而仄，下句对应位置用平补。
- 拗救不是万能：先判断是否属于可救格式，不要自创规则。

## 五、词与曲

- 词：先查词牌的字数、句读、平仄、韵位；一韵到底或按词牌规定换韵。
- 曲：先查曲牌与宫调；衬字不占正字；一宫一韵。
- 词曲的平仄比近体诗更细（分上、去），不确定时以项目校验器结果为准。

## 六、自检流程

1. 定体式（五绝/七绝/五律/七律/词牌/曲牌）。
2. 定韵部，标出所有韵脚。
3. 逐句标平仄（可查 `poetry/data/pingshui.json`）。
4. 检查失替、失对、失粘、孤平、三平尾。
5. 检查对仗（律诗颔联、颈联）。
6. 最后才看意境与炼字。

**顺序不能反**：先改意境再查格律，往往要推翻重写。

## 七、自检表

- [ ] 体式与句数、字数正确？
- [ ] 所有韵脚同部，且为平声（近体诗）？
- [ ] 每句平仄有交替？
- [ ] 每联上下句平仄相对？
- [ ] 联与联之间相粘？
- [ ] 律诗颔联、颈联对仗，且无合掌？
- [ ] 没有孤平、三平尾、三仄尾？
- [ ] 词/曲是否按谱填写？

## 八、说明

本文件只列规则与检查顺序，不代替校验器。项目内置的 `bot/poetry_checker.py` 与 `poetry/data/pingshui.json` 是判定平仄与韵部的权威来源；两者冲突时以校验器结果为准，并记录例外。
