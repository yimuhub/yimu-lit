# 诗词定稿与呈现

> 定稿不是「再改一句」，而是「确认它可以离开你」。呈现方式会影响读者读它的速度与语气。

## 一、定稿前最后四问

1. **主题是否一句话说清？** 说不清，说明意象散了。
2. **有没有一句是「为了显得有文化」加的？** 有就删。
3. **朗读是否顺？** 打结处换字或断句。
4. **标题是否准确？** 标题是诗的一部分，不要用「无题」逃避命名。

## 二、标题与小序

- 标题给出场景/对象/情绪方向，不剧透结论。
- 组诗用「其一/其二」，同一标题下保持体式统一。
- 小序只写必要背景（时间、地点、缘起），不超过三行。
- 不写「有感」「随笔」这类无信息标题，除非组诗需要。

## 三、注释与译文

| 情况 | 做法 |
|---|---|
| 用典 | 注出处与在本诗中的意思，不抄原文大段 |
| 生僻字 | 注音 + 简义 |
| 地名/人名 | 注今地/身份，必要时注与诗的关系 |
| 交付给普通读者 | 可附白话译文，译文只求准确，不求押韵 |
| 交付给专业读者 | 注释从简，保留异文与修改说明 |

**注释是服务，不是炫耀**：一条注释超过三行，通常说明诗里塞了不该塞的东西。

## 四、排版规范

```
《秋夜归人》
（七绝 · 平水韵下平十一尤）

第一句
第二句
第三句
第四句
```

- 近体诗一句一行，句末标点齐全。
- 词按上下阕空一行；曲按宫调/曲牌分段。
- 现代诗按语义断行，不按字数对齐。
- 组诗之间空两行，编号统一。

## 五、交付说明模板

```
体式：
韵部：
首句是否入韵：
修改要点：1–3 条（只写改了什么，不写「更好」）
存疑处：如有，标出并说明原因
```

## 六、自检表

- [ ] 主题能一句话说清？
- [ ] 标题准确、有信息？
- [ ] 小序是否 ≤3 行？
- [ ] 用典/生僻字是否已注？
- [ ] 译文是否准确、不强行押韵？
- [ ] 排版是否符合体式？
- [ ] 交付说明是否写了体式与韵部？
- [ ] 是否还有「为了显得有文化」的句子？

## 七、反例

- ❌ 标题《无题》，小序写了 200 字解释背景。
- ❌ 每句都加注释，读者在读论文。
- ❌ 现代诗为了整齐，把句子切成长短一样的方块。
- ✅ 标题《秋夜归人》，小序一行「甲辰秋，夜归旧宅」，注释只注一个地名。
