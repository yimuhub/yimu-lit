# 近体诗 · 五绝 / 七绝 / 五律 / 七律

> 近体诗不是「整齐的句子」，是**一组被格式约束的表达**。约束不是敌人，是让你被迫精确。

---

## 一、体式与规格

| 体式 | 句数 | 每句字数 | 押韵句 | 对仗 |
|---|---|---|---|---|
| **五绝** | 4 | 5 | 第 1、3 句（或 2、4） | 无 |
| **七绝** | 4 | 7 | 第 1、3 句（或 2、4） | 无 |
| **五律** | 8 | 5 | 第 1、3、5、7 句 | 颔联、颈联 |
| **七律** | 8 | 7 | 第 1、3、5、7 句 | 颔联、颈联 |

**判定口诀**：
- 绝句：四句，一韵到底，两句一联
- 律诗：八句，一韵到底，颔联（3、4 句）与颈联（6、7 句）要对

**首句是否入韵**：绝句首句可入韵可不入；律诗首句**通常不入韵**。
无论入不入韵，**一韵到底**是铁律。

## 二、韵

### 韵部：平水韵 106 部

**写诗用平水韵**（词用词林正韵）。本项目内置 `data/pingshui.json`：
- 8232 个汉字 → 105 个韵部
- 每字带平/仄标注
- 涵盖上平 14 部、下平 15 部、上声 29 部、去声 30 部、入声 17 部

**平水韵只分平仄两类，不分四声。**「上平」「下平」都是「平」，「上声」「去声」「入声」都是「仄」。

### 押韵的三条规矩

1. **一韵到底**：全诗（律诗八句 / 绝句四句）用同一韵部
2. **只押平声**：近体诗押韵用平声韵
3. **不许邻韵通押**：唯独首句可以借邻韵（且首句本可不入韵）

### 常见韵部速记（举例）

| 韵部 | 韵脚举例 | 适合题材 |
|---|---|---|
| 上平一东 | 东、同、虫、风 | 宏阔、开阔 |
| 上平十一真 | 春、人、亲、臣 | 温厚、怀人 |
| 上平四支 | 支、时、诗、离 | 清丽、言志 |
| 上平十三元 | 元、原、园、言 | 悠远、苍茫 |
| 上平七虞 | 虞、珠、书、居 | 雅致、闲适 |
| 下平一先 | 先、烟、传、篇 | 俊逸、清新 |
| 下平七阳 | 阳、扬、香、光 | 昂扬、开阔 |
| 下平十一尤 | 尤、楼、流、舟 | 沉郁、悠长 |
| 下平九青 | 青、清、情、亭 | 清丽、闲适 |
| 上声四纸 | 纸、史、耻、此 | 沉郁、低回 |
| 去声四寘 | 寘、至、志、意 | 决绝、铿锵 |
| 入声四质 | 质、掷、室、疾 | 急切、峻烈 |

### 选韵的策略

**先定情绪，再选韵部。** 韵部本身带音色：
- 开口呼的韵（东、真、阳、尤）响亮 → 豪放、悲怆
- 齐齿呼的韵（支、微、齐）内敛 → 清冷、含蓄
- 闭口呼的韵（鱼、虞）沉闷 → 沉郁、压抑

**避免用容易写滥的韵**（如「尤」「先」「阳」韵的字太多，容易落俗）。

## 三、平仄

### 粘对规则（近体诗的本来规则）

1. **偶数位分明**：每句第 2、4、6…位必须平仄分明，不可错位
2. **对**：同一联内，上句第 2 位与下句第 2 位**相反**
3. **粘**：跨联，上联下句第 3 位与下联上句第 4 位**相同**
4. **奇数位不论**：第 1、3、5 位一般不拘（但有孤平等禁忌另算）

### 常用句型（以五言为例）

```
仄仄平平仄   平平仄仄平
平平平仄仄   仄仄仄平平
平平仄仄平   仄仄平平仄
```

### 一三五不论，二四六分明

这是初学者最有用的一句话：**出问题的地方优先看第 2、4、6 位**。

### 三类「救」的常见情形

| 现象 | 判法 | 处理 |
|---|---|---|
| **孤平** | 仄仄平仄仄（该平处只有一个平） | 换字或换句型 |
| **三平调** | 连续三字同调在关键位 | 换第三字 |
| **三仄脚** | 句末三字全仄 | 换末字 |

**注意**：本项目的校验器对平仄只给「建议」不判「违规」——
因为近体诗有大量变体、拗句与孤平救法，硬判会误伤好诗。
**平仄以人工判断为准，工具只负责把可疑位置标出来。**

### 入声字

**入声字今读平声但作仄声用。** 常见入声字：
白、黑、竹、菊、一、八、十、急、识、别、国、独、落、石、学、绝、节、说、月、玉、屋、熟、服、蜀、菊、绝、律、别…

**这些字在诗中一律算仄声。** 本项目的平水韵数据已按古音标注，直接用。

## 四、对仗

### 律诗的两副对仗

**颔联**（第 3、4 句）与**颈联**（第 6、7 句）必须对仗。

### 对仗的四种类型

| 类型 | 特征 | 例子框架 |
|---|---|---|
| **正对** | 两句意思相近或相承 | 海上生明月 / 天涯共此时 |
| **反对** | 两句意思相反 | 野火烧不尽 / 春风吹又生 |
| **流水对** | 两句连成一句 | 野火烧不尽 / 春风吹又生 |
| **扇面对** | 两句各有两个分句，对得工整 | 拟寒松 / 示秋兰 |

### 对仗的四条基本规则

1. **词性相对**：名对名、动对动、形对形、虚对虚
2. **结构相应**：分句数一致，句式镜像
3. **平仄相反**：对应位置平仄尽量相反
4. **内容相关**：不是同义反复，是同一话题的两个角度

### 对仗的常见错误

| 错误 | 例子 | 问题 |
|---|---|---|
| 合掌 | 「白云千载空悠悠」对「黄鹤一去不复返」 | 意思重复 |
| 词性错位 | 名对动 | 最常见 |
| 结构不一 | 三字句对四字句 | 硬凑 |
| 意境重复 | 两句都在说同一件事 | 浪费了对仗位 |

**合掌是最要命的。** 对仗的两句要互补，不是复述。

## 五、章法

### 四句绝句的常见结构

| 结构 | 布局 | 作用 |
|---|---|---|
| **起承转合** | 1 起 / 2 承 / 3 转 / 4 合 | 最通用 |
| **起承转合（变）** | 1 起 / 2 承 / 3 转 / 4 宕 | 结尾翻出余味 |
| **前二后二** | 1-2 景 / 3-4 情 | 借景抒情 |

**五绝的「小起小承小转小合」**：20 字里完成一个完整的小转折，不铺陈。

### 律诗八句的布局

```
首联（1-2）  起：点题、造境
颔联（3-4）  承：展开，**必须对仗**
颈联（6-7）  转：推进，**必须对仗**
尾联（8）    合：收束
```

**律诗的容量**：五律 40 字 ≈ 一个完整的场景 + 一次情绪推进。
不要在律诗里塞太多情节。

### 七律比五律多在哪

- 每句多两个字 → **转折处可以更从容**
- 首联常「一字入扣」：第一个字定全诗调子
- 中二联对仗可以更宽

**七律适合写「有层次的思绪」**；五律适合写「一个瞬间的完整」。

## 六、意象与炼字

### 意象是硬通货

**写诗是选意象，不是选词。** 一句诗的成败在于它放进了什么画面。

| 弱 | 强 |
|---|---|
| 我很孤独 | 举杯邀明月，对影成三人（孤独但不写孤独） |
| 我很伤心 | 执手相看泪眼，竟无语凝噎 |
| 时间过去了 | 桃花潭水深千尺，不及汪伦送我情 |

### 炼字的四个方向

1. **换动词**：「走」→「蹑」「踏」「没」
2. **换形容词**：「很静」→「阒然」「死寂」
3. **换虚词**：删掉所有「的」「了」「很」
4. **换意象**：把抽象换成具体

### 忌

- **忌空**：没有画面的句子（概念、说理、直抒）
- **忌典故堆砌**：用典要能化成画面，不能只是标签
- **忌俗套**：月、柳、镜、楼 用得太多就没有了

**检验：一首诗里如果有一句不含任何具体名词，它多半是废句。**

## 七、写作流程

```
1. 定题与情感核心（一句话）
2. 选体式（五绝/七绝/五律/七律）
3. 选韵部（按情绪定，先查韵表）
4. 画意象（3-5 个核心意象，排出画面）
5. 布章法（起承转合 / 首联颔联颈联尾联）
6. 落字（先求意思通顺，再调平仄，最后炼字）
7. 校验（字数、押韵、平仄提示）
8. 改（最多 3 轮）
```

**关键顺序：意思 → 平仄 → 炼字。** 反过来做会写出好看但不通的句子。
