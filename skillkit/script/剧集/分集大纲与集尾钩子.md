# 分集大纲与集尾钩子

> 分集大纲不是剧情简介，是「这一集的生产说明书」：每一集要解决什么、留下什么、下一集为什么必须看。

## 一、分集卡字段（每集一张）

```
集号 / 标题：
本集问题：这一集要解决的具体问题（一句话）
A 故事：主线推进（谁要什么、结果如何）
B 故事：对照/关系线（与 A 如何互相解释）
C 故事（可选）：世界/群像线
本集转折：中点发生什么，让方向改变
集尾钩子：新事实 / 新威胁 / 新决定（三选一）
季弧位置：本集让季弧前进/后退了什么
场次清单：场号、地点、时间、功能（≤12 场/集）
```

**一集只解决一个问题。** 如果本集问题需要两句话，说明应该拆成两集。

## 二、集尾钩子的五种类型

| 类型 | 做法 | 强度 | 注意 |
|---|---|---|---|
| **新事实** | 观众得知一个改变理解的信息 | 高 | 必须在前文有伏笔 |
| **新威胁** | 一个更大的危险逼近 | 高 | 不要每集都用，会疲劳 |
| **新决定** | 主角做出不可逆选择 | 中高 | 必须让观众理解代价 |
| **倒计时** | 明确期限被压缩 | 中 | 期限要具体 |
| **关系断裂** | 信任崩塌/结盟破裂 | 中 | 要落在具体台词或动作上 |

**强度轮换**：连续两集不要用同一类型；高强度钩子（新威胁）每 3–4 集一次。

## 三、钩子的写法（可拍摄）

- 用画面结束，不用解释性旁白。
- 最后一镜要能让观众问出一个具体问题：「他为什么知道？」「她会不会去？」
- 钩子必须与本集人物选择有关，不能靠天降意外。
- 不要在钩子后加「下集预告」式字幕来代替真正的悬念。

## 四、季弧对照

每 3 集检查一次：

1. 季弧目标前进了吗？没有 → 本集是水集。
2. 主角的代价增加了吗？没有 → 冲突太安全。
3. 对手有行动吗？没有 → 对手工具化。
4. B 故事与 A 故事有对照吗？没有 → 两条线各写各的。

**水集判定**：删掉本集，季弧是否不受影响？如果是，本集要么合并，要么重写。

## 五、场次清单纪律

- 每集 8–12 场；超过 12 场通常是场景没合并。
- 每场只写「地点 / 时间 / 功能 / 结果」，不写对白。
- 同一地点连续场景尽量合并，降低拍摄成本。
- 夜外、雨戏、群演、儿童、动物、特效要在清单里标出来——它们是预算信号。

## 六、自检表

- [ ] 每集的本集问题能一句话说清？
- [ ] 每集只解决一个问题？
- [ ] A/B 故事是否互相解释，而不是各写各的？
- [ ] 集尾钩子类型是否轮换？
- [ ] 钩子是否来自人物选择，而不是天降意外？
- [ ] 删掉这一集，季弧是否不受影响？
- [ ] 场次是否 ≤12，且标出了高成本场景？

## 七、反例

- ❌ 每集结尾都是「主角回头，看见一个黑影」。
- ❌ 分集大纲写成 800 字剧情小说，拍摄时无法拆场。
- ❌ B 故事只负责搞笑，删掉不影响任何东西。
- ✅ 第 4 集结尾：主角打开证物袋，里面不是他放进去的东西——新事实，且前 3 集都出现过这个袋子。
