# 多线叙事与 A/B/C 故事

> 多线不是「同时发生」，而是「互相解释」。A 线让观众紧张，B 线让观众理解，C 线让观众看见世界。

## 一、三条线的分工

| 线 | 功能 | 占比 | 必须回答 |
|---|---|---|---|
| **A 故事** | 本集/本季主目标 | 55–65% | 主角要什么、失败会怎样 |
| **B 故事** | 对照与关系 | 25–30% | 它如何解释 A 的代价 |
| **C 故事** | 世界/群像/主题 | 10–15% | 它如何让世界可信 |

**B 故事不是副线笑话**。它要提供 A 故事缺少的东西：另一种选择、一个反例、一段关系代价。

## 二、交织节奏

```
A1 → A2 → B1 → A3 → A4 → C1 → B2（碰撞 A）→ A5
```

- 新线第一次出现，给足 1 场完整建立。
- 每次切换至少 1 场，避免碎切。
- B 线每 3–5 场必须与 A 线发生一次信息/人物/物件碰撞。
- C 线每集不超过 2 场，避免抢主线。

## 三、主题共振

三条线应该回答同一个问题的不同面：

- A：为了真相，要不要毁掉一个人的生活？
- B：主角的搭档为了保住家庭，选择沉默。
- C：码头少年为了生计，替人作伪证。

**共振不是重复**：不要三条线都在说「真相很重要」，而是让它们给出不同答案。

## 四、汇合与分离

汇合点必须有「必须见面」的理由：

1. 同一物件在两条线出现；
2. 同一截止时间逼两条线同时行动；
3. 一条线的发现解释另一条线的异常；
4. 两条线的人物直接相遇。

**汇合后要分离**：解决一个共同问题后，各线产生新的独立目标，否则剧情会挤成一团。

## 五、每集配额

- A 线：至少 3 场；
- B 线：1–2 场；
- C 线：0–2 场；
- 三条线同集出现时，至少两条发生碰撞。

## 六、自检表

- [ ] A/B/C 各自的目标能一句话说清？
- [ ] B 线是否解释了 A 线缺少的东西？
- [ ] B 线是否每 3–5 场与 A 线碰撞？
- [ ] C 线是否每集 ≤2 场？
- [ ] 三条线是否回答同一问题的不同面？
- [ ] 汇合点是否有「必须见面」的理由？
- [ ] 汇合后是否产生了新的独立目标？

## 七、反例

- ❌ B 线只负责搞笑，删掉不影响 A。
- ❌ 三条线各自精彩，但从不交汇。
- ❌ 每集都三条线平均分配，结果每条都推进不动。
- ✅ A 线查案，B 线搭档隐瞒收钱，C 线码头少年作伪证；三条线在「同一张通行证」上汇合，汇合后各自面临新选择。
