# 单集结构 · 冷开场 · 集尾钩子

> 一集 = 一个完整的观看单元 + 一个让人必须看下一集的理由。

---

## 一、单集的四个块

```
冷开场（Teaser / Cold Open）  0-3 分钟
前情提要（Recap）           30 秒（可省略）
主体（Act A / B / C）        35-40 分钟
集尾钩子（Act Out）          1-3 分钟
```

### 冷开场

**冷开场是「今晚的戏」，不是「上集的续集」。**

| 好的冷开场 | 坏的冷开场 |
|---|---|
| 一个独立的悬念小场景 | 上一集结尾的下一帧 |
| 换时间线/换视角 | 主角在车里的对话 |
| 让观众先看到本集的核心 | 回顾人物关系 |
| 制造情绪落差 | 日常流程 |

**流媒体剧集**（尤其 30 分钟喜剧）：冷开场常省略，直接进。
**黄金时段剧集**（45 分钟）：冷开场是传统，必须有。

### 前情提要

**越少越好。** 30 秒以内，只提必要。
现代观众更愿意被信任；大段回顾是 90 年代的遗产。

## 二、四幕网格与页码锚点

### 45 分钟剧集（约 42-44 页）

| 幕 | 结束页 | 内容 |
|---|---|---|
| Act A | ~8 | 建立本集问题 |
| Act B | ~28 | 加压与波折 |
| Act C | ~40 | 收束 |
| Act Out | ~42 | 钩子 |

### 30 分钟情景喜剧（约 28 页）

| 幕 | 结束页 |
|---|---|
| Act A | ~6 |
| Act B | ~21 |
| Act C | ~26 |
| Act Out | ~28 |

### 幕内转折

| 转折点 | 位置 | 功能 |
|---|---|---|
| **转折一** | 幕一末 | 引入对手的阻击 |
| **转折二** | 幕二中 | 中点，波澜再起 |
| **转折三** | 幕三初 | 主角反扑 |
| **转折四** | 幕三末 | 解决或失败 |

**「看不见的三幕」测试**：如果剧本没有标 ACT 标记，
把幕点位置遮住问「这四场戏能否用一张纸覆盖其余部分」——
如果能，说明幕是隐性的，结构依然成立。

## 三、场次比例

一集里各类场次的大致比例：

| 类型 | 占比 | 说明 |
|---|---|---|
| **主要角色戏** | 50-60% | 推进主线 |
| **次要角色戏** | 20-30% | B 故事 / 群像线 |
| **过场/转场** | 10-15% | 时间跳跃、空间移动 |
| **冷开场 + 集尾** | 5-10% | 钩子 |

**B 故事不是可有可无的。** 它承担：
- 给主线提供对照与反讽
- 让演员有喘息空间
- 在主线僵持时提供另一种张力

## 四、A/B/C 故事编织

| 故事线 | 功能 | 交叉方式 |
|---|---|---|
| **A 故事**（主线） | 观众追剧的主因 | —— |
| **B 故事**（副线） | 对照、深度、喘息 | 与 A 共享人物，主题镜像 |
| **C 故事**（轻线/喜剧线） | 节奏调剂 | 独立，但常与 A 共享场景 |

**编织原则**：
- A 和 B 至少交叉 3 次
- 每次交叉，两条线都变
- C 线不需要交叉，但要有至少一次「A 线人物闯入 C 线」

## 五、集尾钩子

### 五种做法

| 做法 | 说明 | 强度 |
|---|---|---|
| **倒计时** | 炸弹、绝症、最后期限 | 强 |
| **揭示** | 揭开一个身份或事实 | 中强 |
| **反转** | 刚建立的认知被推翻 | 强 |
| **情感爆破** | 关系彻底断裂 | 很强 |
| **不可逆行动** | 主角做了不能撤回的事 | 最强 |

### 钩子的三条纪律

1. **钩子必须是本集的结果**，不是外挂的悬念。要么本集的高潮本身就是钩子，要么钩子来自本集埋的线。
2. **不要每集用同一级**。轮换。
3. **钩子之前要有一个「呼吸」**。观众要有半秒准备，钩子才有效。

### 不可逆行动的例子（自创）

- 主角把唯一一份证据交了出去
- 主角删掉了那条录音
- 主角当着所有人承认了
- 主角离开了那个位置

## 六、单集分集大纲模板

```
第 12 集《标题》
时长：45 分钟 | 场景数：9 | 场景总量：约 43 页

本集核心问题：主角要不要相信他一直不信任的人？
本集类型节拍：2（对手进攻）/ 5（真相浮现）
A 故事线：______（3-4 句）
B 故事线：______（2-3 句）
C 故事线：______（1-2 句）

场次表：
 1  外景  医院门口  晨   —— 冷开场：陌生人递来一封信
 2  内景  警局办公室  日 —— 前情：新的调查方向
 3  内景  审讯室     日  —— 冲突：老搭档对质
 4  外景  停车场     日  —— 转场，B 故事线
 5  内景  天台       黄昏 —— 转折二：真相反转
 6  内景  会议室     夜  —— 转折三：主角反扑
 7  内景  走廊       夜  —— 转折四：结果
 8  内景  车内       夜  —— 集尾钩子：B 级倒计时

幕点：Act A 结束于场次 2 / Act B 结束于场次 5 / Act C 结束于场次 7
集尾钩子等级：B
开篇状态 vs 结尾状态：主角从"独行"变为"有了同盟但失去退路"
```

## 七、单集自检表

- [ ] 冷开场是本集新戏，不是上集续帧
- [ ] 前情提要 ≤ 30 秒（或省略）
- [ ] 幕点位置符合网格（可遮住验证）
- [ ] 转折一至四都在，且位置合理
- [ ] A/B 至少交叉 3 次
- [ ] 主要角色戏占比 50-60%
- [ ] 集尾钩子是本集结果，不是外挂悬念
- [ ] 钩子等级与上集不同（全季轮换）
- [ ] 钩子前有呼吸
- [ ] 开篇与结尾的状态有明确差异
