# 交付格式与拍摄可行性

> 剧本交付不是「写完发过去」，而是「让制片、导演、演员、剪辑都能用同一份文件工作」。格式错、场景不可拍，内容再好也会被打回。

## 一、交付清单

```
□ 正文字体：中文宋体/黑体，英文 Courier（按剧组要求统一）
□ 页面：A4，左侧留装订边，页脚含页码与剧名
□ 场景头：内/外景 · 地点 · 时间，独立成行
□ 场景号：修订稿保留，便于拆景与排期
□ 角色名：首次出现给年龄/身份，之后统一
□ 对白：角色名居中或顶格，按剧组模板
□ 转场：全剧统一，不混用
□ 封面：剧名、集数、版本号、日期、作者/联系方式
□ 修订页：本版改动清单
```

**一份文件只保留一个版本号。** 不要用「最终版」「最终版2」「真的最终版」。

## 二、版本与修订标记

| 标记 | 用途 |
|---|---|
| 白纸 | 初稿 |
| 蓝纸 | 修改稿 |
| 粉纸 | 拍摄稿 |
| 黄纸 | 现场改稿 |

电子稿用 `v1 / v2 / v3` + 日期；每次只改一处结构时升小版本，重写时升大版本。修订处用侧边标记，页脚写「修订页：3、7、12」。

## 三、拍摄可行性检查

| 项目 | 问题 | 替代方案 |
|---|---|---|
| **场景数** | 单集是否超过 12 场/过多转场 | 合并同地点场景 |
| **夜外** | 是否大量夜外/雨戏 | 改日景/内景，或集中拍摄 |
| **群演** | 是否需要大场面人群 | 用画外声/局部特写暗示 |
| **儿童/动物** | 是否有儿童/动物重场戏 | 改年龄/用画外 |
| **特效** | 是否依赖未确定的视效 | 改成可实拍的效果 |
| **道具** | 是否有定制/稀有道具 | 用常见物替代，保留功能 |
| **地点** | 是否频繁跨地点 | 集中到 3–4 个主场景 |
| **动作** | 是否有高风险特技 | 改调度/剪辑暗示 |

**可行性不是降低质量**：用更少的场景讲同样的信息，往往更好看。

## 四、预算敏感的改写原则

1. **先保戏，再保景**：一场戏的核心是冲突，不是地点。
2. **能合并就合并**：把三处谈话合并到同一空间，用时间/服装变化区分。
3. **用声音代替画面**：爆炸、追击、 crowd 可以用画外声 + 反应镜头。
4. **把特效改成调度**：无法拍的变形，用遮挡、光影、剪辑完成。
5. **标记而不是硬写**：确实需要高成本时，在场景清单里标「预算敏感」，让制片决定。

## 五、交付前自检表

- [ ] 封面、页码、版本号、日期齐全？
- [ ] 场景头格式全剧统一？
- [ ] 场景号连续、无重复、无跳号？
- [ ] 角色名前后一致，首次出现有年龄/身份？
- [ ] 单集场景数是否在可拍范围？
- [ ] 夜外/群演/儿童/动物/特效/特技是否已标出？
- [ ] 修订页是否列出本版改动？
- [ ] 是否删掉了所有「镜头推近」类后期指令？

## 六、反例

- ❌ 同一集里「内景/日」和「日/内景」混用，制片无法统一拆景。
- ❌ 每集 20 场，跨 15 个地点，预算直接翻倍。
- ❌ 用「千军万马」写战争，没有标注可替代方案。
- ✅ 把三场不同地点的谈话合并到同一间办公室，用窗外光线变化表示时间流逝，场景数从 14 降到 10。
