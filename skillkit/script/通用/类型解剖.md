# 类型解剖 · 观众契约 · 节拍表

> 类型不是题材标签，是**观众与银幕之间的契约**。违背契约 = 观众离场。

---

## 一、类型契约

每种类型都向观众承诺三件事：

1. **我会看到什么**（体验承诺）
2. **我为什么还在看**（持续动力）
3. **我会得到什么**（兑现方式）

观众进场时心里有一张「支票」：我付了两小时注意力，你要还我这三种东西。

**类型契约被违背的典型死法：**
- 悬疑片拖到一半变成爱情戏 → 观众等谜底，等不到
- 喜剧片最后一分钟哭成泪人 → 观众被骗
- 恐怖片用烂片手法吓人 → 观众觉得被侮辱

---

## 二、十二类家族与节拍

每个类型有固定的节拍表。写之前先想清楚：**我的剧本命中了哪几个节拍？**

### 恐怖 / 惊悚
1. 日常被打破
2. 威胁被感知但看不见
3. 第一次真正的袭击
4. 短暂喘息
5. 威胁升级（且更近）
6. 真相的暗示
7. 主角孤立
8. **终极对决**
9. 代价（有人失去，或真相本身是代价）

**契约**：观众在等「它到底是什么」和「谁能活下来」。

### 动作
1. 平常世界
2. 威胁逼近
3. 第一次交锋（小胜）
4. 反派得势
5. 盟友背叛或失去
6. 主角被逼到极限
7. 重整旗鼓（得到新资源/新认知）
8. 最终对决
9. 代价

**契约**：期待「干脆的解决」和「身体性的爽」。

### 科幻
1. 现状（世界如何运作）
2. 异常出现
3. 第一次接触
4. 试图理解（可能得出错误结论）
5. 代价显现
6. 真相浮现
7. 最终选择（拥抱还是对抗）

**契约**：期待「概念」——世界观必须提出一个能推演的问题，而不是一堆设定。

### 犯罪 / 黑帮
1. 日常
2. 一次越界（通常是小规模）
3. 成功（让人尝到甜头）
4. 后果上门
5. 清理
6. 代价升级
7. 崩塌
8. 代价（背叛、失去、自由）

**契约**：期待「权力与它的腐蚀」。

### 爱情
1. 相遇（或重逢）
2. 吸引与冲突
3. 试探
4. 障碍显现
5. 分离
6. 证明 / 转变
7. 重聚
8. 新平衡

**契约**：期待「情感被验证」，不是「障碍被清除」。

### 喜剧
1. 荒谬的常态被建立
2. 压力累积
3. 第一次崩溃尝试
4. 升级
5. 更大的崩溃尝试
6. 低谷
7. 最终的疯狂计划
8. 爆发（同时解决主要问题）

**契约**：期待「升级与释放」。**喜剧的规则是：越糟越好笑。**

### 西部
1. 边疆的日常
2. 威胁逼近
3. 英雄拒绝介入
4. 事件迫使介入
5. 战斗中失去同伴
6. 反思
7. 最终对决
8. 离开

**契约**：期待「代价与和解」。

### 奇幻 / 玄幻
1. 日常世界
2. 召唤 / 异象
3. 拒绝（必须被迫接受）
4. 导师出现
5. 试炼
6. 深入敌境
7. 惨败
8. 顿悟
9. 最终试炼

**契约**：期待「旅程与蜕变」，**必须有离开与回归**。

### 惊悚 / 心理悬疑
1. 表面正常
2. 异常细节
3. 主角的怀疑
4. 调查
5. 误导（观众和主角一起错）
6. 真相的碎片
7. 真相
8. 代价

**契约**：期待「重新理解已经看过的内容」。

### 传记 / 成长
1. 童年 / 起点
2. 第一次挫折
3. 找到方向或导师
4. 重大成功
5. 崩溃
6. 面对真相
7. 接受
8. 传承

**契约**：期待「一个人如何成为他自己」。

### 家庭 / 群像
1. 家庭聚在一起
2. 表面和谐
3. 裂缝出现
4. 旧账被翻出
5. 分裂
6. 各自面对
7. 部分重聚
8. 新的平衡

**契约**：期待「未结的账被处理」。

## 三、三条通用规则

### 规则一：命中该类型的每个节拍

跳过节拍 = 观众感到被骗。但**不必平均分配篇幅**——某些节拍可以一句话带过，某些要写三场。

**检验**：把节拍表和你的场景清单并排，标出每个节拍在哪一场。

### 规则二：混合三到四个类型

**纯类型 = 单调。**

| 主类型 | 混合类型 | 效果 |
|---|---|---|
| 惊悚 | 爱情 | 恐怖来自关系的恶化 |
| 动作 | 科幻 | 打斗有了规则和代价 |
| 喜剧 | 惊悚 | 笑点与惊吓交替 |
| 科幻 | 家庭 | 宏大命题落在具体关系上 |
| 西部 | 犯罪 | 英雄变成反派的过程 |

**混合的原则**：主类型决定**结构骨架**（节拍表），混合类型决定**局部质感**（人物关系、场景质感）。

### 规则三：超越主类型

最好的类型片会**问出类型本身回答不了的问题**。

- 恐怖片问「恐惧来自什么」
- 爱情片问「爱是否需要被对方理解」
- 动作片问「暴力解决不了什么」

**超越不等于反转。** 是让类型承担更重的命题，不是把类型掀翻。

---

## 四、类型与剧本阶段的关系

| 阶段 | 类型的作用 |
|---|---|
| S0 引擎 | 选定主类型 + 1-2 个混合类型；写出类型契约（观众会得到什么） |
| S2 文档 | 检查每个角色的功能是否符合类型要求（类型里的角色分工） |
| S3 试播结构 | 按主类型节拍表排布单集结构 |
| S4 分集大纲 | 逐集标注命中了哪些节拍 |

## 五、类型自检表

- [ ] 写下了主类型与混合类型
- [ ] 写下了**类型契约**（观众会看到什么 / 为什么还在看 / 得到什么）
- [ ] 节拍表逐条标出了对应场景
- [ ] 有 1-2 个混合类型，且不喧宾夺主
- [ ] 有一个类型本身回答不了的问题
- [ ] 全篇没有违背类型契约的地方（比如悬疑片中途大团圆）
