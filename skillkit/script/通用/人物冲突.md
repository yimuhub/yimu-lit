# 人物 · 对手 · 冲突

> 戏剧冲突 = 人物对人物的**欲望对撞**。没有对手的故事只是事故。

---

## 一、人物的三维构造

每个主要人物必须填满这三个维度，缺一不可：

| 维度 | 核心问题 | 常见误解 |
|---|---|---|
| **生理** | 他有什么天赋/缺陷/身体状况？ | 只写外貌 → 那是设定不是人物 |
| **社会** | 他在社会/家族/组织里是什么位置？ | 只写职业 → 职业不产生冲突 |
| **心理** | 他**相信**什么？他**恐惧**什么？ | 只写目标 → 目标不是信念 |

### 生理维度

不是长相，是**限制**。每个主要人物至少有一个生理上的限制或特质，会影响他做事的方式：
- 他只有一只手能抬起来 → 动作戏的每个选择都变
- 她必须每天下午三点吃药 → 时间表变成戏剧压力
- 他听力受损 → 关键信息只能靠别人转述

### 社会维度

**位置产生冲突。** 一个人在社会结构中的位置，决定他必须维护什么、必须服从什么、必须隐藏什么。

写人物小传时要回答：
- 他在这个结构里**管谁**？**怕谁**？**欠谁**？
- 他违反了哪条规则？违反的代价是什么？
- 别人**指望**他做什么？

### 心理维度

**信念（不是目标）。** 信念是他相信世界应该怎么运转。
- 目标：我要拿到那份文件（可以变）
- 信念：努力就有回报（很难变，变了就是弧光）

**恐惧**是信念的反面。
> 「我相信努力就有回报」→ 恐惧「我会被看不起」
> 「我相信规则能保护好人」→ 恐惧「我变成他们」

**人物弧光 = 信念的改变或代价。**

## 二、主角设计

### 缺陷必须是双刃的

好的缺陷**同时是优点**：
- 固执 → 坚持到底，也听不进劝
- 魅力 → 说服别人，也让人不设防
- 控制欲 → 危机时能调度一切，也摧毁关系

**只有缺点没有优点的角色是功能性的，不是戏剧性的。**

### 主角的三重渴望

主角同时想要三样东西，其中两样互相矛盾：

1. **外在目标**（剧本的引擎）：拿到证据 / 赢得官司
2. **内在需求**（弧光的来源）：被原谅 / 承认自己错
3. **对自身矛盾的渴望**（最有戏的部分）：既想证明自己对，又想证明自己值得被爱

第三项最重要。**「我想要 X，但只有变成 Y 才能得到 X」** 是人物弧光的核心公式。

### 主角的失控时刻

主角必须有一个**会失去控制的时刻**——不是被击败，是**他自己越过了自己的线**。
这个时刻是观众判断角色深度的锚点。

## 三、对手设计

### 对手必须有正当性

**最常见的剧本病：对手是坏人。**

坏人的威胁靠外部力量，观众不会真正紧张。对手必须**有正当理由**：
- 他做的事从他的角度看是对的
- 他赢得有道理
- 观众甚至会有一瞬间认同他

主角与对手的关系应该是**镜面**：同样的手段，不同的目的；或者同样的目的，不同的手段。

### 对手的三层结构

1. **战术层**：他下一步怎么走（观众能跟上的具体行动）
2. **战略层**：他的中期目标（需要预判）
3. **哲学层**：他相信的东西（解释了为什么他不会退让）

三层都要有。战术层给场景，战略层给节奏，哲学层给重量。

### 对手与主角的关系矩阵

| 对手类型 | 说明 | 例子结构 |
|---|---|---|
| **镜像** | 方法相同，信念相反 | 两人都是警察，一个信程序一个信直觉 |
| **互补** | 各自有对方缺的东西 | 一个有能力没人信，一个有信任没能力 |
| **师徒** | 主角继承并背叛 | 老警探的规矩 vs 新人的手段 |
| **同源** | 同一环境造就，不同选择 | 同一个工厂出来的两个工友 |
| **面具** | 对手其实是主角的另一面 | 主角的黑化版本 |

### 反派梯队

一部戏需要至少三级压力：

1. **执行层**（杂兵）：制造具体麻烦
2. **阻碍层**（中层对手）：挡住主角的路
3. **根源层**（真正的对手）：代表主角必须面对的那个命题

主角打赢了执行层，还要面对阻碍层，最后面对根源层。**只打一级 = 剧本单薄。**

## 四、冲突设计

### 冲突的三个来源

| 来源 | 说明 | 强度 |
|---|---|---|
| **内在** | 主角 vs 自己 | 最强，但最难写 |
| **人际** | A vs B | 常用 |
| **外在** | 人 vs 环境/制度 | 弱，除非制度有人格化 |

**好的剧本至少有一条内在冲突线。**

### 冲突的升级

冲突不能原地重复。三种升级方式：

1. **加码**：赌注变大（从丢工作到丢命）
2. **换场域**：换到主角更不利的地方（家里 → 法庭）
3. **换性质**：从对抗变成合作再变回对抗（信任 → 背叛）

### 阻碍手（Obstacle）

给每个目标配三层阻碍：
- **物理阻碍**：具体的东西（门、锁、时间、伤）
- **制度阻碍**：规则、流程、条款
- **关系阻碍**：某个人的不合作

**永远先检查物理阻碍有没有被用尽。** 大多数平淡的剧本是因为主角只是「不想做」而不是「做不到」。

## 五、人物网（剧集用）

### 三种关系

| 关系 | 功能 | 剧集价值 |
|---|---|---|
| **血缘/亲密** | 情感深度 | 提供理由 |
| **职业/机构** | 压力来源 | 提供冲突 |
| **债务/亏欠** | 道德张力 | 提供戏剧性 |

### 人物网的三条设计线

1. **每两个人之间都要有未结的事**（欠债、旧事、未说的话）
2. **每个人物都要与主角有两条不同的线**（一条温情一条对立）
3. **每季至少有一条关系要**翻转**（盟友变敌人 / 敌人变盟友）

### 群像戏的秘密

群像剧最容易散。**解法：所有人物共享同一个秘密，但只有一个人知道全貌。**
这个人物是轴心，其他人都围绕他对齐。

## 六、人物小传模板

每个主要人物写一页：

```
【姓名】  年龄 / 职业 / 外形一句话

生理维度：身体上限制他行动的一件事
社会维度：他在结构中的位置、管谁怕谁欠谁、违反了哪条规则
心理维度：他相信什么（信念） / 他恐惧什么 / 他说给自己听的谎言

外在目标：他嘴上说想要什么
内在需求：他真正缺什么
矛盾渴望：他必须变成什么才能得到想要的东西

与主角的镜面关系：____

弧光：起点信念 → 终点信念（或：起点信念 → 付出了什么代价）
```

## 七、自检表

- [ ] 每个主要人物的三维都填满了
- [ ] 每个主要人物都有一个**双刃**缺陷
- [ ] 对手有**正当性**，从他的角度看有理
- [ ] 对手有三层（战术/战略/哲学）
- [ ] 主角有至少一个「失控时刻」的设计
- [ ] 存在一条内在冲突线
- [ ] 每场戏的主要阻碍**可具象化**（不是「他不愿意」而是「他做不到」）
- [ ] 至少三级反派梯队
- [ ] 每两个人之间有未结的事
