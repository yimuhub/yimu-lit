# 场景设计 · 进出场 · 价值转折

> 场景不是地点，是**价值的改变**。没改变价值的场景是布景。

---

## 一、场景的最小单位

一个场景必须包含：

```
目标（谁要什么）
  ↓
阻碍（谁挡着 / 什么挡着）
  ↓
交锋（升级）
  ↓
结果（变了 / 没变 / 变得更糟）
```

**检验方法：把这场戏的结果用一句话说出来。**
说不出来 → 这场戏还没成型。

### 场景的结果分四类

| 类型 | 说明 | 后续影响 |
|---|---|---|
| **赢** | 主角拿到想要的 | 但代价已付出 |
| **输** | 主角没拿到 | 局面更紧 |
| **转折赢** | 拿到了没想到的东西 | 引入新信息 |
| **代价** | 拿到了，但失去别的 | 引爆下一场 |

**最弱的结果是「没变」。** 如果一场戏结束时一切如常，删掉它。

---

## 二、价值转折（Value Turn）

每个场景内部都有一条**价值曲线**：

```
场景开始时的价值（正/负）→ 场景结束时的价值（正/负）
```

场景的有效性 = **价值发生了极性翻转**。

| 起始 | 结束 | 有效 |
|---|---|---|
| 正 | 负 | ✅ 主角失去 |
| 负 | 正 | ✅ 主角获得 |
| 正 | 正 | ❌ 没变化（除非有程度的提升） |
| 负 | 负 | ❌ 没变化 |

**场景内部还会再翻转多次。** 一场戏有 3-5 次小转折（beat）才够看。

### Beats（节拍）

**一个 beat = 一次价值方向的改变或一次信息改变。**

写法：在草稿上给每个转折点标一个 `>` 符号。

检验：
- 一场戏少于 3 个 beat → 太平
- 多于 8 个 beat → 观众跟丢
- 5 个 beat 是舒适区

## 三、进出场（Enter Late, Leave Early）

### 进场

**观众知道的永远比人物早一点。**

- 场景开始时，人物**已经在麻烦里**
- 前几行不要用来建立空间和介绍人物
- 台词第一句就该有摩擦

> ❌ 场景 12 内景 咖啡厅 日
> 她走进咖啡馆，环顾四周，看到他坐在角落，坐下。
> ❌ 场景 12 内景 咖啡厅 日
> 「你怎么才来？」
> 「堵车。」
> 「我妈说你要走。」
> 「嗯。」

### 离场

**在问题刚解决（或刚变严重）时离开。**

- 场景最后一行应该制造下一个场景的欲望
- 最后一个动作比最后一句话更重要
- 不要用「他们又聊了一会儿」收尾

### 压缩空间的两个手法

1. **省略**：跳过无聊的部分，直接到冲突
2. **重叠**：两个场景同时发生在一个空间

## 四、场景分类

| 类型 | 特征 | 目的 |
|---|---|---|
| **对称场** | 双方力量均衡 | 建立僵局 |
| **不对称场** | 一方明显占优 | 施压或反击 |
| **喜剧场** | 预期落空 | 释放压力 |
| **反讽场** | 观众知道而人物不知道 | 制造悬念/笑点 |
| **间接场** | 冲突通过第三方发生 | 增加复杂度 |
| **最小场** | 一个人 + 一个动作 | 转折点、缓冲 |
| **反应场** | 一个人对前面发生的事的反应 | 情绪消化、埋伏笔 |

**一场戏只做一件事。** 混着做会互相削弱。

---

## 五、场景设计的五个检查

### 1. 目的检查
这场戏存在是为了什么？（推进情节 / 揭示人物 / 制造悬念 / 提供喘息）

**四场戏不重复目的。** 如果连续三场都是「推进情节」，中间要插一场揭示或喘息。

### 2. 冲突检查
主角在场上的**目标**是什么？**阻力**是什么？

阻力必须是**人**或**可具象化的东西**，不能是「气氛不对」。

### 3. 转折检查
最后一个 beat 是什么？它和第一个 beat 有什么关系？

### 4. 新意检查
这场戏和之前哪场戏最像？如果很像，合并或改角度。

### 5. 视觉检查
这场戏能被拍出来吗？需要多少场景？成本会不会失控？

**剧本的成本控制是真实约束**：一个「所有人都在同一场戏里」的大场面很爽，但预算和排期上未必可行。写大纲时就要标出**场景数**和**预计页数**，让制片方看得懂。

## 六、道具与场景设计

### 道具的三种功能

1. **推动**：改变场面（如一把钥匙打开了不该开的门）
2. **揭示**：暴露人物（他下意识地整理领带）
3. **预示**：后面会回来（第一次出现时观众不会注意）

**每个主要道具至少要承担一项功能**，纯装饰的道具要删。

### 场景的视觉母题

同一场景反复出现时，会有**视觉上的重复与变化**。
- 第一次：同质、整齐、常规
- 中间：开始有磨损
- 最后：彻底变形

这比台词更有效地表达时间流逝与关系变化。

## 七、场次清单模板

```
场次 12  内/外  地点  时间
------------------------------------------------------------------
出场：林（母亲）、陈（儿子）
道具：一台旧收音机、药瓶
前提：林催陈把检查结果的事说清楚
触发：陈掏出体检报告
阻碍：林不肯相信，想把报告抢走
beat1：报告被抢走（价值 转负）
beat2：陈说出「你早就知道了」（信息 揭露）
beat3：林说「知道也得你去」（关系 转折）
beat4：林把药瓶推到陈面前（价值 转正，但更复杂）
结果：林知道陈要去，但不去；关系表面缓和，暗流未解
钩子：报告上的名字不是林
```

## 八、自检表

- [ ] 每场戏的目标、阻碍、结果都能一句话说清
- [ ] 价值极性在场景内翻转
- [ ] beat 数在 3-8 之间
- [ ] 进场时人物已在麻烦里
- [ ] 离场时问题刚解决或刚变严重
- [ ] 相邻场次的目的不重复
- [ ] 阻力可具象化
- [ ] 道具承担了功能
- [ ] 场景数与预计页数已标注（成本可评估）
