# 场景写作与动作行

> 剧本正文只写「镜头能拍到、话筒能收到」的东西。心理活动、作者评论、摄影机指令，都不属于场景。

## 一、场景头的标准写法

```
内景 / 医院走廊 / 夜
外景 / 码头 / 清晨（雨）
```

- 三要素：内/外景、地点、时间（日/夜/晨/昏，必要时加天气）。
- 场景头独立成行；同一场景中途不重复。
- 地点只写拍摄地，不写「主角的内心世界」。
- 场景号在修订稿里保留，便于制片与剪辑对照。

## 二、动作行的五条规则

1. **现在时**：写「她推开门」，不写「她推开了门」。
2. **可视化**：只写能拍到的动作、物件、光线、声音。
3. **一段不超过 3 行**：长段落拆成多个动作节拍。
4. **不写心理**：「她感到害怕」→「她的手在门把上停住，指节发白」。
5. **不写摄影机**：「镜头推近」→ 用动作引导视线：「她把信封推到桌子中央」。

## 三、动作行的信息密度

每个动作行最好同时承担两件事：

| 动作 | 同时交代 |
|---|---|
| 他把椅子往后拖了半步 | 距离感 + 防御姿态 |
| 她先把杯子擦了一遍才倒水 | 洁癖/紧张 + 待客礼数 |
| 他数了三遍钞票才递过去 | 经济状况 + 不信任 |

**纯功能性动作**（开门、走路、坐下）单独出现时，要么删，要么附着一个态度。

## 四、对白在场景里的位置

- 对白前给一个动作锚点，让演员知道在做什么。
- 一段对白不超过 6 行，中间插入动作或反应。
- 不要让两个人物站着说话超过一页；给他们一件事做（收拾、开车、签字）。
- 台词不解释设定；设定通过「选择」暴露。

## 五、转场与蒙太奇

- 常规转场不写；用场景头自然切换。
- 需要强调时用「切至」「叠化」，但全剧保持统一。
- 蒙太奇写清「主题」与「声音」：一组画面要说明什么，配什么声音。
- 不在场景里写「淡入淡出」等后期指令，除非导演稿明确要求。

## 六、场景结束的四种方式

1. **动作收束**：一个动作完成，局面改变。
2. **台词收束**：一句让局面翻转的话。
3. **画面收束**：一个视觉信息，观众先于人物知道。
4. **硬切**：直接切到下一场，用反差制造意义。

**最弱的是「说完再见，走出门」**：没有信息变化，只是结束。

## 七、自检表

- [ ] 每个场景都有标准场景头？
- [ ] 动作行是否都是现在时、可视化、≤3 行？
- [ ] 有没有写心理活动、作者评论或摄影机指令？
- [ ] 对白段落是否超过 6 行没有动作穿插？
- [ ] 场景结束是否改变了局面？
- [ ] 纯功能性动作是否已删或附着态度？
- [ ] 场景号是否保留，便于制片对照？

## 八、反例

- ❌ 「她心里一阵酸楚，想起母亲。」——拍不到。
- ❌ 「镜头缓缓推近他的脸，音乐渐强。」——导演/后期的事。
- ❌ 两个人坐在咖啡厅聊了 4 页，没有任何动作变化。
- ✅ 「她把糖包撕开，倒进杯子，又停住。杯口已经满了。」——动作交代情绪，不解释。
