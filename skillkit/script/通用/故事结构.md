# 故事结构 · 三幕 · 幕点 · 序列

> 结构不是时间顺序，是**因果链**。删掉一个环节，后面的环节必须不成立。

---

## 一、层级结构

```
故事（Story）
└── 幕（Act）
    └── 序列（Sequence）
        └── 场景（Scene）
```

**场景 = 最小的完整戏剧单位。** 一个场景必须有：
- 一个目标（谁想要什么）
- 一个冲突（谁挡着）
- 一个结果（得到了 / 没得到 / 变了）

三者缺一，这个场景就是「过场」，应该删掉或合并。

---

## 二、三幕结构

| 幕 | 页数占比（长片） | 核心问题 | 结束时 |
|---|---|---|---|
| **第一幕** | 25% | 主角要什么？ | 他决定行动 |
| **第二幕** | 50% | 他能不能得到？ | 他输掉一切 |
| **第三幕** | 25% | 他付出什么代价换回来？ | 他做出最终选择 |

### 第一幕（0-25 页）

四个必备节拍：

1. **开场画面**（1 页内）：给一个能概括全片质感的画面
2. **主题陈述**（5 页内）：一句台词点出主题，常来自配角而非主角
3. **铺垫**（10 页内）：建立日常世界，让观众爱上这个平衡
4. **催化剂**（25 页内）：打破平衡的事件

**催化剂是整部戏的引擎。** 它必须：
- 发生在 25 页内（越晚越拖）
- 逼主角做出**主动**选择（不是被动卷进去）
- 不可撤销（undo 不了）

### 第二幕（25-75 页）

第二幕的功能是**加压**，不是发展。

五种推进动力（每场戏至少靠一种）：
1. **对手进攻**：对手主动出招
2. **时限逼近**：时间在消耗
3. **信息崩解**：主角的认知被打碎
4. **代价升级**：赢一场输更多
5. **内部撕裂**：主角和自己对抗

**中点（Midpoint，约 50 页）**：全片的重心转换。
- 前半：主角在**追求**（被动应对）
- 中点：主角**夺取主动**（转攻）
- 后半：主角**被反击**（局势逆转）
- 中点通常还包含一个「假的胜利或失败」

**第二幕的三个危机点（Crisis）：**
- 约 37%：第一次真正的失败，主角被迫改变策略
- 约 62%：最坏时刻（All Is Lost），一切看似结束
- 约 75%：进入第三幕的触发（通常是「主角得到新信息或新工具」）

**All Is Lost（一切失去）**必须是全片最低点：
- 主角失去的不只是外部目标，而是他赖以行动的信念
- 这一场戏往往只有一句台词改变整场戏的性质

### 第三幕（75-100 页）

第三幕**不引入新信息**，只把前面埋的东西兑现。

- **第二幕的负空间**：第二幕里对手赢的那几场，第三幕要原样奉还
- **最终抉择**：主角必须选，且**不能两头都要**
- **最后一个转折**（可选）：观众以为结束了，其实还有一个更真的结尾
- **收束**：不要用「从此他们幸福地生活在一起」，要给一个**新的平衡**

## 三、幕点（Plot Point）标定法

对页码精确控制是行业惯例。一部 100 页长片的参考锚点：

| 页码 | 事件 |
|---|---|
| 1 | 开场画面 |
| 5 | 主题陈述 |
| 10 | 铺垫（建立世界） |
| 25 | **催化剂**（第一幕结束） |
| 37 | 第一危机 |
| 50 | **中点** |
| 62 | 第二危机 |
| 75 | **All Is Lost / 第二幕结束** |
| 90 | 最终抉择 |
| 100 | 收束 |

**不要机械照搬页码。** 要照搬的是**比例**和**功能顺序**。
短片按比例缩放；剧集按集数和集内比例缩放。

## 四、序列（Sequence）

一个序列 = 一组场景构成的一个小高潮。

**序列的通用结构（适用于任何长度）：**

```
1. 目标建立     —— 谁要什么
2. 阻力出现     —— 对手/环境挡路
3. 局势恶化     —— 尝试失败，代价上升
4. 关键节点     —— 主角被迫做选择
5. 收尾翻转     —— 局面朝意外方向倾斜（不是解决）
```

**序列收尾必须是「倾斜」不是「解决」。** 如果一个序列结束时问题解决了，观众会松劲。
正确的收尾是：新问题比旧问题更棘手。

**检查序列是否需要独立成序列：**
- 能不能抽出来单独看成一个 5-10 分钟的小故事？有 → 是序列
- 抽出来之后剩下的部分还成立吗？不成立 → 是序列

## 五、凤头猪肚豹尾（中文短剧/短片的本土结构）

| 部分 | 占比 | 作用 |
|---|---|---|
| **凤头** | 前 10% | 钩子。第一个画面就抓人。不要铺垫，直接进冲突 |
| **猪肚** | 中间 70% | 肉厚。矛盾层层加码，爽点密集，节奏不塌 |
| **豹尾** | 后 20% | 收得猛。最后一个反转或最强一击，留钩子 |

**与三幕的对应：**
- 凤头 ≈ 第一幕压缩
- 猪肚 ≈ 第二幕放大
- 豹尾 ≈ 第三幕提速 + 留钩

**短剧特别提示**：前 3 秒决定观众划不划走。前 3 秒必须出现**最强的钩子画面或钩子台词**，不是 logo 不是人物介绍。

## 六、结构的常见反模式

| 反模式 | 症状 | 修法 |
|---|---|---|
| **中段塌陷** | 40-60 页全是铺垫 | 把第二幕的每场戏都加上时限或代价 |
| **反派躺赢** | 对手只是等主角犯错 | 给对手主动进攻的场次 |
| **双高潮** | 中点有一个完整高潮 | 中点只做重心转换，不做完整高潮 |
| **结局靠巧合** | 最后靠电话/意外解决 | 让主角的选择导致结局 |
| **尾巴太长** | 高潮后还有 15 页 | 高潮从 75 页就开始 |
| **没有 All Is Lost** | 主角一路下滑但没到底 | 加一场信念崩塌的戏 |

## 七、结构自检表

写完大纲后逐条打勾：

- [ ] 催化剂在 25% 处，且主角**主动**做出了不可撤销的选择
- [ ] 中点前后主角的**主动/被动**状态发生了反转
- [ ] 有一个明确的 All Is Lost，主角失去了信念
- [ ] 第三幕没有引入任何新信息
- [ ] 每一个场景都有目标 + 冲突 + 结果
- [ ] 删掉任何一个序列，整个故事都会塌 → 序列是必要的
- [ ] 结局是主角的选择造成的，不是巧合
- [ ] 最后一场戏给了一个**新的平衡**，不是"从此幸福"

## 八、交付物

进入 S4 分集大纲前：

- [ ] 三幕划分（每幕的起止场景与页数）
- [ ] 幕点表（标定页码或集数）
- [ ] 中点与 All Is Lost 的**具体场景描述**
- [ ] 序列清单（每个序列一句小高潮）
- [ ] 第二幕「对手赢的戏」清单（第三幕要原样奉还）
