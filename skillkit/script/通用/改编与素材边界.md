# 改编与素材边界

> 改编的第一步不是写，是确认「我有什么权利改什么」。权利不清，越写越危险；素材不明，越改越失真。

## 一、先分清四种素材

| 素材 | 能否直接用 | 需要做什么 |
|---|---|---|
| **公有领域** | 可以改编 | 确认作者逝世年限/作品进入公有领域；保留改编声明 |
| **已授权作品** | 在授权范围内改编 | 保存合同/授权邮件；确认媒介、地域、期限、独占性 |
| **真实事件/人物** | 需谨慎 | 核实公开报道；避免诽谤、隐私侵权；活人需考虑名誉权 |
| **用户提供素材** | 可用 | 确认用户有权提供；不擅自外传 |

**没有授权记录时，按「不可改编」处理。**

## 二、改编的四种距离

| 距离 | 做法 | 风险 |
|---|---|---|
| **贴身改编** | 保留人物/主线/关键场景 | 必须完整授权 |
| **松散改编** | 保留核心设定，重写人物与情节 | 仍需授权，且注明「改编自」 |
| **灵感来源** | 只取一个概念/母题 | 不构成改编，但不得使用原作独有名称 |
| **同人/续写** | 使用原作人物与世界观 | 商用需授权；非商用也需遵守平台规则 |

**判断标准**：观众能否一眼认出「这是那部作品」？能，就需要授权。

## 三、改编文档（S2 阶段必填）

```
原作：名称 / 作者 / 权利状态
授权范围：媒介（电影/剧集/舞台）、地域、期限、是否独占
保留：人物、主线、关键场景
删除：不适应当前媒介/时代的内容
新增：为影视化补的冲突与人物
敏感点：真实人物、群体刻画、历史争议
声明：片头/片尾的改编声明文字
```

## 四、真实事件的处理

1. 只使用公开、可核实的信息；未判决案件不写定论。
2. 真实人物要么取得授权，要么做足够变形（姓名、职业、地点、关系）。
3. 避免「纪实感」误导：片头标注「根据真实事件改编，人物与情节有虚构」。
4. 受害者与未成年人：降低可识别度，不做二次伤害。
5. 涉及专业领域（医疗、法律、警务）时，请顾问核对流程。

## 五、不能做的事

- 复制原作连续对白/场景描述超过合理引用范围；
- 使用原作独有的专有名词、组织名、招式名而不加授权；
- 把「同人」直接商用；
- 用「致敬」包装实质性复制；
- 把真实人物的隐私细节写成剧情卖点。

## 六、自检表

- [ ] 原作的版权状态已确认？
- [ ] 授权范围覆盖当前媒介、地域、期限？
- [ ] 改编文档写清了保留/删除/新增？
- [ ] 是否使用了原作独有名称？
- [ ] 真实事件是否只用了公开信息？
- [ ] 真实人物是否已授权或充分变形？
- [ ] 片头/片尾是否有改编声明？

## 七、反例

- ❌ 「只改人名和地名」→ 仍是实质性复制。
- ❌ 「反正是同人，不卖钱」→ 平台传播也可能侵权。
- ❌ 把未判决案件写成「真凶就是他」，并用了真实姓名。
- ✅ 只取「一个失忆者回到故乡」的母题，人物、时代、冲突全部重写，并注明灵感来源。
