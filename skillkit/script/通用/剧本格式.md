# 剧本格式 · 行业规范

> 格式是**沟通工具**。制片、导演、摄影、美术都要读它。格式错 = 沟通断。

---

## 一、页面规格

| 项 | 规格 |
|---|---|
| 纸张 | US Letter 8.5 × 11 英寸 / A4（国内通用） |
| 页边距 | 上 1 英寸，下 1 英寸，左 1.5 英寸，右 1 英寸（用于装订） |
| 字体 | 12pt 等宽字体（Courier / Courier New），或行业通用中文等宽 |
| 行距 | 单倍行距，约 60 行/页 |
| 一页时长 | 长片约 1 分钟（1 页 ≈ 1 分钟） |
| 装订 | **左侧**装订（双面打印时奇数页在右） |

**页数换算**：100 页长片 ≈ 100 分钟；剧集单集 45 分钟 ≈ 45 页（实际会短一些，约 40-44 页）。

---

## 二、页眉

```
                    【剧名】                    修订日期
                    第 12 页                    草稿
```

- 剧名居中
- 修订日期：编剧用 `MM/DD/YY`
- 稿次标识：`FADE IN` 前用 `DRAFT` / `REVISED` / `FINAL`
- **所有页面都要有页眉**，包括场景标题页

---

## 三、场景标题（Scene Heading / Slug）

```
内景  林家客厅  日
外景  医院走廊  夜
内景  警局审讯室  连续
```

规则：
- 必须用**大写**
- 三个要素：**内/外** + **地点** + **时间**
- 时间写 `日` / `夜` / `黄昏` / `黎明`，`连续` 表示紧接着上一场
- 不用句号
- **不写镜头、不写人物**（那是分镜的事）

**常见错误**：
- ❌ `内景 客厅`（缺时间）
- ❌ `INT. LIVING ROOM - DAY`（中英混用不统一）
- ❌ 在场景标题里写「（镜头推近）」

---

## 四、动作行（Action）

```
林从沙发上站起来，走到窗边。她没有拉窗帘。

窗外的雨停了。楼下有个孩子在喊什么。
```

规则：
- **过去时**（中文剧本用动词原形/完成式更自然，但保持全篇一致）
- 只写**可拍**的内容
- **一句不超过三行**，一个段落不超过四行
- 首次出现的人物，用**大写全名**介绍
- 不用摄影术语（推拉摇移、景别、镜头）—— 那是分镜表的活

### 大写规则

**人物首次出场时大写**，之后小写。
这告诉演员表和制片「这是新角色」。

---

## 五、对白

```
                          林
              你什么时候回来的？

                          陈
              （不看她）刚下飞机。
```

规则：
- 角色名**大写**，顶格或缩进（保持全篇统一）
- 角色名后不加冒号
- 括号里的**表演提示**用小写，单独成行
- 段落之间空一行
- **中文剧本一行不超过 30 字**

### 表演提示的克制

括号提示是给演员的参考，不是给剧本的装饰。

- ✅ `（压低声音）` `（不看他）` `（停住）`
- ❌ `（此处演员需要表现出极度的震惊与被背叛的复杂情感）`

**规则：如果你能不用提示就让读者知道，就不用。**

---

## 六、括号行

用于**场景转换处的补充说明**、**技术说明**：

```
（三年后。同一间客厅，但所有家具都蒙着布。）
```

不要用括号做：
- 内心独白（用 VO）
- 时间跳转的复杂说明（拆成新场景标题）
- 补充剧情（写进动作行）

---

## 七、结尾

```
                            淡出：
```

写在场景最后一行下方。

---

## 八、修订标记

### 修订页（Revision）

```
                              修订稿 2/14/26
                              蓝色
```

放在页眉下方。

### 星号标记改动

新改的台词前加 `*`：

```
                          林
              *你什么时候回来的？
```

### 场景编号

给场景编号方便讨论：

```
12  内景  林家客厅  日
```

## 九、提交格式

| 用途 | 格式 |
|---|---|
| **投稿（Spec Script）** | 纯剧本 PDF，无页眉的封面页含标题/作者/联系方式 |
| **拍摄剧本（Shooting Script）** | 完整脚本 + 分镜表 + 演员表 + 场次表 + 通告单 |
| **内部审阅** | 草稿水印，页眉标 `DRAFT` + 日期 |
| **电视脚本** | 双栏对白（Teleplay），左半页是动作，右半页是对白 |
| **中文行业习惯** | 场景标题「内/外 + 地点 + 时间」；正文与对白不严格分栏 |

**本项目默认输出**：中文行业通用格式（场景标题 + 动作行 + 角色名缩进对白），不加分栏，但预留标准模式的开关。

---

## 十、常见格式错误

| 错误 | 后果 |
|---|---|
| 场景标题缺时间 | 分场统计出错，制片无法排期 |
| 人物名大小写不一致 | 演员表混乱 |
| 动作行超过四行 | 变成叙述，节奏变慢 |
| 写了镜头指令 | 与分镜表冲突，导演无法工作 |
| 括号提示写成小作文 | 演员无所适从 |
| 没有页眉 | 打印出来无法排序、无法引用 |
| 场景编号不连续 | 通告单出错 |

## 十一、格式自检表

- [ ] 所有场景标题三要素齐全、全部大写
- [ ] 人物首次出场大写介绍
- [ ] 全篇页眉格式统一
- [ ] 动作行不超过三行一段
- [ ] 角色名顶格/缩进方式全篇一致
- [ ] 无镜头术语
- [ ] 括号提示简洁（≤ 6 字）
- [ ] 场景编号连续
- [ ] 结尾有「淡出：」
- [ ] 修订标记完整（若为修订稿）
