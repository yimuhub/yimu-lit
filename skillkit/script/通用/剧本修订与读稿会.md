# 剧本修订与读稿会

> 读稿会的价值不是「收集意见」，而是「用别人的耳朵发现自己在纸上听不见的问题」。修订要有顺序，否则越改越乱。

## 一、读稿会流程（60–90 分钟）

1. **静读**（15 分钟）：所有人先读完，不讨论。
2. **朗读**（30–40 分钟）：分角色朗读，作者不读自己的主角。
3. **事实问题**（10 分钟）：只问「这里谁在说话 / 他为什么去 / 时间过了多久」。
4. **体验反馈**（15 分钟）：哪里走神、哪里紧张、哪里不信。
5. **作者回应**（10 分钟）：只记录，不辩解。

**规则**：作者全程不解释剧本。需要解释的地方，就是剧本没写清的地方。

## 二、三类笔记分开记

| 类型 | 标记 | 处理 |
|---|---|---|
| **必须改** | A | 事实矛盾、人物动机断裂、格式错误 |
| **可以试** | B | 节奏、场景顺序、对白长度 |
| **个人偏好** | C | 口味、价值观、演员想象 |

修订时只处理 A，再挑 2–3 个 B 做实验；C 记录不执行。

## 三、修订顺序（不要跳步）

1. **结构**：幕点、场景顺序、删并场。
2. **场景**：目标/阻碍/结果是否成立。
3. **对白**：是否承担动作、是否有潜台词。
4. **动作行**：可视化、长度、现在时。
5. **格式**：场景头、场景号、页码、修订标记。

**结构没定之前不要润色对白**，否则会白改。

## 四、朗读测试

- 读起来打结的句子，演员也说不顺。
- 同一角色连续三段长台词 → 拆开或加反应。
- 两个角色声音太像 → 给其中一个换句长/口头禅/知识范围。
- 读稿时笑/走神/看手机的位置，都是节奏信号。

## 五、修订记录模板

```
版本：v3
范围：第 2 集
结构改动：合并场景 4/5；把中点提前到第 18 页
场景改动：场景 7 增加一个阻碍（保安巡查）
对白改动：删 12 行解释性台词
风险：中点提前可能让第二幕变短 → 已补一场对手戏
回归：朗读第 2 集，走神点从 3 处降到 1 处
```

## 六、自检表

- [ ] 读稿会是否先静读再讨论？
- [ ] 作者是否全程没有解释剧本？
- [ ] 笔记是否分成 A/B/C 三类？
- [ ] 是否先改结构，再改场景、对白、格式？
- [ ] 改完是否朗读一遍，确认顺口？
- [ ] 修订记录是否写清风险与回归结果？

## 七、反例

- ❌ 会上每个人提一条，作者全部照改，剧本变成拼盘。
- ❌ 先花三天润色对白，最后发现整场戏该删。
- ❌ 用「观众会不懂」为理由加旁白解释。
- ✅ 读稿发现第 18 页有人走神，回看是场景 6 重复交代信息，删掉后节奏恢复。
