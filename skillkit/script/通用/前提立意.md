# 前提 · 立意 · 戏核

> 一切从「一个能把人钉在座位上的问题」开始。没有前提的剧本只是事件排列。

---

## 一、前提是什么

**前提（Premise）= 一句能同时点燃冲突、定义主角、暗示结局的话。**

它不是主题，不是梗概，是**那个必须回答的问题**。

- 差：「一个警察为了正义与黑暗对抗」——这是题材，不是前提。
- 好：「一个警察必须在救他害死的女儿和救他效忠的部门之间选择。」

前提一旦成立，整部戏的**每一个选择**都会自动朝那个问题倾斜。

### 前提的三个必要条件

| 条件 | 说明 | 自检问法 |
|---|---|---|
| **有对立** | 至少两股力量互相排斥 | 主角不想要的那件事是什么？ |
| **有代价** | 赢的一方要付出东西 | 赢了会失去什么？ |
| **不可两全** | 存在真正的坏选项 | 有没有第三条路让两边都不痛？若有，前提就软了 |

### 五问检验（写前提前逐条回答）

1. **主角是谁？**（要具体的名字，不要「一个年轻人」）
2. **他想要什么？**（行动目标，可被观众衡量）
3. **谁挡着他？**（对手必须有和主角同等的欲望）
4. **他为什么现在必须行动？**（触发事件，不是背景）
5. **他最怕失去什么？**（这才是真正的赌注）

五问答不全，不要往下写。

## 二、主题与控制思想

**主题**是剧本探讨的问题：「人能不能赎罪」「忠诚是否值得」。

**控制思想（Controlling Idea）** 是主题 + 因果：
> 「如果一个人愿意付出 X，那么他就能得到 Y —— 或者失去 Z。」

没有因果的主题只是话题。举例：

| 话题（弱） | 控制思想（强） |
|---|---|
| 爱情 | 「如果一个人愿意先低头，他就能留住爱 —— 或者证明自己不值得被爱。」 |
| 正义 | 「如果一个人愿意放弃私利去追求公道，他就能赢得公正 —— 或者发现公正从未给他公正。」 |

控制思想是编剧的**判词**：每一个场景写完后回头问一句，这个场景是在支持还是在反驳这句话。

## 三、logline 的写法

**logline = 前提 + 触发 + 对手 + 赌注 + 结局方向**，一到两句。

结构模板：

```
当 [触发事件] 迫使 [主角] 必须 [行动目标]，
但 [对手] 想要 [相反的事]，
于是 [主角] 必须 [两难抉择]，
否则 [最坏后果]。
```

四个检验：

1. **不用人名也能懂**（说明冲突本身够强，不靠角色名撑）
2. **一句话说完**（说不清就是没想清）
3. **有动词**（静态名词不是故事）
4. **读起来有节奏**（念出声不拗口）

### 三版迭代法

写三遍，每遍只改一个变量：

1. **V1 事件版**：把事件串起来，不管好不好看
2. **V2 冲突版**：把对手换强，把赌注加大
3. **V3 主题版**：把 logline 的最后一句换成控制思想

V3 往往最弱也最真——因为这时候你在写命题，不是在写噱头。

## 四、戏核（中文语境的独立价值）

西方编剧体系里没有「戏核」这个明确位置，但它在中文创作实践中极其有效。

**戏核 = 一场戏的核心矛盾，用一句话说清，且必须能被演出来。**

- 差：「一个男人在社会压迫中挣扎」——抽象，不能演
- 好：「儿子必须亲手签下文件，把父亲送进监狱。」——一个动作，一次对抗

**戏核的四个检验：**

1. **可演**：能不能用两个演员在一个空间里演出来？不能就还不是戏核
2. **不可调和**：两个人的目标不能同时满足
3. **有代价**：输的一方要失去具体的东西
4. **有转向**：戏核里必须藏着一次反转的可能

一部戏可以有很多场戏，但**只能有一个戏核**。找不出唯一戏核，说明剧本还是散的。

## 五、选材与开掘

### 选材要严

判断一个素材值不值得写，问三句：

1. **有没有一个不写就难受的问题？**（有）
2. **这个问题能不能靠对话解决？**（能 → 适合剧本；不能 → 更适合小说）
3. **主角必须做出选择的时刻在哪？**（找得到 → 找到了戏核）

第 2 条是剧本与小说的分水岭：
- 小说可以用叙述绕过冲突
- **剧本必须让所有东西都在场上发生**

### 开掘要深

同一素材有三层：

| 层 | 例子 | 价值 |
|---|---|---|
| **事件层** | 一次车祸 | 低，谁都能写 |
| **关系层** | 车祸中父亲为救儿子受伤 | 中，有情感 |
| **命题层** | 父亲救儿子的瞬间，放弃了报复的机会 | 高，有主题 |

写剧本要往第三层走。**事件层是素材，命题层才是剧本。**

### 视角要新

同一件事换叙述者就换一个剧本。检查自己是否：

- 用了最「理所当然」的主角（警察、医生、老师）？
- 用了最常见的视点（全知、主角）？
- 把最戏剧性的时刻放在了开头？

如果答案都是「是」，换。

## 六、从想法到前提的工作流

```
1. 收集素材（任何形式：新闻、亲身经历、梦、他人故事）
2. 写一句话：这件事里最刺人的是什么
3. 找五问的答案（主角/想要/对手/触发/赌注）
4. 写 V1/V2/V3 三版 logline
5. 定控制思想
6. 提炼戏核（一句话，可演）
7. 验证：念给一个不懂剧本的人听，他能复述吗
```

第 7 步不能省。听不明白说明前提里塞了太多东西，或者用了行话。

## 七、常见反模式

| 反模式 | 症状 | 修法 |
|---|---|---|
| **前提写成了梗概** | logline 里全是「然后」 | 砍掉所有「然后」，只留一次抉择 |
| **主角没有对手** | 冲突来自外部（坏人/命运） | 给对手一个和主角同等正当的目标 |
| **主题是话题不是命题** | 「讲的是爱情」 | 加上因果和代价 |
| **戏核不可演** | 「他和自己和解」 | 换成具体动作 |
| **堆设定** | 花三页交代世界观 | 设定只从冲突需要处渗出 |

## 八、交付物

进入下一阶段（S1 人物网与季弧）前，必须有：

- [ ] **一句话 logline**（V3 版）
- [ ] **控制思想**（含因果与代价）
- [ ] **戏核一句话**（可演）
- [ ] **主角五问答案**
- [ ] **主角想要的 / 对手想要的 / 赌注** 三行对照
