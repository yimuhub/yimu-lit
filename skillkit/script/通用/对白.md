# 对白 · 潜台词 · 声音

> 对白是**行动**，不是信息传递工具。删掉所有台词，如果这场戏的意思还在，说明台词是多余的。

---

## 一、对白的本质

**对白是人物在特定处境下试图改变对方的行为。**

判断一句台词是否合格，问一句：
> 这句话让对方**做了什么**（或没做什么）？

- 「你在这儿干什么？」——问句没行动，是信息索取
- 「我数到三，你最好自己走出来。」——有行动预期

### 对白三原则

1. **对白即行动**：每句台词都是施动方的一次尝试
2. **对白有阻力**：顺畅的对话是失败的对话。有人在抵抗
3. **对白不是解释**：如果一个角色在说一段剧情背景，删掉它，让场景自己演

---

## 二、潜台词

**潜台词 = 台词字面意思之下的真实意图。**

| 潜台词 | 说出来的话 |
|---|---|
| 「我想要你留下」 | 「你外面那么冷，进来坐会儿吧。」 |
| 「我不信你」 | 「你今天怎么这么早就来了。」 |
| 「我在生气」 | 「谢谢你的提醒，我记下了。」 |
| 「我需要你」 | 「这个你拿着吧，我用不上。」 |

**写台词的方法：先写潜台词，再包装成字面。**

### 潜台词的三条纪律

1. **不解释潜台词**。观众要能自己听出来
2. **不给潜台词加旁白**。如果非解释不可，说明潜台词设计失败
3. **同一场戏里，潜台词方向要会变**。一直朝一个方向 = 单调

### 对手戏（重要手法）

让 A 说什么，B 就**不**接哪句：

> A：「你还在生我的气。」 ← 说「我没生气」
> B：「你从来不听我说话。」 ← 说「我听了」

一个否定，一个承认——两句台词的潜台词互相打架，戏就有了。

## 三、避免 exposition（说明性对白）

角色向另一个人解释观众已经知道的事，是最常见的剧本病。

### 四种消除方式

| 手法 | 说明 |
|---|---|
| **删掉** | 90% 的情况，删掉就行 |
| **改成动作** | 用行为代替解释（「你瘦了」→ 递上一件外套） |
| **改成争执** | 让信息在冲突中被说出来，而不是平静陈述 |
| **延后** | 留到它变成冲突的时候再说 |

### 例

> ❌ 「我父亲三年前去世了，那年我十八岁，所以我去学了医。」
> ✅ 桌上放着一张医院的实习合照。对方看了一眼：「你当医生是继承你爸？」
> ✅ 「不是。我只是没别的地方可去。」

## 四、节奏与密度

### 台词长度的黄金比例

一段正常对话中：
- **短句占多数**（60%+）
- 长句在**关键处**出现，制造重量
- 长句连续两句以上就是警报

### 信息密度

**每场戏的对白应该带走至少一样东西**：
- 一个新信息
- 一个态度转变
- 一个关系变化
- 一个决定

如果一场戏的对白拿走的是「原来如此」，这场戏可以压缩成三行。

### 台词长度的物理约束

- 中文对白：**一句不超过 30 字**（超过就该拆）
- 超过 40 字：必须拆成两句，或加动作

## 五、角色声音

### 每个人的语体特征

给每个主要角色定一套**可辨识的语言标记**：

| 维度 | 例子 |
|---|---|
| **句长** | 短促 / 冗长 |
| **词汇层级** | 书面 / 口语 / 方言 / 行话 |
| **句式** | 陈述 / 疑问 / 感叹 / 省略 |
| **口头禅** | 固定重复的词或句式 |
| **回避** | 他永远不说什么（比说什么更能辨识） |
| **节奏** | 打断 / 迟疑 / 抢话 / 沉默 |

**检验：把角色名遮住，读者能不能猜出是谁在说话？** 猜不出就是没有声音。

### 角色声音与情境的关系

同一个角色在不同处境下，声音会有偏移但不变质：
- 平时话少的人，在崩溃时会话多
- 平时话多的人，在关键时刻会沉默

**这个偏移本身就是戏。**

### 不要让角色「编剧腔」

反面症状：
- 角色说出主题句（"人就是这么 complicated 的"）
- 角色互相总结对方的心理
- 角色在争吵时变得逻辑清晰、条理分明
- 所有角色说话长度和节奏雷同

**争吵中的人不会说完整的句子。** 打断、重复、跑题、答非所问才是真实。

## 六、动作行（Action）

### 动作行的功能

1. **可见**：只写摄像机能拍到的
2. **必要**：只写推动戏或建立空间的
3. **简洁**：一段不超过四行

### 可见性检查

| ❌ 不可见 | ✅ 可见 |
|---|---|
| 他感到紧张 | 他把杯子放下的手在抖 |
| 她想起往事 | 她看着窗外，很久没说话 |
| 他很生气 | 他把门推开，没看对方 |
| 场面陷入僵局 | 两人都不说话。窗外车开过去 |

### 动作行的三种用法

1. **写行为**：可拍的动作
2. **写空间**：建立场景需要的一两句
3. **写转折**：动作改变场面

**不要写「他意识到…」** —— 意识不可见。

## 七、字幕与画外音

| 元素 | 用法 | 禁忌 |
|---|---|---|
| **SUPER（字幕）** | 时间地点、时代背景、关键说明 | 用来重复台词刚说过的事 |
| **VO（画外音）** | 内心独白、叙述、回忆 | 解释观众刚看到的 |
| **OS（画外）** | 同一场景的同期声 | 当解说用 |

**画外音是最容易偷懒的地方。** 先问：这场戏能不能全靠画面 + 台词完成？能就去掉 VO。

## 八、修订清单

- [ ] 遮住角色名，读者还能分辨说话人吗
- [ ] 每句台词都能说出施动方的意图吗
- [ ] 每场戏的潜台词方向有变化吗
- [ ] 有没有角色在解释观众已知的事
- [ ] 有没有角色说出主题句
- [ ] 争吵中的对白符合真实interrupt节奏吗
- [ ] 长句是否集中在关键处
- [ ] 动作行是否全部可见
- [ ] 画外音是否都可以删掉
- [ ] 台词总字数 ÷ 场景数，是否异常高（信息过载）

---

## 九、量化的粗检

写完一场戏后粗算：

```
台词字数 / 场景页数 ≈ 每页台词量
```

- 每页 15-25 字：正常
- 每页 30 字以上：**台词过密**，检查是否该删
- 每页 8 字以下：可能过于视觉化，缺少戏剧推动

这个数字只是警报器，不是标准。
