# 随笔 · 议论 · 说理

> 议论不是「讲道理」，是**让读者自己得出那个道理**。

---

## 一、随笔与论文的区别

| | 论文 | 随笔 |
|---|---|---|
| 目的 | 论证一个可检验的命题 | 表达一种看法的趣味与锋利 |
| 结构 | 严整（引言-方法-结果-讨论） | 松散有致（一个想法的展开） |
| 语气 | 克制、限定条件 | 有态度、有锋芒 |
| 读者 | 同行 | 愿意听一个人说话的人 |
| 引用 | 必引 | 少引，多用生活细节 |
| 结尾 | 结论与展望 | 一句更狠的话 |

**随笔的看家本领：一个具体的小切口。** 从一杯茶、一场雨、一个等电梯的瞬间，切进去，剖开一个更大的东西。

---

## 二、随笔的三种写法

### 1. 从小切口进入

```
一个具体的场景 / 物件 / 动作
   ↓
这个场景里的一个别扭或心动
   ↓
它连着一个更大的普遍问题
   ↓
在更大的层面继续推
   ↓
落回原来的小切口，但意思变了
```

**关键**：最后要**落回**。不落回就是没写完。

### 2. 从一个反常识的判断开始

```
「人都以为 X，其实 Y。」
  ↓
举 2-3 个例子支撑（例子要具体）
  ↓
处理最强的反驳
  ↓
把判断推到更狠的地方
```

**关键**：必须处理反驳。跳过反驳的随笔是「爽文」，不是好随笔。

### 3. 从一个词开始

从一个被误用的词、一个过时的词、一个新出现的词入手。
**词的历史里藏着社会的变化。**

## 三、议论的骨架

### 一个可用的论证结构

```
1. 主张（一句话，可被反驳）
2. 界定（这个主张在什么范围内成立）
3. 支撑（2-4 个具体证据 / 例子 / 观察）
4. 转折（最强的一条反驳 + 回应）
5. 限定（这个主张不适用于什么）
6. 落定（重新表述主张，比开头更狠或更深）
```

**第 4 步是随笔与论文的共同底线。** 没有反驳处理的议论是单向输出。

### 主张的四种类型

| 类型 | 例子 | 强度 |
|---|---|---|
| **描述性** | 「城市里孤独的人越来越多」 | 弱，需证据 |
| **因果性** | 「因为 XX，所以 YY」 | 中，需排除他因 |
| **规范性** | 「应该 XX」 | 强，需给理由 |
| **预测性** | 「接下来会 XX」 | 最强，最容易错 |

**写之前先确定你的主张是哪一类**，因为它决定了你要给多少证据。

---

## 四、举例的质量

### 好例子的四个条件

1. **具体**（有时间、地点、人物、数字）
2. **相关**（直接支撑那个论点，不是「相关话题」）
3. **出乎意料**（不是读者预想到的例证）
4. **有代价**（这个例子本身是有代价的，不轻松）

**「比如有个人……」是最弱的例子。** 「我一个朋友在 2019 年……」比它强十倍。

### 数量

**2-4 个例子。** 1 个太单薄，5 个以上读者会疲劳。
**每个例子的篇幅不超过一段。**

### 反例

**每个论证都要有一个反例。** 这是让读者信任你的最快方式——**主动说出你的主张在哪儿不成立**。

---

## 五、语气

### 随笔的锋利来自具体，不来自狠话

| 弱 | 强 |
|---|---|
| 「当今社会非常浮躁」 | 「我上个月在咖啡店坐了两小时，旁边四桌人在刷手机，没有一个人说话」 |
| 「我们要学会独立思考」 | 「我曾经花了三年想明白一件我母亲用一句话说清的事」 |
| 「这很离谱」 | 「他给这条狗办了个入学手续。」 |

**攻击对象要具体，攻击要有事实基础。** 否则就是「键盘侠式」的随笔，读者不会信。

### 自我暴露

**随笔的说服力有一半来自「我也在里面」。**

- 说自己犯过的错
- 说自己相信过但后来发现不对的东西
- 说自己也没想明白的地方

**不要滥用**（每篇都自嘲会变成表演），但完全不用会显得居高临下。

## 六、结构清单

写之前问：

- [ ] 主张是什么？一句话
- [ ] 切入口是什么？（一个具体场景 / 一个判断 / 一个词）
- [ ] 有什么具体例子？2-4 个
- [ ] 最强的反驳是什么？我怎么回？
- [ ] 主张在什么范围内不成立？
- [ ] 结尾落回哪里？比开头多说什么？
- [ ] 有没有一句「只有我能说」的话？（独特性）

最后一条如果答不上来，这篇随笔写出来就是任何人都能写的。

---

## 七、常见问题

| 问题 | 症状 | 修法 |
|---|---|---|
| **空洞深刻** | 结论很大，例子很虚 | 降一个量级，把结论落到具体 |
| **正确但无用** | 说的都对，但没信息 | 加一个只有内行才知道的细节 |
| **自嗨** | 只有作者自己看得懂 | 检查第二段能不能独立成文 |
| **没有反驳** | 顺着一口气说完 | 主动写「有人会说……但」 |
| **结尾重复开头** | 绕了一圈回到原点但意思没变 | 结尾要**改变**开头的意思 |
| **例子同质** | 三个例子都是同一类 | 至少一个反例，一个极端例 |

## 八、字数与节奏

- **随笔 800-2000 字**最舒服
- 段落 3-6 行，段间空一行（视觉节奏）
- 段首句是主张，段尾句是推进或转折
- **每 500 字要有一次「节奏变化」**：一个短句、一个转折、一个具体的物

**检验**：念出来。凡是连续三段长度和句式雷同，就要在那里插一句短的。
