# 增删与节奏

> 改稿的两个动作：删掉不承担功能的，补上读者需要的。节奏不是快，是该快的地方快、该停的地方停。

## 一、先删：五类必删

| 类型 | 例子 | 处理 |
|---|---|---|
| **重复信息** | 同一件事说了两遍 | 留更具体的那次 |
| **解释结论** | 「这说明他很孤独」 | 删，让细节自己说 |
| **万能形容词** | 美丽、动人、深深、无限 | 换具体或删 |
| **过渡套话** | 然而、总之、值得一提的是 | 删，靠内容衔接 |
| **无关风景** | 与主题无关的描写 | 删或压缩成一句 |

**删的标准**：删掉后，读者是否仍能理解并感受到？能，就删。

## 二、再增：四类必补

1. **场景锚点**：读者不知道「这是哪、什么时候」时，补一句。
2. **动作**：情绪停在抽象层时，补一个身体动作。
3. **反例/代价**：议论只有正面时，补一个反例或代价。
4. **过渡**：两段之间跳跃过大时，补一个物件/时间/问题衔接。

**增不是加字数**：增是补读者缺失的信息，不是补形容词。

## 三、句长节奏

```
短句（≤10 字）：加快、强调、收束
中句（11–25 字）：叙述主力
长句（26 字以上）：铺陈、压迫、回忆
```

- 连续三个长句，读者会喘不过气；插入一个短句。
- 连续五个短句，节奏会碎；合并成中句。
- 段落结尾用短句，收得硬。

## 四、段落节奏

| 段落类型 | 长度 | 作用 |
|---|---|---|
| 场景段 | 100–200 字 | 让读者看见 |
| 回忆段 | 150–300 字 | 提供背景 |
| 议论段 | 80–150 字 | 给出判断 |
| 过渡段 | 1–3 句 | 换时间/空间 |

**一段超过 400 字**，通常包含两个功能，应拆开。

## 五、朗读测试

- 读出声，打结处改句。
- 一口气读不完的句子，拆。
- 连续出现同一个词（「然后」「就是」「其实」），删或换。
- 读到想跳过的地方，就是该删的地方。

## 六、自检表

- [ ] 是否先删后增，而不是边删边加？
- [ ] 五类必删是否已清理？
- [ ] 四类必补是否已补？
- [ ] 句长是否有变化，没有连续三个长句？
- [ ] 每段是否 ≤400 字、只有一个功能？
- [ ] 朗读是否顺，有没有想跳过的段落？
- [ ] 删改后字数变化是否合理（通常净减 10–20%）？

## 七、反例

- ❌ 为了「丰富」给每段加形容词，越改越长。
- ❌ 把「然而」全删了，但段落之间没有替代衔接，读起来跳。
- ❌ 连续五个短句，像新闻标题。
- ✅ 删掉两段解释，补一个「他把碗放回柜子，柜门没关严」的动作，情绪反而更重。
