# 起草与细节密度

> 散文的空洞，通常不是句子不好，是「没有可验证的东西」。起草阶段先收集实质，再谈文采。

## 一、先素材，后句子

动笔前先列「可用素材」，每类至少一条：

```
场景：老屋的厨房，下午四点，光从西窗进来
物件：搪瓷盆、裂了口的碗、贴在墙上的挂历
动作：母亲把米淘三遍，用手背试水温
声音：楼下修车铺的气泵，每隔一会儿响一次
数字：1998 年、六楼、碗口缺了 2 厘米
一句话：她说「水凉了，饭就硬」
```

**没有素材就写，只能靠形容词撑**，读者一眼能看出来。

## 二、细节的三个标准

| 标准 | 说明 | 反例 |
|---|---|---|
| **可验证** | 能被看见/听见/数出来 | 「很旧」 |
| **有态度** | 细节透露叙述者的关注 | 「有一张桌子」 |
| **服务主题** | 与全文要说的东西有关 | 无关的风景描写 |

三条都满足的细节，一个顶十个。

## 三、密度：每 300 字一个锚点

- 叙事散文：每 300 字至少一个可验证细节（时间、地点、数量、身体感受）。
- 议论散文：每 300 字至少一个具体例子/数据/反例。
- 抒情散文：每 300 字至少一个物件或动作，不要连续抽象抒情超过 200 字。

**密度不是堆砌**：细节要选，不是把看到的都写进去。

## 四、缺口标记

没有事实时，不要用模糊表述填坑。用显式标记：

```
[待补：具体年份]
[待核：这个说法出自哪本书]
[待确认：母亲当时是否在场]
```

**缺口标记是专业性的体现**，不是缺陷。交付前统一搜索 `[待` 处理。

## 五、句子的起草纪律

1. 一句只做一件事；长句拆开。
2. 先写动词，再补修饰。
3. 少用「的」；连续三个「的」通常可以删一个。
4. 不写「我感到」；直接写身体反应或动作。
5. 每段开头不要都用「我」。

## 六、起草时的三个禁止

- 禁止边写边润色：先把意思写完整，润色留给 P 阶段。
- 禁止用总结句收尾每段：段末总结会让文章变成 PPT。
- 禁止为了抒情编造事实：宁可留缺口。

## 七、自检表

- [ ] 动笔前是否列了素材清单？
- [ ] 每 300 字是否有一个可验证细节？
- [ ] 细节是否满足「可验证/有态度/服务主题」三条？
- [ ] 没有事实的地方是否用了缺口标记？
- [ ] 是否有连续三个「的」的句子？
- [ ] 是否写了「我感到……」而不是动作？
- [ ] 是否边写边润色，导致进度停滞？

## 八、反例

- ❌ 「那是一个阳光明媚的下午，我回到了久违的故乡。」——全是套话。
- ❌ 「母亲很辛苦」——没有细节。
- ❌ 「据统计，大多数人都……」——没有来源。
- ✅ 「下午四点，光从西窗斜进来，照在搪瓷盆的缺口上。母亲淘了三遍米，用手背试水温。」——时间、物件、动作、数字都有。
