# 散文修订与定稿

> 修订是四遍不同的活，不要一遍干完。定稿是确认「每一句都有人负责」。

## 一、四遍法

| 遍次 | 只看什么 | 不看什么 |
|---|---|---|
| **第一遍：结构** | 段落顺序、功能、删并 | 句子 |
| **第二遍：事实** | 数字、时间、引文、地名 | 文采 |
| **第三遍：声音** | 句长、重复、语气、朗读 | 结构 |
| **第四遍：标点** | 标点、格式、错字 | 内容 |

**不要一遍改所有东西**：注意力会漏，改到第三遍时结构又变了。

## 二、第一遍：结构检查

- 每段功能能否一句话说清？
- 有没有可以合并/删除的段？
- 开头是否从具体处进入？
- 结尾是否落在具体上？
- 主推进力是否一致？

## 三、第二遍：事实核验

- 每个数字是否有来源？
- 时间线是否自洽（年龄、季节、先后）？
- 引文是否准确，是否标了出处？
- 地名、机构名、专业术语是否写对？
- 没有核实的地方是否保留缺口标记？

**宁可标「待核」，不要写一个看起来很确定的错数字。**

## 四、第三遍：声音检查

- 朗读一遍，标出打结处。
- 删重复词（然后、其实、就是、非常）。
- 检查句长变化，避免连续长句/短句。
- 检查语气是否统一（克制/热烈/冷静）。
- 删掉「我感到」「我觉得」开头的句子，改成动作。

## 五、第四遍：标点与格式

- 中文用全角标点；引号、书名号成对。
- 省略号用「……」，不用「...」。
- 数字用法统一（阿拉伯数字/汉字数字）。
- 段落首行是否缩进统一（按交付平台要求）。
- 标题层级、署名、日期齐全。

## 六、定稿清单

```
□ 结构：段落功能清晰，无冗余段
□ 事实：数字/时间/引文已核，缺口已处理
□ 声音：朗读顺，重复已删
□ 标点：全角、成对、统一
□ 标题：准确、有信息
□ 署名/日期：齐全
□ 改动说明：列出 3–5 条主要修改
```

## 七、改动说明模板

```
稿次：v3
主要修改：
1. 删除第 2 段解释性总结，改用母亲试水温的动作
2. 补 1998 年与六楼两个可验证细节
3. 结尾从抒情改为「柜门没关严」的动作
存疑：父亲当年的职务名称待核
```

## 八、自检表

- [ ] 是否按结构→事实→声音→标点四遍走？
- [ ] 每个数字/时间/引文都能追溯？
- [ ] 朗读是否顺，打结处已改？
- [ ] 标点是否全角、成对、统一？
- [ ] 标题、署名、日期是否齐全？
- [ ] 改动说明是否写清「改了什么、为什么」？
- [ ] 是否还有未处理的 `[待` 标记？

## 九、反例

- ❌ 一边改错字一边调结构，最后结构没改完，错字又漏了。
- ❌ 为了「严谨」把不确定的数字写成确定值。
- ❌ 定稿只检查错字，不朗读，句子打结。
- ✅ 四遍分开走，最后一遍只做标点与格式，交付时附 3 条改动说明。
