# 议论散文 · 随笔 · 书评

> 议论散文和议论文不同：论文要「无懈可击」，散文要「有我」。
> 议论文是说服，随笔是分享。读者在随笔里得到的不是结论，是「原来可以这样看」。

---

## 一、随笔 vs 论文

| | 论文 | 随笔 |
|---|---|---|
| 目标 | 证明/说服 | 分享/启发 |
| 立场 | 必须站住 | 可以留白 |
| 例子 | 数据、文献、严谨推理 | 个人、具体、意外 |
| 语言 | 准确、克制 | 鲜活、有个性 |
| 读者 | 检查者 | 同行、朋友 |

**判断你写的是哪种**：删掉第一人称还能不能读？能，多半偏论文。不能，是随笔。

---

## 二、论证骨架（6 步）

```
1. 主张     → 一句话说清「我认为 X」
2. 界定     → X 在这里指什么（范围、前提）
3. 支撑     → 具体例子 / 证据 / 亲历（≥2 条，且不重复）
4. 转折     → 最强的反方论点 + 为什么我仍如此（不假装不存在）
5. 限定     → 主张的边界在哪里（什么情况下不成立）
6. 落定     → 一句话收束，回应开头的问题
```

**最常见的失败**：只有 1→3→6，跳过了 4。没有「反方」的论证是单方陈述。

### 转折是加分项，不是负担

「最有力的一句话反驳」要**具体**。
> 弱：有人会说这不成立，但我认为……
> 强：最有力的反驳来自 X 本人——他承认 A，但坚持 B。我的看法是：B 只在 C 条件下成立。

---

## 三、例子的四条硬标准

| 条件 | 说明 |
|---|---|
| **具体** | 有姓名、日期、数字（「一位朋友」不行） |
| **相关** | 直接指向主张，不是背景装饰 |
| **出乎意料** | 读者没见过这个角度 |
| **有代价** | 用这个例子本身要付出什么（时间/钱/关系/机会） |

**四条少一条，例子的效力就少一截。**

**例子的反例也要给**：「如果只用这个例子，会漏掉什么」。
反例让论证从「我说的对」变成「我考虑过整个空间」。

---

## 四、议论散文的「我」

| 层次 | 做法 |
|---|---|
| 观点层 | 「我认为」是起点，不是终点 |
| 经验层 | 我见过什么、做过什么、失败过什么 |
| 情绪层 | 为什么这件事让我非说不可 |

**三层混合**才有个人语气。只有「我认为」是评论；加上后两层是随笔。

---

## 五、结构选择（二选一）

| 类型 | 适合 | 结构 |
|---|---|---|
| **辐射式** | 一个观点，多方向展开 | 中心论点 + 3-5 分论点，各带一个例子，收束 |
| **递进式** | 观点要一步步推 | 每段建立在前一段结论上，最后才到主张 |

**递进式比辐射式强**，但更难控制。

---

## 六、语言纪律

| 规则 | 原因 |
|---|---|
| 不用「显然/无疑/大家都知道」 | 读者会想：真的吗？我要被说服 |
| 数字要能查证 | 无法溯源的数字比不用数字更糟 |
| 引语保留原话 | 不改动，改动就标注「意译」 |
| 形容词克制 | 一个精准的形容词胜过三个模糊的 |
| 段落有观点句 | 每段开头那一句要说清这段在论证什么 |

---

## 七、书评 / 读后感专属

**书评不是内容复述。** 复述是「这本书说了什么」，书评是「这本书说了什么 + 我认为这对什么有/没有意义」。

**三条**：
1. 选**一个**你真正想讨论的问题（不是全书）
2. 给一个**你自己的反例**（证明你读过，且有判断）
3. 说清楚**这本书对谁有用，对谁没用**（限定，见骨架第 5 步）

**读后感**：重点放在「这件事在我身上」，不在书上。书是引子，不是主题。

---

## 八、Pre-flight（写完检查）

- [ ] 主张一句话说清，读者能在 30 秒内复述
- [ ] 支撑例子 ≥2 条，且不重复
- [ ] 有一个具体的反方论点
- [ ] 有反例（漏掉了什么）
- [ ] 例子的四条硬标准至少满足三条
- [ ] 没有「显然/无疑」类词
- [ ] 数字能溯源
- [ ] 限定写清（主张不成立的边界）
- [ ] 段落都有观点句
- [ ] 收束回应了开头的问题
