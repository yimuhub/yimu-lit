# 追读曲线 · 爽点类型学 · 卡点

> 读者弃书只有一个原因：**这一章没给他任何东西**。

---

## 一、追读曲线

### 追读 = 读者的「下一个问题」强度

**每章结尾必须留下一个读者会问的问题**，且这个问题要**具体到下一章开头就能回答**。

| 弱的钩子 | 强的钩子 |
|---|---|
| 「而这一切，才刚刚开始。」 | 「门开了。站在门口的是十年前失踪的那个人。」 |
| 「他不知道，更大的危险正在逼近。」 | 「他低头看表。表停了，指在三点十七分——正是三年前那场车祸的时刻。」 |
| 悬念（没说清是什么） | 悬念（明确但未解答） |

**区别**：弱钩子制造的是**模糊的不安**，强钩子制造的是**具体的疑问**。读者为疑问留下，不为不安留下。

### 章节的最小完整结构

```
本章目标（读者以为这章要干什么）
  ↓
推进（但遇到阻力）
  ↓
局部兑现（给读者一个小满足）—— 不要每章都省掉这个
  ↓
更大问题（把读者推向下一章）
```

**「局部兑现」是常被忽略的一环。** 只有问题没有兑现的章节，读者会累。

## 二、爽点类型学

**爽点不是「打脸」，是一切让读者情绪得到回报的设计。**

### 九种爽点

| 类型 | 读者得到什么 | 典型场景 |
|---|---|---|
| **认知爽** | 「原来如此」 | 谜底揭开、真相反转 |
| **尊严爽** | 「他被尊重了」 | 被轻视者展现实力 |
| **权力爽** | 「他能做到」 | 掌控局面、支配资源 |
| **复仇爽** | 「他被付出了代价」 | 加害者遭报应 |
| **情感爽** | 「我懂他」 | 人物弧光的完成、泪点 |
| **预期爽** | 「正如我所料」 | 布局生效、伏笔回收 |
| **共鸣爽** | 「这说的就是我」 | 说出读者心里的话 |
| **稀缺爽** | 「这是独属于主角的」 | 独有身份、独有能力 |
| **秩序爽** | 「坏人被制住」 | 正义执行、规则恢复 |

### 爽点的三要素

1. **铺垫**：读者要**先看到压制**（有多难、多被轻视）
2. **兑现**：压制被解除的瞬间要**具体、可感**
3. **余韵**：兑现之后要有一拍停顿，让读者回味

**跳过铺垫 = 打脸无感。** 读者没尝到苦，就尝不到甜。

### 爽点密度

**默认每章 ≥ 2 个爽点，每 1500 字约 1 个。** 题材可调（悬疑更靠认知爽，爽文更靠尊严爽/权力爽）。

**但爽点不能同质。** 连续三章都是「打脸」，读者会麻。**轮换类型。**

### 爽点的反模式

| 反模式 | 症状 | 修法 |
|---|---|---|
| **无压制的爽** | 主角一来就赢 | 加压制：阻力、误解、代价 |
| **重复爽** | 每章同一个套路 | 换爽点类型 |
| **廉价爽** | 靠对手降智 | 让对手的失败有他的理由 |
| **施舍爽** | 别人主动送上门 | 让主角自己去挣 |
| **数字爽** | 「众人震惊」代替具体反应 | 写一个具体的人的具体反应 |

## 三、卡点（章末留人的具体手法）

### 八种卡点手法

| 手法 | 说明 | 例 |
|---|---|---|
| **打断** | 动作被打断 | 「他刚要开门——」 |
| **揭晓** | 一个信息突然出现 | 门后站着的人 |
| **反转** | 刚建立的认知被推翻 | 盟友是幕后的人 |
| **逼近** | 危险在靠近 | 脚步声停在门外 |
| **抉择** | 逼主角做选择 | 只能救一个 |
| **倒计时** | 时间快到了 | 只剩十分钟 |
| **新问题** | 解决了旧的，冒出新的 | 找到钥匙，但门后是空的 |
| **沉默** | 什么都不说，但有异样 | 他没回答，只是把照片翻了过去 |

### 卡点的三条纪律

1. **卡点前要有一个「呼吸」**。让读者有半秒准备，卡点才有效
2. **卡点要具体**。「更大的危险」不行，「门后是他」才行
3. **卡点要兑现承诺**。上一章埋的东西，这一章至少推进一点

## 四、黄金三章（细化）

### 第 1 章：让人读下去

**必须完成**：
- 建立主角（姓名、身份、处境）
- 给出「金手指 / 特殊能力 / 特殊知识」或极强的困境
- 制造第一个具体的问题或期待
- 兑现一个小爽点（**很多新手第一章不兑现，这是最大的失误**）

**不该做**：大段世界观交代、人物介绍清单、慢热日常

### 第 2 章：让人相信
- 展示主角的能力边界（能做什么，不能做什么）
- 第一个真正的阻力出现
- 让读者看到「这个人不一样」

### 第 3 章：让人投入
- 第一个真正的**小高潮**（不是全书高潮，是第一个阶段性胜利）
- 第一个伏笔埋下
- 抛出更大的期待

**三章总字数：9000-12000 字**（3000-4000/章）。第一章可以短一点（2000-2500），第三章要够分量。

## 五、开篇类型（按题材选）

| 开篇类型 | 适合 | 特点 |
|---|---|---|
| **悬念前置** | 悬疑 | 第一段就抛谜 |
| **困境前置** | 爽文 | 第一段就濒死 / 被辱 |
| **日常切入** | 都市、情感 | 从一个具体场景进 |
| **身份反差** | 扮猪吃虎 | 平凡外表下的异常 |
| **倒叙** | 悬疑、复仇 | 从结果倒推 |
| **重逢** | 情感、年代 | 久别重逢的第一句话 |

**别用「主角起床 → 刷牙 → 上学」这种开篇。** 从**他人生中正在发生的那件事**开始。

## 六、章节结构模板

```
【本章目标】主角这一章要达成什么
【阻力】谁 / 什么挡着
【推进】具体经过（要有具体场景，不是概述）
【节拍】3-5 次小翻转
【局部兑现】读者这一章得到了什么
【章末卡点】具体的问题
【状态变更】这一章之后，什么变了（人物关系/信息/资源/处境）
```

写完后检查：**状态变更这一栏能不能填出来。** 填不出来说明这章白写了。

## 七、自检表

- [ ] 每章结尾有一个**具体**的疑问，不是模糊的不安
- [ ] 每章都有局部兑现
- [ ] 爽点密度达标（≥2/章，≥1/1500 字）
- [ ] 爽点类型不连续重复三次
- [ ] 每个爽点前有压制铺垫
- [ ] 爽点兑现有具体反应（不是「众人震惊」）
- [ ] 卡点前有呼吸
- [ ] 黄金三章：第 1 章有兑现，第 3 章有小高潮
- [ ] 每章能写出「状态变更」
- [ ] 第一章没有大段设定交代
