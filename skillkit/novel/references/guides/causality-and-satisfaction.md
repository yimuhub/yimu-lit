# 因果链与爽点纪律 · 每章写作时对照（原创）

## 一、因果链（情节的唯一合法推动方式）

> 因为【前因】→ 主角做出【选择】→ 导致【直接结果】→ 结果造成【新问题/代价】→ 迫使主角【下一步行动】。

删除检验：一个情节删掉后，若不影响后续任何事件、人物关系、认知或主题，它就是无效情节——删掉或换成有因果的。

**六条低质量推动方式，发现即重写**：
1. 角色突然变蠢，只为衬托主角聪明。
2. 关键人物突然失忆/失联/改变原则。
3. 重要证据恰好掉到主角脚下。
4. 反派连续犯低级错误，且无人利用其真实能力。
5. 规则在需要时才出现，事后也不解释。
6. 主角凭空获得恰好解决当前困境的能力。

## 二、爽点五条件（不是主角永远赢）

爽点 = 压抑后的释放、努力后的回报、认知差的兑现、关系的情感回报、代价后的成长。

每个重要爽点过五条：
1. 之前存在明确的期待或压抑；
2. 主角的行动对结果有实质贡献（不是天降）；
3. 结果不是无成本的随机馈赠；
4. 兑现后局势/关系/认知发生变化；
5. 下一阶段给出新问题，而不是重复同一场打脸。

九类爽点轮换着用：逆袭 / 破局 / 认知差 / 成长 / 反击 / 守护 / 关系兑现 / 智力胜利 / 价值抉择。

## 三、情绪节奏（不许全书一个强度）

- 高强度冲突后安排回落章，但回落章也必须供给人物/关系/世界信息；
- 牺牲必须有铺垫、有选择、有后果，不当催泪按钮；
- 幽默来自性格与处境反差，不破坏重大场景的重量；
- 悲伤要写出失去的具体对象与不可替代性，不靠人物哭+作者解释。

## 四、单章任务底线（七选一即合格，尽量多条）

推进主线事件 / 改变人物关系 / 揭示有效新信息 / 兑现一个承诺 / 主角作出重要选择 / 改变资源·风险·局势 / 加深对人物或主题的理解。

一章只是重述上章、重复同一情绪、重复讲解已知设定 → 删掉、合并或重写。
