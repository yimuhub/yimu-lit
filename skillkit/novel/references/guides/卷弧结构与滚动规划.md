# 卷弧结构与滚动规划

> 长篇写崩，九成不是文笔问题，是"规划粒度"错了：要么全书一次规划到底（写到一半发现前面立不住，推翻重来），
> 要么完全没有卷的概念（一百万字 flat 推进，读者感觉"一直在走，从没到过"）。

## 一、卷是长篇的基本单位

卷同时承担三个功能，缺一个就会出问题：

| 功能 | 具体含义 | 缺失后果 |
| --- | --- | --- |
| 节奏单位 | 一卷 = 一个完整的"起—承—转—合" | 全书一个节奏，中段必塌 |
| 商业单位 | 读者在卷末做"要不要继续追"的决定 | 卷末没有兑现，掉收 |
| 认知单位 | 一卷给读者一个可记住的"这段讲什么" | 读者说不清书在讲什么 |

**卷长参考**（按平台/品类浮动，不是硬指标）：

- 男频爽文 / 玄幻：20–40 万字一卷，40–120 章
- 女频言情 / 古言：8–20 万字一卷，30–70 章
- 悬疑 / 推理：12–25 万字一卷（一卷至少闭合一个案件）
- 短了铺不开主冲突，长了读者疲劳。低于 6 万字"卷感"不成立，超过 50 万字必须拆。

## 二、卷弧四段（每卷都要走一遍）

1. **入卷（前 10%）**：给出"新常态"，并埋下本卷主冲突的引信。
   - 新常态必须和上一卷末不同（地位/地图/关系至少变一项），否则读者觉得没推进。
   - 引信要具体：不是"似乎有危险"，而是"某人/某物已经动了"。
2. **铺开（10%–45%）**：主冲突明确化，赌注逐级抬升。
   - 至少三次"尝试—受阻"，每次受阻原因不同（不能都是"打不过"）。
   - 这一段最容易水，判断标准：**删掉任意 3 章，主线是否受损？不受损就是水。**
3. **中点翻盘（45%–55%）**：主角的认知或处境发生反转。
   - 优先做"认知反转"（原来敌人是自己人 / 原来目标搞错了），其次才是"实力反转"。
   - 反转必须由前文已给的信息支撑，不能靠新角色空降解释。
4. **卷末（最后 15%）**：兑现本卷承诺 + 埋下一卷引信。
   - 兑现要"看得见"：击败/获得/揭晓，三选一必须有。
   - 引信必须是**更高层级**的威胁，不是同层级换个人再来一遍。

## 三、滚动规划：只拆到下一卷

全书**只锁三样东西**，其余全部留白：

1. 终点（结局画面，一句话）
2. 三个必经里程碑（大约 1/4、1/2、3/4 处各一个，各一句话）
3. 主角的弧光终点（他从什么样的人变成什么样的人）

**粒度纪律**：

- 当前卷：拆到**章**（每章一句话目标 + 章末钩子）
- 下一卷：拆到**卷级 beat**（四段各写 2–3 条）
- 更远的卷：只有一句话

**为什么不能一次规划到底**：读者反馈、平台数据、角色在写作中"长出来"的性格，都会改变后续走向。
一次规划到底的结果不是"有远见"，是"写到 40 万字时必须推翻 60 万字的计划"。

**补卷时机**：当前卷写到 **70%** 时，把下一卷从 beat 拆到章。早了浪费，晚了断更。

## 四、卷内节奏表

| 位置 | 该发生什么 |
| --- | --- |
| 每 5–8 章 | 一个小高潮（一次交手/一次揭露/一次关系推进） |
| 每 20–25 章 | 一个中高潮（阶段目标达成或失败） |
| 卷末前 3 章 | 连续加压，不留喘息章 |
| 卷末章 | 兑现 + 引信，双落点 |

连续两章没有"变化"（信息/关系/处境至少变一项），就是节奏坏了。

## 五、自检清单（每卷开写前过一遍）

- [ ] 本卷主冲突一句话能说清吗？
- [ ] 它和全书主线是什么关系？（无关 = 注水卷）
- [ ] 卷末兑现的是什么？读者能复述吗？
- [ ] 下一卷的引信比本卷威胁高一层吗？
- [ ] 中点反转用的信息，前文真的给过吗？
- [ ] 本卷有没有"删掉也不影响"的连续三章？

## 六、常见崩法

- **卷内目标与全书目标脱节**：打了 30 万字怪，主线复仇一步没动。修法：每卷至少推进主线一个必要条件。
- **卷末不兑现，只留钩子**：读者连续两卷"什么都没得到"，第三卷必弃。修法：兑现和引信必须同时给。
- **同层级循环**：换地图、换对手、套路完全一样。修法：每卷换一个"取胜方式"（这卷靠武力，下卷必须靠别的）。
- **规划过细导致僵硬**：连第 80 章的对话都写死了，角色一"活"就冲突。修法：只锁里程碑，中间留活口。

## 附：分卷设计九项（v4.25.0，每卷开卷前逐项过）

每卷至少明确，缺项先补规划再动笔：
1. 本卷核心命题/主要冲突；2. 主角本卷目标；3. 主要对手及其目标；
4. 本卷新规则/新场景/新关系；5. 三个以上关键事件节点；
6. 主角本卷得到什么、失去什么、改变什么；7. 本卷解决什么问题；
8. 本卷留下什么新问题（下一卷入口）；9. 本卷如何服务全书结局。

## 附：中期防疲劳七问（每卷过半自查一次）

1. 是否在重复前期成功的模式？2. 主角只变强，没有变成熟或改变价值选择？
3. 配角是否失去独立目标？4. 新地图/新势力是否只是换皮？
5. 核心谜团是否一直不兑现？6. 支线是否挤压主线？
7. 是否用回忆/卷宗/旁白/设定说明代替正在发生的戏？

中期升级要换冲突维度：个人生存→责任选择、力量竞争→制度冲突、解谜→价值判断、私人关系→群体命运。
