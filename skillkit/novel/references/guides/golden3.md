# 黄金三章门（原创）

> 网文排行第一道生死关：前 3 章决定推荐量/追读。写/改前 3 章必须逐项过门。

## 第 1 章（立）
- [ ] **300 字内出钩子**：开篇即冲突/悬念/异常，不铺垫背景。
- [ ] 主角 + 核心设定在 1-2 段内亮明（读者知道"看谁、为啥看"）。
- [ ] 第一个爽点/情绪点在前 1/3。
- [ ] 章末钩子（追读）。

## 第 2 章（拉）
- [ ] 冲突升级或第二个爽点；不重复第 1 章信息。
- [ ] 立住"期待"：读者清楚这本书在攒什么大招。
- [ ] 章末钩子更紧。

## 第 3 章（锁）
- [ ] 兑现一次"小爽"（打脸/破局/揭示一角），让读者尝到甜头。
- [ ] 抛出主线总悬念（贯穿全书的核心问题），读者决定追下去。
- [ ] 前 3 章合计 ≥3 个爽点；无注水；人物已分声。

## 付费/免费差异（全平台通配默认取较严）
- 起点（付费）：第 3 章末设首个"付费卡点"前奏。
- 番茄/七猫（免费）：爽点密度拉满，第 1-3 章"三章一个小高潮"。
默认同时满足两者：第 3 章既有爽点兑现、又埋付费点。
