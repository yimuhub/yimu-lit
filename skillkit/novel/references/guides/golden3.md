# 黄金三章门（写/改前 3 章必须逐项过门）

## 核心数据（硬指标）
- 前 200 字主角出现并做出第一个可见行动。
- 前 300 字给出 钩子（反常/落差/危险/利益/误会 至少其一）。
- 800 字内触发核心冲突；第一章场景 ≤2 个、互动人物 ≤3 个。
- 第 3 章末合计 ≥3 个爽点；无注水；人物已分声。

## 第 1 章（立）：让落差被看见
新手错误是堆冲突——陌生人被刀架脖子没人关心。有效的是情绪落差：
- **锚点**：主角坠落前的最高光（一个具体画面）。
- **现状**：坠落后的最低谷（一个具体画面）。
- **对比触发器**：锚点与现状在同一场里正面碰撞，读者自己得出"他不该如此"。
冲突让人紧张，情绪落差让人放不下。

## 第 2 章（拉）：给读者特权信息
第二章的任务不是拉仇恨，而是制造"读者知道、剧中人不知道"的信息差：
- 身份特权（真实身份）、未来特权（即将发生）、能力特权（金手指暗涨）、视角特权（反派密谋）。
- 必须在一个具体事件中展示，不做旁白介绍；金手指通过行动效果亮相，不摆属性面板。

## 第 3 章（锁）：还小账，立新标
前两章憋的情绪要在第三章还一笔小账，然后立刻划新期待线：
- 还小账三式：力量验证（金手指干成一件小事）/ 预判兑现（铺垫冲突首次回应）/ 选择宣示（主角主动做决定）。
- 立新标三式：时间标（"三年之约"）/ 对手标（亮出更高级的敌人）/ 悬念标（主线总问题浮出）。
- 严禁第三章开始铺世界观、拉势力网——读者等着的是兑现，不是信息。

## 付费/免费差异（默认取严）
- 起点（付费）：第 3 章末设首个付费卡点前奏。
- 番茄/七猫（免费）：爽点密度拉满，三章一个小高潮。
默认同时满足：第 3 章既有爽点兑现、又埋付费点。

## 反模式自检
- [ ] 第 1 章是否先铺世界观/履历/体系名词？（砍掉，直接进冲突）
- [ ] 主角是否"只是惨"而没有"曾经拥有"？（补锚点）
- [ ] 前 3 章是否只有主角在受苦、没有任何兑现？（补还小账）
- [ ] 是否连续三章用同一种断章钩子？（换类型：危机/谜题/情感/反转/抉择）
