# 三轮编辑与章节五项快评 · 审校/质检阶段工具（原创）

## 一、三轮编辑法（按顺序，先结构后句子）

**第一轮 · 结构编辑**（先修结构，绝不先润色句子）：
因果是否成立 / 节奏是否失衡 / 冲突是否具体 / 人物动机是否成立 / 设定是否一致 / 本章任务是否完成。

**第二轮 · 商业阅读编辑**：
开篇是否快速进入场景 / 理解门槛是否过高 / 信息分配是否合理 / 本章给读者的回报是什么 / 情绪曲线是否有起伏 / 结尾期待是否成立。

**第三轮 · 语言编辑**：
删冗余 / 减重复 / 调句式节奏 / 区分人物声音。禁止为"文采"把清楚的句子改晦涩。

## 二、章节五项快评（每项 0-2 分，总分 10，诊断用）

1. 本章任务是否清楚？（知道这章在干嘛）
2. 是否有真实事件变化？（局势/关系/认知至少一项变了）
3. 主角是否有主动行动或有效反应？
4. 是否给读者提供情绪/信息/情节回报？
5. 结尾是否自然引出下一步？

低于 7 分：检查是否需要合并、删减或重写。日常过渡章、情绪章有不同功能，不用刺激程度一刀切。

## 三、交付前硬检查（发现硬伤先修复再交付）

- **故事**：主角当下目标清楚？冲突具体？事件由选择与前因推动？核心设定影响情节？
- **人物**：言行符合已建立性格与知情范围？主角有主动性？对手有合理目标？配角有独立价值？
- **连续性**：时间/地点/年龄/身份/伤势/物品/资源一致？人物不知道不该知道的信息？伏笔未遗忘未提前泄露？
- **阅读体验**：开头尽快进场景？无无效重复？无过度解释与模板化动作？对话有目的？章末不断章？
- **合规原创**：无近似照搬表达或桥段？专业知识不写成确定事实？

硬伤（逻辑、一致性、原创性、合规）不许用"文风润色"掩盖。
