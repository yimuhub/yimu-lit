# 书名 · 简介 · 标签

> 书名和简介是**唯一被读者看到两次的东西**。正文写砸了没人读，但书名能救。

---

## 一、书名的四种有效结构

| 结构 | 说明 | 例子方向 |
|---|---|---|
| **身份反差** | 平凡身份 + 异常处境 | 《退役特种兵开三家小店》 |
| **能力承诺** | 直接给出主角的特殊能力 | 《我能看见万物提示》 |
| **困境悬念** | 抛出一个没解开的难题 | 《失踪的第 37 天》 |
| **情绪承诺** | 直接给出阅读快感 | 《重生后我不再讨好所有人》 |

### 三个必须满足的条件

1. **一眼能懂**：不解释就懂在讲什么
2. **有具体信息**：不含「精彩」「绝伦」「史上最强」这类空词
3. **能被记住**：读一遍能复述出来

### 常见的坏书名

| 坏 | 为什么坏 |
|---|---|
| 《都市修仙传》 | 无信息，任何一本都能用 |
| 《惊世骇俗的修仙之旅》 | 空词堆砌 |
| 《剑道》 | 太泛，没有钩子 |
| 《我的老婆是女帝》 | 只有设定，没有困境或悬念 |
| 《第 108 章 血战》 | 章节名不是书名 |

### 长度

**6-14 字最佳。** 超过 16 字在手机上会截断。
**不要用标点分隔符**（《XXX：XXX》），除非两部分都极强。

---

## 二、简介的三段结构

```
第一段：一句话钩子（主角 + 困境 + 反常）
第二段：展开（他能做什么 / 遇到什么 / 为什么会这样）
第三段：承诺（读者会得到的爽点或悬念）
```

### 硬规则

- **150-250 字**
- **第一行必须是最强的那个信息**（很多平台只显示前两行）
- **不要剧透关键反转**
- **不要写「本书讲述了一个……的故事」这种废话开场**
- **要有具体的名词**：具体的身份、具体的能力、具体的困境

### 反例与正例

> ❌ 本书讲述了一个普通青年在获得神秘力量后成长并守护爱人的故事，感情丰富，情节曲折。
>
> ✅ 沈昭在殡仪馆化妆十三年，某天接了一具不该接的尸体——
> 死者三天前刚办过自己的葬礼。
> 他决定查下去，然后发现自己家三代人的死，都写在这本工作簿上。

**区别**：正例有**具体名词**、**具体异常**、**具体钩子**。

---

## 三、标签

**标签是给算法的，也是给读者的。**

**3-5 个**，从这几类里选：
- 题材（都市 / 玄幻 / 悬疑 / 历史 / 科幻）
- 风格（爽文 / 慢热 / 轻松 / 沉重）
- 卖点（金手指 / 升级流 / 反转 / 群像 / 无系统）
- 人群（男性向 / 女性向 / 职场）

**不要标你不写的东西。** 标错会招来错读者，差评率上去后很难翻身。

---

## 四、多书名方案（给用户选）

生成 8 个书名 + 简介，**风格要分散**：

| # | 风格 | 侧重 |
|---|---|---|
| 1 | 悬念向 | 抛问题 |
| 2 | 爽感向 | 给承诺 |
| 3 | 人设向 | 打反差 |
| 4 | 文艺向 | 有意象 |
| 5 | 简洁向 | 只有核心词 |
| 6 | 数字向 | 有具体数字 |
| 7 | 对话向 | 用一句台词 |
| 8 | 组合向 | 混合结构 |

每个书名后面附一行「为什么用这个」——让用户知道每个名字的赌注在哪。
