# 推理 / 悬疑（原创）

## 公平游戏（Fair Play）
给读者的线索 **≥** 给角色的：每个关键反转都要"读者本可以推出来"（证据已给）。埋线在 `clue-ledger` 标"可推理证据"。

## 结构与爽点
- 爽点 = **揭示/反转/推理成功**，不是打脸。节奏靠"小谜团回收 + 大谜团推进"。
- 误导要"公平"（给错方向，但线索真实存在，读者回头看能懂）。

## 黄金三章专属
- 第 1 章：异象/尸体/消失，300 字内给"不对劲"，立主角与动机。
- 第 2 章：第一层调查，排除一个明显嫌疑（反打）。
- 第 3 章：揭示一角 + 抛出总谜团（核心问题），读者追下去。

## 常见坑
- 反转靠"天降信息/降智"（违反公平）；谜底提前露；角色全知全盲乱跳；误导没证据（纯忽悠）。
