# 历史 · 架空历史

> 历史文的读者要的不是还原，是**「在那个约束下，普通人怎么办」**。

---

## 一、两种历史文

| | 历史文 | 架空历史 |
|---|---|---|
| 基础 | 真实史实 + 真实制度 | 真实制度逻辑 + 改动关键事件 |
| 自由度 | 低 | 中高 |
| 爽点来源 | 知识差、预知 | 改变命运、改写大事件 |
| 风险 | 常识错误 | 制度逻辑崩 |

**架空不等于随便。** 架空世界的**制度、逻辑、代价**必须自洽。

---

## 二、真实的约束感

**历史感不来自考据，来自「当时的一个人能做什么、不能做什么」。**

### 三个维度的约束

| 维度 | 问题 |
|---|---|
| **制度** | 官制、税制、军制、法律、科举怎么运作 |
| **技术** | 交通、通信、照明、货币、兵器、 medicine 到什么水平 |
| **观念** | 什么被允许，什么被禁止，人们怎么想 |

### 每个场景要过的三问

1. **这个人在这套制度下的位置是什么？**
2. **他手里的资源够办成这件事吗？**
3. **他这么做，别人会怎么反应？**

**第 3 问最常被忽略。** 历史里的行动都有反应链。

---

## 三、真实感的建立方式

### 五个具体做法

1. **用当时的词**：不要用现代抽象词。「格局」「思维」「效率」在宋代没有
2. **用当时的计量**：一斗、一贯、一里、一更。用「三十两」比「一笔钱」真实十倍
3. **用当时的流程**：递帖子要写递帖子，不能直接找领导
4. **用当时的麻烦**：真写一份奏章很麻烦——这份麻烦本身就是内容
5. **用当时的常识**：主角不该惊讶于当时人尽皆知的事

### 例

> ❌ 他意识到，推行新政必须得到皇帝的支持，否则就会前功尽弃。
>
> ✅ 狄仁杰把拟好的两道诏书对放在案上，一道走中书省，一道走门下省。
> 走中书省要二十日，走门下省只要三日——但门下省会把「免租」改成「减租」。

**「减租」两个字就是全部的历史感。**

## 四、爽点设计

### 历史文的核心爽点

| 类型 | 说明 |
|---|---|
| **先知差** | 知道未来会发生什么，布局等待 |
| **技术差** | 用当时可行的方法做出超常结果 |
| **制度差** | 知道制度的漏洞或缝隙 |
| **信息差** | 知道别人不知道的事（密报、驿传、账目） |
| **人心差** | 看透各方利益与立场 |

### 架空历史的额外爽点

**改变大事件**（救下一个人、改变一场战役的结果、提前一项技术）。
**但代价必须更重**——蝴蝶效应是真的，读者要看到代价。

---

## 五、常见错误

| 错误 | 症状 | 修法 |
|---|---|---|
| **现代思维穿越古代** | 主角张口「效率」「品牌」 | 换成当时的表达方式 |
| **制度是摆设** | 主角一句话就改了律法 | 写清流程要经过谁、付出什么 |
| **配角集体降智** | 所有古代人都比不上主角 | 给每个重要配角合理的判断 |
| **无代价改史** | 改了历史什么也没发生 | 写清连锁反应 |
| **术语堆砌** | 满篇生僻官名 | 只保留反复出现的，其余白话 |
| **时代错位** | 出现后来的技术或观念 | 建一张「当时没有什么」的清单 |

---

## 六、开篇建议

**历史文的黄金三章要完成**：
1. 立刻落到一个具体的、有时限的问题
2. 让读者知道「这个人处在什么位置上」
3. 第一个小兑现（主角用制度/信息/技术优势解决一个小麻烦）

**不要**用大段朝代背景开篇。

---

## 七、自检表

- [ ] 主角的制度位置清晰
- [ ] 用了当时的词、计量、流程
- [ ] 每场戏想过「别人会怎么反应」
- [ ] 配角有合理判断，不降智
- [ ] 改史有连锁代价
- [ ] 无现代抽象词穿越
- [ ] 有「当时没有什么」的清单
- [ ] 黄金三章有具体时限问题和小兑现
