# 题材 craft · 总则（全平台通配默认）

> 题材未指定时用它。默认**兼顾起点（付费：黄金三章+付费点）与番茄/七猫（免费：爽点密度+追读）**，参数取两者较严。

## 通用节奏参数
- 单章 2000-4000 字；每章末必钩。
- 爽点密度：每章 ≥2、每 1500 字约 1 个。
- 前 3 章：小高潮 ×3，第 3 章末埋付费点前奏。
- 卡点常放第 6-8 章（最想知道答案处）。

## 情绪主副
- 主情绪（爽/燃/虐/暖/恐 之一）+ 副情绪。全篇别换主情绪。

## 选题材套
- 推理 → `mystery.md`（公平游戏）
- 言情 → `romance.md`（节拍）
- 恐怖 → `horror.md`
- 都市爽文 → `urban.md`
- 玄幻仙侠 → `xuanhuan.md`
- 历史/架空 → `历史.md`（制度三问：制度/技术/观念）
- 科幻/硬科幻/末世 → `科幻.md`（推演三问，末世的代价）
- 仙侠/修真/东方玄幻 → `仙侠.md`（三柱：道、人、旅途）
- 职场/商战/都市异能 → `职场.md`（业务层、权力三权）
- 军事/战争/谍战 → `军事.md`（战术可信度、信息三层分离）

## 通用节奏参数（补充）
- 追读曲线与爽点 → `../guides/追读曲线与爽点.md`（九种爽点、八种卡点、黄金三章细化）
- 书名/简介/标签 → `../guides/书名与简介.md`（8 个候选风格分散）
