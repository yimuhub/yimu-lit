# 职场 · 商战 · 都市异能

> 职场小说的读者代入的是**「我遇到过这种事」**。所以每场戏都要能对应到真实的工作场景。

---

## 一、职场文的三层

| 层 | 内容 | 失败表现 |
|---|---|---|
| **业务层** | 真实业务、真实流程、真实术语 | 女主随口一句「我们把产品推向市场」，读者出戏 |
| **博弈层** | 人与人之间的利益与站位 | 老板是好人/坏人的二元设定 |
| **情绪层** | 职场的委屈、代偿、自我证明 | 只有爽没有痛 |

**三层都要有，业务层是地基。**

---

## 二、业务层：写对才算可信

### 必写的具体流程

| 环节 | 具体内容 |
|---|---|
| **立项** | 谁提的、预算多少、考核指标是什么 |
| **排期** | 里程碑、交付物、谁做哪块 |
| **执行** | 需求变更怎么发生、怎么被挡回去 |
| **验收** | 谁签字、卡在哪个标准 |
| **复盘** | 出问题怎么归因、怎么向上汇报 |
| **人事** | 招聘、绩效面谈、裁员名单 |

**最容易被跳过的是「验收」和「复盘」。** 恰恰是这两步让职场真实。

### 术语纪律

**用行业里真的存在的词。** 写互联网就用「对齐」「拉通」「赋能」这类真实黑话（并让它们带贬义）；写咨询就用「客单价」「交付」「复用素材」。

**不要用错位术语。** 程序员不会说「这个方案很有诚意」。

**一次最多三个术语**，其余用白话。

---

## 三、博弈层：权力的真实形态

### 办公室权力不是职位，是三样东西

| 权力 | 是什么 | 怎么用 |
|---|---|---|
| **决策权** | 谁能拍板 | 拍板的人不一定想要 |
| **信息权** | 谁知道什么 | 关键信息延迟送达 |
| **定义权** | 谁能定义「做得好」 | 改了标准，你就成了差的 |

**第三样最狠。** 上司不批评你，只是换了一把尺子。

### 冲突的四个来源

1. **资源冲突**（预算、人手、名额）—— 最硬
2. **责任冲突**（出事谁背）—— 最常见
3. **评价冲突**（谁定义成功）—— 最隐蔽
4. **位置冲突**（空降、嫡系、资历）—— 最情绪化

**职场戏要有「实际利益」**。只争一口气的戏撑不过两章。

---

## 四、情绪层：职场的痛点

| 痛点 | 真实表现 |
|---|---|
| **功劳被抢** | 汇报时你的名字消失了 |
| **背锅** | 邮件抄送了很多人，只有你没退路 |
| **不被看见** | 做了很多，没人在意 |
| **不得不低头** | 你知道他说得不对，但他说得对老板 |
| **加班无用** | 熬到凌晨，需求第二天改了 |
| **体面离开** | 走得很难看，但还是要走 |

**「不得不低头」写得最准的时候，是读者在痛。**

### 主角的成长不是「变强」，是「选择变多」

| 阶段 | 状态 |
|---|---|
| 一 | 只能忍，为了活下去 |
| 二 | 学会周旋，学会说话 |
| 三 | 有了底气，可以说不 |
| 四 | 自己定规则 |

**很多职场文停在第二层。** 爽感来自第三层开始。

---

## 五、爽点设计

| 爽点 | 条件 |
|---|---|
| **打脸** | 前面有明确轻视，且打脸有实际后果（不只口头） |
| **反杀** | 被算计后用对方的规则赢回去 |
| **被看见** | 关键决策被采纳，最好是上司当众说 |
| **止损** | 避免了一个大坑，读者替主角松口气 |
| **翻身** | 拿到了具体的东西（位置、项目、钱） |

**打脸后必须有实际收益**，否则读者的爽是空的。升职、涨薪、拿到项目权，至少给一个。

---

## 六、常见错误

| 错误 | 症状 | 修法 |
|---|---|---|
| **业务悬浮** | 一句话带过整个项目 | 写流程、节点、卡点 |
| **老板脸谱化** | 恶霸老板 / 圣母老板 | 给老板自己的指标和压力 |
| **反派无能** | 靠巧合赢 | 让对手也有信息、有动作 |
| **爽点无代价** | 主角一句话解决所有事 | 给阻力、给妥协 |
| **术语错位** | 行业词乱用 | 查真实术语，或换行业 |
| **加班即敬业** | 熬夜被当美德 | 写无效劳动的荒诞 |
| **人设靠事件** | 只说「他很拼」 | 用选择和取舍显出性格 |

## 七、黄金三章

1. **一个具体的职场困境**（不是「工作不顺」）
2. **主角的第一次专业判断**（展示他懂这行）
3. **第一次不公**（为后面的还击蓄力）

## 八、自检表

- [ ] 业务流程具体到节点
- [ ] 术语是本行业真实存在的，且不超三个
- [ ] 每次冲突背后有实际利益
- [ ] 上司/对手有自己的指标
- [ ] 打脸后有实际收益
- [ ] 写了无效劳动/背锅等真实痛点
- [ ] 主角的成长体现为选择变多
- [ ] 黄金三章有具体困境 + 专业判断 + 一次不公
