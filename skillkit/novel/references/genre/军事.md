# 军事 · 战争 · 谍战

> 战争小说的读者要的不是战术科普，是**「人在这种处境里怎么办」**。

---

## 一、三种战争题材的差异

| 题材 | 核心快感 | 难点 |
|---|---|---|
| **军事战争** | 战术对抗、指挥博弈 | 战术可信度 |
| **战争年代** | 乱世中的生存与人性 | 时代质感 |
| **谍战** | 身份伪装、心理博弈 | 信息控制 |

---

## 二、军事战争：战术可信度

### 纪律

| 原则 | 说明 |
|---|---|
| **兵力要算** | 一个排多少人、弹药够几天、后勤线多长 |
| **地形要具体** | 距离、坡度、掩体、视线，不是「一片树林」 |
| **通讯要受限** | 无线电受干扰、传令兵要时间、没有卫星 |
| **补给是主线** | 军队打的是补给，不是勇气 |
| **伤亡是真实的** | 不是死了三个人的象征性伤亡 |

**最常犯的错：把战争写成了竞技游戏。** 战争里没有「无损通关」。

### 一定要写清楚的五件事

1. **任务目标是什么**（一句话，能让读者复述）
2. **地形什么样**（读者能想象出画面）
3. **手里有什么**（武器、人数、弹药）
4. **对面是谁**（番号、兵力、指挥官风格）
5. **代价是什么**（时间、人、物资、道德）

### 指挥官

**不要让指挥官是全知的。** 他看到的只是传回来的信息，而信息可能过时或错。

好指挥官的写法：
- 他**做决定**时有取舍
- 他**错过**（这就是代价）
- 他**知道**自己不知道什么

## 三、战争年代：乱世质感

### 五个时代坐标

| 维度 | 表现 |
|---|---|
| **吃饭** | 粮食紧张的具体表现（配给、抢粮、吃树皮） |
| **走路** | 交通、逃难、行程时间 |
| **说话** | 当时的称呼、官话与方言、避讳 |
| **身份** | 成分、户籍、路条、盘查 |
| **钱** | 物价、法币/银元/票子、能不能买 |

**「盘查」是好用的场景**：写证件、写长相、写一个不该问的问题。

### 乱世里的人物

- **不是人人英雄**，多数人只想活下去
- **选择比立场重要**：同一件恶事，有人做有人不做
- **善要有成本**，好人不免费

---

## 四、谍战：信息控制

### 核心：读者知道的 ≠ 角色知道的 ≠ 作者知道的

**三层分离**是谍战全部的乐趣来源。

| 层 | 作用 |
|---|---|
| 读者知道更多 | 产生悬念（他知道主角不知道的事） |
| 角色知道 | 产生紧张（他必须在信息不足下决策） |
| 作者知道 | 产生反转空间（埋线） |

### 谍战必备四件套

1. **身份**（他是谁、掩护身份是什么）
2. **任务**（他被派来做什么，界限在哪）
3. **接头规则**（怎么接头、暗号、谁可能叛变）
4. **退路**（失败怎么办，暴露了怎么办）

**没有退路的谍战主角太被动。** 给他一条退路，他每次选择才都有重量。

### 悬念的三个来源

| 来源 | 做法 |
|---|---|
| **暴露倒计时** | 有人在查他，不知道查谁 |
| **身份冲突** | 掩护身份和真实身份的要求矛盾 |
| **第三方** | 另一股势力也在做同样的事 |

### 常见错误

| 错误 | 症状 | 修法 |
|---|---|---|
| **主角全知** | 什么都知道，从不误判 | 给信息盲区 |
| **暗号万能** | 说了就信 | 让接头有验证程序 |
| **敌方蠢** | 处处露出破绽 | 让对手按自己的逻辑行动 |
| **巧合过多** | 每次都能脱险 | 提前埋好退路，别用巧合 |
| **无代价** | 暴露了也没事 | 一旦暴露，任务就结束 |
| **时代错位** | 用现代话术 | 用当时的表达 |

## 五、战争场景的写法

### 场景骨架

```
战前（具体、安静、有具体的人）
  ↓
交火（短句、感官、混乱、但要具体）
  ↓
转折（有人做了决定，代价出现）
  ↓
战后（安静、代价的具象化、留白）
```

**「战前安静 → 战后安静」是最有效的结构。** 中间尽量短。

### 写战斗的正确顺序

1. 先写**目标**（要拿什么、到几点、到不了怎么办）
2. 再写**阻碍**（地形、敌情、己方状态）
3. 然后写**选择**（主角做了什么决定，牺牲了什么）
4. 最后写**结果**（达成/未达成，新的处境）

**不要按时间顺序流水账写战斗。**

## 六、黄金三章

1. **一个具体任务**（不是战争背景介绍）
2. **一次具体的判断**（展示主角的专业性或人性）
3. **第一次不可逆的选择**（有代价）

## 七、自检表

- [ ] 兵力、弹药、后勤算过
- [ ] 地形具体到距离和视线
- [ ] 通讯受限于当时的条件
- [ ] 指挥官的决策有取舍、有错过
- [ ] 战争年代五坐标落地
- [ ] 谍战有身份/任务/接头/退路四件套
- [ ] 三层信息分离清晰
- [ ] 战斗按「目标→阻碍→选择→结果」写
- [ ] 每次胜利都有代价
