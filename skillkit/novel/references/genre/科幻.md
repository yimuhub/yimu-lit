# 科幻 · 硬科幻 · 末世

> 科幻小说的读者要的不是「酷」，是**「如果真是这样，人会怎么办」**。

---

## 一、科幻的三个层次

| 层次 | 核心 | 读者关心 |
|---|---|---|
| **设定层** | 世界怎么运作 | 这个设定有意思吗 |
| **推演层** | 这个设定推导出什么后果 | 后果自洽吗 |
| **人性层** | 人在这种处境里怎么活 | 我能代入吗 |

**大部分科幻只做到第一层。** 好科幻三层都做。

**检验**：把你的设定推演到底，会不会推出一个你自己没想到的后果？如果不会，说明设定还不够锋利。

---

## 二、硬科幻的纪律

| 原则 | 说明 |
|---|---|
| **能量守恒** | 任何新技术都要有能量来源与效率说明 |
| **时间要算** | 光速、衰变、散热、材料疲劳——时间会杀死很多设定 |
| **尺度要算** | 一个城市能用多少电？多少水？多少原材料？ |
| **成本要算** | 造这个东西要多少钱多少人多少年 |
| **不要有万能技术** | 一个设定解决所有问题，故事就死了 |

**最常见的破绽：主角突然需要一个功能，设定里恰好有。**
**修法**：能力有限制、代价、有失效条件。

---

## 三、末世的三种基底

| 基底 | 核心资源 | 冲突形式 |
|---|---|---|
| **资源崩坏** | 食物、干净水、能源 | 争夺、分配不公 |
| **秩序崩坏** | 安全、信息、秩序 | 新的强权 vs 旧秩序残骸 |
| **认知崩坏** | 现实本身、人的记忆 | 不可信、无法确认 |

**资源崩坏最好写**（具体、可争），**认知崩坏最有意思**（难写但上限高）。

### 末世的六个必答问题

1. **人靠什么活？**（写清楚：吃什么、喝什么、怎么取暖）
2. **第一周怎么过？**（读者要能代入）
3. **谁在维持秩序？**（新政权？互助网络？无政府？）
4. **敌人是谁？**（不只是怪物——是人、是被迫的）
5. **代价是什么？**（每次活下来要付出什么）
6. **重建的可能吗？**（希望在哪，或为什么不希望）

**第 5 条最容易漏。** 没有代价的末世是爽文，不是科幻。

## 四、推演方法

### 设定推演三问

拿到一个设定，逐层问：

```
这个设定的技术原理是什么？
   ↓
基于当前技术，最早什么时候能实现？（不能是「很快」）
   ↓
实现之后，第一个用它的人会做什么？
   ↓
第二个呢？（跟风者 / 垄断者 / 反对者）
   ↓
社会结构因此怎么变？
   ↓
谁因此受损？他们怎么反抗？
   ↓
反抗产生了什么新问题？
```

**到第 7 层，故事自己就出来了。** 这比「编一个反乌托邦」扎实得多。

### 设定分层

| 层 | 内容 | 什么时候揭示 |
|---|---|---|
| **表层** | 这个世界看上去什么样 | 开头 |
| **机制层** | 它怎么运作 | 前 1/3 |
| **代价层** | 用它要付什么 | 中段 |
| **真相层** | 为什么会这样 | 后段（可作反转） |

**不要一次把设定讲完。** 每次揭示一层，同时用它制造一个新问题。

## 五、人物

### 科幻人物的核心矛盾

**人 vs 设定**（被环境挤压）不如 **人 vs 人对同一设定的不同解读**。

例子：同样的 AI 技术
- 一派认为这是解放（AI 接管危险工作）
- 一派认为这是威胁（AI 接管决策权）
- 一派认为这是机会（用它做生意）

**同一个设定，三种立场，冲突自动产生。**

### 末世中的人

**不要写「好人」和「坏人」。** 写：
- **在极端环境下会做什么**（他的底线在哪，什么条件下会破）
- **他守着什么**（不只是生存，还有某种坚持）
- **他放弃了什么**（每个末世主角都该有一个已经失去的东西）

## 六、常见错误

| 错误 | 症状 | 修法 |
|---|---|---|
| **设定即答案** | 「科技能解决问题」 | 加限制与代价 |
| **术语代替推演** | 满篇名词，读者不懂发生了什么 | 每个新设定配一个具体场景 |
| **末世无代价** | 主角怎么活都能活 | 每次行动有消耗 |
| **人性不变** | 末世里大家还讲道理 | 极端环境改变合理行为边界 |
| **科技万能** | 关键时刻掏出新设备 | 提前埋好且限定用途 |
| **世界观说明书** | 开篇三章讲设定 | 设定从冲突里渗出 |

## 七、黄金三章

**科幻的黄金三章必须完成**：
1. 一个具体的异常现象（不是世界观介绍）
2. 主角的**具体反应**（他做了什么，不是他在想什么）
3. 第一次展示这个设定的**限制**（不是它的强大）

**第 3 条最重要。** 先给限制，读者才会相信作者懂这个设定。

---

## 八、自检表

- [ ] 设定能推演出至少一个意外后果
- [ ] 能量/时间/尺度/成本算过
- [ ] 能力有明确限制与失效条件
- [ ] 末世六问都答了
- [ ] 每次生存有消耗
- [ ] 同一设定有多种立场
- [ ] 主角有已经失去的东西
- [ ] 设定分层揭示，不是说明书
- [ ] 黄金三章展示了设定的**限制**
