# 仙侠 · 修真 · 东方玄幻

> 仙侠的读者代入的不是「我会飞」，是**「我想成为那样的人」**。

---

## 一、仙侠的三根柱子

| 柱子 | 内容 | 塌了会怎样 |
|---|---|---|
| **道** | 世界运行的法则 | 设定随便改，读者弃书 |
| **人** | 修行者的欲望与代价 | 没有代入感 |
| **旅途** | 升级路径上的具体经历 | 变成流水账 |

**大部分仙侠只做第三根柱子（升级），前两根是装饰。**

---

## 二、道：法则要自洽且有代价

### 世界运行三问

1. **力量从哪来？**（天地灵气？血脉？香火？规则本身？）
2. **谁来分配？**（宗门？天道自动？还是有人垄断？）
3. **代价是什么？**（寿元？记忆？因果？情绪？）

**第 3 问是仙侠最容易被忽略的。** 没有代价，修行就只是「努力就能赢」，故事立刻变单薄。

### 代价设计（好用的几种）

| 代价 | 效果 | 适合 |
|---|---|---|
| **寿元换力量** | 越强越短命 | 悲剧主角、飞升 |
| **记忆/情感损耗** | 力量会吃掉人的一部分 | 冷酷、孤独 |
| **因果债** | 每次借用要还 | 因果、宿命 |
| **人性磨损** | 修行会磨掉人的软处 | 爽文正、反两面 |
| **天劫/瓶颈** | 突破有具体条件 | 节奏控制 |

**代价必须可见。** 读者要能看见主角因为修行失去了什么。

### 境界体系的三条纪律

1. **每境有明确的门槛**（不是「感悟够了」）
2. **每境改变的是「能做什么」，不是「数字变大」**
3. **每境之间有死亡风险或不可逆**

**境界表的检验**：随便挑两个相邻境界，能不能说出「前一个境界的人为什么做不到后一个境界的事」？说不出，境界就是贴纸。

---

## 三、人：欲望的具体性

### 修行者的三种欲望

| 欲望 | 写法 |
|---|---|
| **活得久** | 怕死 → 会做很多妥协 |
| **活得强** | 要面子 → 会做蠢事 |
| **活得像个人** | 想保有人性 → 会放弃力量 |

**最动人的是第三种。** 「我修到最后才发现我要的是回家」比「我要成仙」有力量得多。

### 配角不要都是资源

常见错误：宗门长老、师姐、师父全是给主角资源/信息/保护的。

**好的配角**：
- 有自己的目标，且和主角冲突
- 有自己隐瞒的事
- 会因为主角而改变选择

**一个能真正威胁主角的配角，比十个工具人有用。**

---

## 四、旅途：升级要具体

### 每次升级要给出的东西

```
这一趟主角获得了：能力 / 物 / 人 / 仇 / 知识
这一趟主角失去了：时间 / 情分 / 寿命 / 底线 / 退路
这一趟主角认识了：具体的人（有名有姓）
```

**三样都要有。** 只给「能力」的段落是流水账。

### 具体化清单

| 抽象 | 具体 |
|---|---|
| 历练 | 在某个具体地方待了多久，遇到了什么事 |
| 提升 | 境界 + 一样能用的东西 + 一个新麻烦 |
| 奇遇 | 天降机缘必有代价：陷阱、追问、追债 |
| 宗门 | 门内几派、谁是靠山、谁要夺他 |
| 资源 | 灵石够买什么、丹药几品、值多少年 |

---

## 五、经典桥段的处理

**桥段本身不是雷区，敷衍才是雷区。** 读者看过的桥段比你以为的多得多。

| 桥段 | 敷衍版 | 写出新意的办法 |
|---|---|---|
| **废柴逆袭** | 打脸众人 | 让他赢的方式出乎意料（不靠力量） |
| **宗门大比** | 比武擂台 | 比的不是武，是别的东西 |
| **师门被灭** | 复仇 | 复仇过程中发现师门有问题 |
| **获得传承** | 戒指老爷爷 | 传承有条件/陷阱/代价 |
| **天劫飞升** | 雷劫成功 | 飞升后发现飞升是个骗局 |
| **前世今生** | 记忆觉醒 | 记忆是假的，或有另一版 |

**通用解法：给读者一个「他预判之外」的信息。**

## 六、爽点的分层

| 层级 | 爽点 | 适合节奏 |
|---|---|---|
| **小爽** | 打脸、扬名、得宝 | 每章 1-2 个 |
| **中爽** | 破境、扬名立万、身份揭露 | 每 5-10 章 |
| **大爽** | 复仇、翻盘、真相大白、护短 | 每卷 1-2 次 |
| **终极爽** | 格局跃迁、规则改写 | 全书一次 |

**小爽维持粘性，大爽维持期待。** 只有小爽会腻，只有大爽会让人弃书。

### 打脸三要素

1. **压制要具体**（不是「他看不起我」，是他说了什么/做了什么）
2. **反转要有路径**（读者能看出来他早有准备）
3. **打脸要有后果**（对方失去了什么/地位变了）

**没有后果的打脸等于没打。**

---

## 七、常见错误

| 错误 | 症状 | 修法 |
|---|---|---|
| **境界无代价** | 变强只有好处 | 加代价并让它可见 |
| **奇遇无陷阱** | 天上掉馅饼 | 每次奇遇附条件或债务 |
| **配角工具化** | 只给资源 | 给对手自己的目标 |
| **天道是作者** | 需要什么来什么 | 法则提前定死，不为剧情改 |
| **升级流水账** | 「三年后他到了金丹」 | 每次升级绑定具体事件 |
| **数字通胀** | 境界越写越大 | 控制层级，细节留白 |
| **现代思维** | 主角讲逻辑、算收益 | 换成修行者的世界观 |

---

## 八、黄金三章

1. **一个具体的处境**（不是「他天资平平」）
2. **一次具体的觉醒/获得**（小奇遇 + 小代价）
3. **一个具体的对手**（有名有姓，压迫感落地）

## 九、自检表

- [ ] 每个境界门槛明确，改变的是「能做什么」
- [ ] 代价可见（读者看见主角失去了什么）
- [ ] 每次升级有 得 / 失 / 人 三样
- [ ] 奇遇有条件或债务
- [ ] 配角有自己的目标
- [ ] 天道不为剧情临时改规则
- [ ] 经典桥段有「预判之外的信息」
- [ ] 打脸有具体后果
