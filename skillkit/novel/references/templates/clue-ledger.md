# 线索账本（10）· 模板（原创）

> 登记所有服务主线的悬念/伏笔。每条都要有"真实答案 + 计划兑现章"，作者掌握真相，不靠临场编。
> 状态机：`planned`（埋了）→ `open`（推进中）→ `paid-off`（回收）。确定性引擎查：闲置>3章 / 超期未兑现。

## 登记表
| ID | 线索 | 首次出现(章) | 初始表象 | 真实含义 | 可推理证据 | 误导方式 | 计划兑现(章) | 状态 |
|---|---|---|---|---|---|---|---|---|
| L1 | | | | | | | | planned |

## 纪律
- 只登记**服务主线**的线索（控制 3-8 条，别贪多）。
- 每条至少 1 处"读者能独立推出来"的证据（公平性）。
- 每章写后：新增/推进的线索在此追加一行（状态 updated）。
- 到"计划兑现章"仍未回收 → 确定性引擎报 critical，必须处理（兑现或改计划）。
