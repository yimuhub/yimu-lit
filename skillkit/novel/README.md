# 一幕·神笔 · ShenBi NovelCraft（技能包）

原创长篇爽文创作方法论，随 novel-bot 分发自包含。

- `SKILL.md`：系统总纲（三大黄金法则 / 七条创作底线 / 全流程 / 质量标准）。
- `references/guides/`：人物、大纲、章节、标题、钩子、对话、扩充、**黄金三章门（golden3）**、**反 AI 腔（anti-slop）**。
- `references/templates/`：故事圣经、线索账本、章节摘要、时间线、修订记录、**质量报告**。
- `references/genre/`：题材 craft 套（推理/言情/恐怖/都市/玄幻 + 通用默认）。

全部文字为原创；方法论吸收业界通用创作思想（故事圣经、伏笔账本、连续性检查、黄金三章、爽点密度等均为通用创作方法），不复制任何第三方技能文本。文字版权归 novel-bot 团队所有。
