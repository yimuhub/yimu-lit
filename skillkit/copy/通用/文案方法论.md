# 文案创作方法论

## K2 钩子库（前 3 秒定生死）
钩子 7 型：
1. 悬念（"最后一步 90% 的人做错了"）
2. 反差（"月入 3 千和月入 3 万的区别，只在这一个习惯"）
3. 痛点直击（"还在为 XX 烦恼？"）
4. 数字（"3 个方法 / 只花了 9.9"）
5. 热点借势（连接当下热话题）
6. 提问（"你有没有发现…"）
7. 直给利益（"看完这条视频帮你省 XXX"）

## K3 正文框架
- AIDA：注意 → 兴趣 → 欲望 → 行动。
- PAS：痛点 → 放大 → 解决方案。
- 口播稿用 [停顿] [重音] 控制节奏；每段对应画面切换。
- 种草笔记：真实感受口吻 + 适量 emoji + 亲测体验 + 转化引导。

## K4 标题
- 5 个标题各不同角度：悬念/数字/痛点/直给/情绪。
- 平台风格：抖音短直快、小红书生活感、公众号可长标题。

## K5 平台适配
- 抖音：节奏快、口语化、CTA 明确。
- 小红书：种草感、亲测体验、标签多。
- 公众号：可长文、段落清晰、引导在看。
- B站：弹幕互动感、专业与趣味并存。
