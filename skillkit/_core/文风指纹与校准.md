# 文风指纹与校准

> 同一部作品里，每章的文风要像「同一个人写的」——不是像同一条流水线灌出来的。

## 一、文风指纹六个维度

| 维度 | 采样方式 | 稳定性 |
|---|---|---|
| **句长分布** | 段落里短句/长句的比例 | 高（一章一章看） |
| **叙事视角与距离** | 贴脸/远观 | 中（可故意调） |
| **形容词偏好** | 高频形容词（不重复使用） | 低（容易混） |
| **动词密度** | 每段动作词 vs 状态词 | 高 |
| **对白风格** | 每角色 1-2 个专属口头禅/语速 | 中 |
| **情绪底色** | 同一种情绪用同一种色调渲染 | 低（最容易漂移） |

**前三个和后两个是「可漂移」的，中间两个（动词密度、对白）是「指纹」**——这两条漂了读者就出戏。

## 二、校准流程（每写完 3 章跑一次）

```
取最近 3 章正文
  ↓
按 6 维各取一段 200 字样本
  ↓
逐维对照 文风基线（第 1 章或文风卡）
  ↓
漂移 > 一档 → 重写最漂的那一段
  ↓
漂移 ≤ 一档 → 记入「允许漂移区间」，不再调
```

**只重写最漂的那一段，不是全章。** 全章改等于换文风，不是校准。

## 三、对白指纹（最值钱的一条）

**每个主要角色建 1-2 条专属语言习惯**，写在文风卡里，写作时强制引用：

| 角色 | 习惯 | 反习惯（他绝不会说的） |
|---|---|---|
| 老兵 | 短、命令式、不用副词 | 「其实/可能/也许」 |
| 学者 | 长句、先否定再肯定 | 直接结论 |
| 孩子 | 重复词、问句结尾 | 形容词 |

**「反习惯」比「习惯」更有力**——读者靠反习惯认出角色。

## 四、情绪色板

同一情绪不要每次用同一套描写。建一本自己的「情绪色板」：

- 紧张 → 冷色（蓝、灰、金属）/ 具体物件（表针、烟灰）/ 短句
- 悲伤 → 暖色褪去（黄、褐）/ 日常细节（一碗凉了的汤）/ 长句
- 愤怒 → 暖色过曝（红、橙）/ 具体动作（捏、砸）/ 动词密集

**每次情绪场景先选色板，再写。** 随机选会漂移，选完写稳定。

## 五、Pre-flight

- [ ] 6 维采样过
- [ ] 最漂的那段已重写
- [ ] 对白指纹在文风卡里且每章都用
- [ ] 情绪场景选色板后写
- [ ] 相邻两章句长分布不雷同
