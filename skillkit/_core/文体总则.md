# 文体总则

> 选文体之前先回答三个问题。选错文体再努力也没用。

## 三问

| 问 | 答案 |
|---|---|
| 核心是要「事件」还是「情绪」？ | 事件 → 小说/剧本；情绪 → 散文/诗词 |
| 有没有具体的、可展开的情节？ | 有 → 叙事文体（小说/剧本）；无 → 非叙事文体（散文/诗词） |
| 读者期待的是「跟着走」还是「停下来」？ | 跟着走 → 连续叙事；停下来 → 单点抒情 |

## 四文体速查

| 文体 | 核心承诺 | 典型长度 | 节奏 |
|---|---|---|---|
| 小说 | 跟着主角走一段路 | 2万字以上 | 可长可短，钩子驱动 |
| 剧本 | 一个具体场景，说清谁要什么、被什么挡 | 60-120分钟电影 | 三幕/序列 |
| 散文 | 一件事在我身上的样子 | 1000-8000字 | 单点放大，留白多 |
| 诗词 | 一个意象的瞬间 | 20-120字 | 一息之间 |

## 错体文的最常见形式

| 错 | 症状 | 修 |
|---|---|---|
| 拿散文体写小说 | 大量心理描写、无具体事件 | 换成场景+动作 |
| 拿小说体写剧本 | 旁白解释、场景不落地 | 改成动作行+台词 |
| 拿议论文写散文 | 结论先行、论证式展开 | 换成场景进入 |
| 拿叙事写诗词 | 讲了一个完整故事 | 压成单个意象瞬间 |
