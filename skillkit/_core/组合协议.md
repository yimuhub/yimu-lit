# 文体组合协议

> 当一篇作品需要跨文体（如：小说里插诗词、剧本里念白文、散文里串诗）时，用什么规则。

## 一、三类混排

| 类 | 说明 | 典型 |
|---|---|---|
| **嵌** | 小段落嵌入大文体 | 小说里人物念一首诗 |
| **串** | 多个小文体串成一体 | 散文里多个诗节 |
| **对位** | 两个文体同时叙述同一件事 | 剧本台词 + 旁白散文 |

**「嵌」最安全，「对位」最难写但最有力。**

## 二、切换点三规则

1. **切换前停一拍**（空行、破折号、静场），让读者准备好切换
2. **切换理由要在地**（人物为什么念这首诗，为什么切到旁白）
3. **切换后先立住再进内容**（切到诗先给一个具体的视觉锚，不是直接进韵脚）

**没有一拍停顿的切换 = 硬切。** 硬切让读者出戏。

## 三、诗词嵌入规范

- 嵌诗不超过 3 行（小说/剧本里）
- 嵌诗要有人物动机（不是作者抒情）
- 嵌诗后给一拍（动作/反应），不要马上接分析

## 四、散文式旁白（剧本/小说）

- 旁白是留白的，不是解释的
- 一段旁白 ≤ 3 句
- 旁白不覆盖关键动作（让动作先发生，旁白再补一拍）
- 旁白用第一人称，不用「他/她」（拉距离）

## 五、对位结构（高级）

两个文体同叙一件事时：

| 文体 A | 文体 B | 效果 |
|---|---|---|
| 台词（明） | 旁白（潜） | 反讽 |
| 动作（快） | 散文（慢） | 时间拉伸 |
| 诗词（凝） | 小说（散） | 张弛 |

**对位只在关键场景用，不是每场都用。** 每场都对位 = 没对位。

## 六、Pre-flight

- [ ] 切换前有停顿
- [ ] 切换理由成立
- [ ] 嵌诗 ≤ 3 行 + 有人物动机
- [ ] 旁白 ≤ 3 句 + 不覆盖关键动作
- [ ] 对位只在关键场景用
- [ ] 相邻两次同类型切换之间 ≥ 3 场（或 3 段）
