# 人物塑造指南（chinese-novelist v3.0）

## 核心原则：人物不是标签集合
情节必须由**人物的欲望、恐惧、缺陷、选择与代价**推动。不要让任何人（含主角）突然变蠢、突然变强、突然变心来服务反转。配角与反派要有自己的信息源、目标与决定，甚至让主角的计划失败——他们不只是给主角送经验、送线索、送胜利。

## 每个主要角色至少记录 10 项（档案必须可指导写作）
1. 当前身份、姓名、年龄区间、经历与社会位置。
2. 表层目标 与 隐藏目标。
3. 最害怕失去的东西。
4. 性格矛盾（例：慷慨但控制欲强、聪明却羞于求助）——**矛盾必须在行动中表现**，不能只写在档案里。
5. 能力、资源、盲点与限制。
6. 过去形成的伤口、信念与行为逻辑。
7. 与其他主要角色的关系、债务、误解、权力差。
8. 说话方式：句长、直接或迂回、会不会说谎、压力下怎么变。**别给每人一句口头禅后反复念**。
9. 角色弧光：开始时相信什么 → 经历哪些证据与损失 → 最后如何改变（或拒绝改变）。
10. 不能随便做的事：哪些行为若发生必须有明确铺垫。

## 表达必须有差异
同一场景里的人物不能共用一种聪明、一种幽默、一种反应速度。差异来源：身份、教育、年龄、地位、情绪、利益。
- 有人直接有人绕弯，有人沉默有人以问题代替回答；
- 有人压力越大越讲礼数，有人压力越大越口不择言；
- 有人用事实压人，有人用关系施压，有人冷处理，有人先示弱。
同一人对不同对象可改变说话方式，但**变化要有社会原因**。

## 情绪通过行为表现，不替读者下结论
让读者看见人物如何承受情绪：她把要递出的信又压进袖口；他先问伤口再问是谁动的手；她明明听懂了却故意把称呼叫错。避免"她心中五味杂陈/眼神复杂/意味深长一笑"后不接具体反应。必要时一句精准心理判断胜三段装饰动作——目标是选最有效的方式，而非"所有情绪都展示"的死规则。

## 主角要改变策略，不只是升职位/数值
成长须有可观察阶段：最初如何处理压力 → 何时失效 → 失败让她看见什么 → 尝试什么新方式 → 新方式牺牲了什么 → 是否形成更成熟的判断。若每次都用同一种吐槽/威胁/临场编造化解，只换地点仍是重复剧情。必要时让旧策略失灵、让主角承认误判、向不喜欢的人求助。

## 反派/强势角色
反派要有可理解的动机、真实资源与理性策略，并会随主角行动更新打法；不能只靠"怕一个角色"说明其权势——权力要落在能调动谁、封锁什么、罚谁、向谁交代上。
