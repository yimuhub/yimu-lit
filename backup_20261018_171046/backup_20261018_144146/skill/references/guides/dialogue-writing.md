# 对话写作规范（v3.0）

## 对话至少承担一种功能（重要的常兼两三种）
获取信息 / 隐瞒意图 / 争夺主动权 / 测试关系 / 回避痛点 / 拉近距离 / 制造误解 / 推动行动。重要对话通常同时承担两种以上功能。

## 台词之下的第二层意思
不要让所有人物都把内心活动说得清清楚楚。真实人物会说谎、停顿、答非所问、改话题、故意理解错、说一半又咽回去。**沉默必须改变场面或关系**，不是单纯营造气氛。

## 不同人不同说话方式
- 有人说话直接，有人绕弯；有人沉默，有人以问题代替回答。
- 有人压力越大越讲礼数，有人压力越大越口不择言。
- 有人用事实压人，有人用关系施压，有人冷处理，有人先示弱。
- 同一人在不同对象面前可改变说话方式，但这种变化要有社会原因。
**不要为每个角色强行设一个口头禅。** 个性来自思路、观察重点、隐瞒方式、行动习惯，而不只是词汇不同。

## 智斗的对话要可复盘
一段可信的反击/谈判至少体现：主角依据哪些已出现的信息判断；他如何获取/验证/保护证据；对手为何入局或为何没识破；对手的反制手段；主角付出的资源/信誉/关系/时间成本；结果如何改变下一轮博弈。
主角可诈唬、冒险、碰运气，但不能连续靠"随口编个秘密对方刚好心虚"通关。偶然只打开一扇门，之后必须由人物的调查、判断、行动承担结果。

## 情绪不靠对话喊出来
"他很生气"不如"他把要递出去的信又压进袖口"。对话要贴着人物的身份、情绪与利益；情绪用行为与停顿表现，必要时一句精准心理判断更有力。
