# 章节写作 · 规范与去机械化（原创）

## 写前自检（每章动笔前 30 秒过一遍）
1. 本章要推进的冲突/事件是什么？（一句）
2. 承接上一章结尾的什么状态？（不复述已发生）
3. 本章末钩子是什么？
4. 连续性：人物知情范围/时间/伤势/物品/规则是否与前文一致？
5. 本章爽点/情绪点至少 1 个（节奏题材 ≥2）。

## 章节内部节奏（黄金结构）
- 开局 10%：从"上一章留下的那个钩子"直接进，别重新铺垫。
- 中段：一段一段推进，每 2-3 段一个小的"推进"（信息/冲突/情绪）。
- 末段 10%：章末钩子（悬念/反转/新威胁）。

## 去机械化清单（写时照打勾，写后 Editor 复查）
- [ ] 不用"突然""瞬间""空气凝固"起头（假悬念）。
- [ ] 不排比轰炸（三连句以上的情绪排比要砍到 1-2）。
- [ ] 心理不直陈（"他很愤怒"→写手抖/砸东西）。
- [ ] 场景转换给锚点（时间/地点/感官），别"与此同时"硬跳。
- [ ] 对话夹动作/反应，别"乒乓球式"纯对白。
- [ ] 同一信息不重复喂（前后章节说了 3 遍同一句背景）。
- [ ] 字数不足用"加冲突/加代价/加细节"扩，不用废话注水（见 content-expansion）。
- [ ] 每章至少一个新信息或新格局。

## 章末钩子（必留，三选一）
悬念（"门后站着的人让陈默血色尽褪"）/ 反转（前文判断被打脸）/ 新威胁（更大麻烦冒头）。
