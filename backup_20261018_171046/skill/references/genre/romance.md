# 言情（原创）

## 爽点 = 情绪 payoff（甜/虐/嗑）
- 甜文：误会解除、双向奔赴、高光宠溺。虐文：牺牲、错过、身份差。嗑点密度 = 每章至少 1 个情绪峰。

## 关系节拍（Beat）
相识/相冲 → 破冰 → 靠近（小事件推动）→ 障碍（身份/误解/外力）→ 抉择（付出代价）→ 兑现（HE/BE 由承诺定）。
每两章推一个节拍；卡点设在"抉择"前。

## 人物声音（言情尤其吃）
- 男女主声音必须对立/互补且"遮名可认"；关键场景用潜台词（嘴上说的和心里想的错位=嗑点）。

## 黄金三章专属
- 第 1 章：强关系起点（重逢/错位/被迫同行），300 字出"张力"。
- 第 2 章：第一个小嗑点 + 立"他们之间有什么不同"。
- 第 3 章：一次情绪兑现（甜或虐），抛出主线情感悬念（他俩能成吗/为什么错过）。

## 常见坑
- 全员同口；障碍靠误会且迟迟不放（读者弃）；情绪平（没有峰谷）；HE/BE 没按开书承诺兑现。
