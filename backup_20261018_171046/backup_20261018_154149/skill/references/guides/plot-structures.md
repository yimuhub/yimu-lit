# 情节结构 · 因果链（原创）

## 因果，不是罗列
章节/事件之间必须"因为 A 所以 B"。写完大纲，逐章自问：**删掉上一章，这章还成立吗？** 成立→上一章是空转，删。

## 幕的责任（三幕最稳）
- **第一幕（起）**：常态被打破，主角被推入问题；末了做出"不可逆选择"（进入第二幕的门）。
- **第二幕（承转）**：尝试—失败—升级；中点反转翻盘预期；末了"至暗时刻"。
- **第三幕（合）**：用弧光获得的新认知解决；兑现开书承诺；收伏笔。

## 爽文结构（打脸·升级流）
- 压抑（被轻视/危机）→ 亮牌/反击 → 打脸（旁观者震惊）→ 收获/升级 → 更大危机（升级后新威胁）。
- 每一轮"压抑-打脸"就是一个爽点循环，节奏题材可高频（见 `genre/urban.md`、`genre/xuanhuan.md`）。

## 智斗结构（推理/权谋）
- 双方都有目标与信息差；每次博弈改变"谁掌握什么信息"。
- 公平游戏原则：给读者的线索 ≥ 给角色的（推理类），反转要靠"早已给过的线索"而非降智。

## 钩子与卡点
见 `hook-techniques.md`。每章末必钩；关键章（常为 6-8 章）设"卡点"制造付费/追读动机。
