# 恐怖 / 惊悚（原创）

## 恐怖来自"具体 + 未知 + 代价"，不来自形容词
- 写**看得见的细节**（气味/声音/触感）而非"很可怕"。
- 未知 > 已知：留一个"读者和角色一起不懂"的核心恐惧，比明明白白更怕。
- 恐惧要有**代价**（怕了会失去什么/付出什么），不然只是吓人不是剧情。

## 结构与节奏
- 慢烧（氛围铺垫）→ 惊点（具体吓人一刻，别滥用）→ 规则揭示一角 → 更大恐惧。
- 惊点要"少而重"，全章 1-2 个，别密集到脱敏。

## 黄金三章专属
- 第 1 章：日常裂开一道缝（不对劲的细节），300 字出"寒意"。
- 第 2 章：第二次异常，读者意识到"这不是错觉"。
- 第 3 章：揭示规则一角 + 抛出总恐惧（这到底是什么/它要什么）。

## 常见坑
- 形容词堆"恐怖/阴森"；惊点太密脱敏；规则前后乱改（违反硬规则=崩）；恐怖没代价（吓人但不推剧情）。
