# 情节结构方法（v3.0）

## 一、用因果链推进，不用"然后"拼接事件
每个重要剧情节点写成因果链：
**人物意图 → 采取行动 → 遇到具体阻力 → 作出新选择 → 产生代价 → 改变下一步局势。**

自检：把大纲里的"然后"换成"因此"或"但是"再读一遍。若事件只是顺序相接、人物选择没有造成后果，剧情就会像任务清单。

## 二、每一幕/卷的职责（按长度灵活，不必硬套单一模板）
- **起势**：让读者认识主角的日常秩序、缺口与压力，并发生足以打破旧生活的事件。
- **投入**：主角主动采取策略，获阶段性胜利，同时制造新的麻烦。
- **升级**：对手针对主角策略调整，旧方法有效性下降；主角须换方法或付更大代价。
- **低谷**：因自身错误、局势变化或对手有效行动而失去重要东西；不能只是"所有人突然误会她"。
- **终局**：主角利用此前建立的能力、关系、线索作出最终选择；结局回答故事最核心的问题。
- **余韵**：展示选择的真实后果。续集钩子可留，但不取代本部应有的结局。

## 三、每章大纲卡（开写前简要确定）
- 章节作用：对主线/人物/关系/世界认知做了什么不可替代的推进？
- 主视角人物眼下想要什么？本章阻力来自谁、什么制度/资源限制/主角自身缺点？
- 主角采取什么具体策略？对方为什么没有轻易让步？
- 发生什么变化？变化有前文依据吗？
- 主角付出什么代价 / 获得什么有条件的收益？
- 本章结束时，关系/风险/资源/信息/目标至少一项改变了什么？
- 读者还想知道什么？这个问题在何处推进或兑现？

不必每章都惊天反转，但**每章必须让故事状态发生有意义的变化**。

## 四、节奏不是硬塞波峰（按场景任务调速度）
- 动作/危机/追逐/争辩：句子变短，少解释，让动作与选择带速度。
- 推理/策略/交易：给足信息让读者理解双方依据与风险。
- 关系/悲伤/恐惧/羞耻：允许停顿、回避、误答、小动作，不急着总结情绪。
- 过渡场景：只留能改变状态或呈现新细节的内容，跳过机械日常。
别机械执行"每 500 字必须冲突"。真正要查的是：读者是否长期没得到新信息、没感到变化、也不知道场景为何存在。

## 五、按故事类型调整（非一套模板套所有）
- **穿越/系统/升级流**：先定系统为何存在、服务谁、能做什么、不能做什么、使用成本；奖励有稳定规则；系统提供信息/工具，不替主角完成关键调查、决策与情感成长；能力有误差与盲区，避免悬疑一出现就被系统扫出。
- **悬疑/宫斗/权谋/智斗**：重要信息有获取路径（记录谁能接触）；反派有自己的计划并随主角更新；证据链分层（可疑≠铁证）；误导公平；每次反击考虑失败路径；权力落在实际资源上。
- **言情/关系线**：感情靠具体互动与选择积累；关系升级有阶段（试探/共同经历/信任受损/修复）；强势者的控制欲要展示其对另一个人的真实影响；冲突依赖真实目标差异，不靠反复误会拖篇幅。
- **历史/架空古风**：对官职/称呼/位份/礼仪/钱粮/交通/信息传播建统一词典；架空朝早期定核心制度，突破规则要付代价。
- **喜剧/吐槽**：笑点来自人格、认知差、处境荒谬、语言错位；吐槽有强弱节奏（沉重时允许不搞笑）；笑点之后仍要改变局势或关系。
