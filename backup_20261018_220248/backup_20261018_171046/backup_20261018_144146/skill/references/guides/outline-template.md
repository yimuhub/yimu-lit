# 大纲模板（v3.0 · 先设计值得读的故事，再分章）

> 写正文前先回答这些，可内部推演、不必全抛给用户。章节数 = 配置的 `chapters`。

## 一、故事引擎（一句话）
一个什么样的人，最想得到什么，在什么限制下，被迫做什么选择；如果失败会失去什么。
（不合格＝只有标签，如"女孩穿越靠系统升级"；合格＝独特困境＋主动选择＋代价。）

## 二、故事承诺（读者为何点、为何留、收获什么）
- **题材承诺**：<宫斗智斗/感情拉扯/推理破案/成长逆袭/社会观察/冒险…>
- **独特卖点**：与同题材相比最鲜明的一处差异（不能只写"反转多、很爽"）。
- **情绪承诺**：读者主要追求 快感/心疼/紧张/甜蜜/愤怒/敬佩/恐惧/余味。
- **兑现方式**：这些体验由哪些人物关系、选择、具体事件产生，而非作者直接说"很爽"。
- **标题/简介/开篇同一故事**：标题招来的读者，开篇要看见标题承诺的体验；转弯须有铺垫并保留原吸引力。

## 三、核心冲突（须能持续制造选择）
外部目标 / 内部需求 / 错误信念 / 致命弱点 / 底线 / 独特能力及边界 / 不可逆代价。每个大转折都迫使主角作艰难选择，而非事件发生后被动接收结果。
