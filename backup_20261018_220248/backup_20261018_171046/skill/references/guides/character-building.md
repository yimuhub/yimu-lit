# 人物塑造（原创）

## 一个能用的人物 = 欲 + 缺 + 价

- **欲望（Want）**：ta 嘴上/表面要什么（外部目标）。
- **缺陷（Need/Gap）**：ta 真正欠缺的内在东西（与主题咬合）。
- **代价（Cost）**：为了要，ta 准备付什么；付了会失去什么。
三者张力越大，人物越立得住。主角必须三样齐全；关键配角至少两样。

## 十项人物档案（逐条填，缺一条就补）

1. 姓名 / 称谓（不同人对 ta 的叫法不同，别乱串）
2. 年龄 / 时代锚点
3. 社会身份 / 职业 / 资源
4. 性格内核（1-2 句，能预测 ta 在压力下会怎么做）
5. 想要（Want）/ 欠缺（Need）/ 代价（Cost）
6. 说话方式（口头禅、句式长短、爱不爱用修辞）——**每个主要角色声音要能"摘掉名字也认得出"**
7. 与主角关系 / 立场（帮·阻·利用·情感）
8. 秘密 / 知情范围（ta 此刻**知道**什么、**不知道**什么）
9. 弧光：开局状态 → 转折 → 终局状态（至少变一处）
10. 标志性细节（物件/动作/习惯，用于连续性核对）

## 人物辨识度（排行级硬要求）

- 主要角色 ≥3 个时，**声音必须互不相同**：给每个角色设 1 条"绝对不用"的语言习惯（如反派不解释、老手不煽情）。
- 关系要能推动冲突，不是背景板。
- 死人不复生；复活/回归必须有前文伏笔支撑。
- 出场即给"功能"：每章在场的人，要么推进冲突，要么推进信息，要么推情绪，否则删。

## 常见坑

- 主角全知全强无代价（无张力）；
- 反派为坏而坏（缺动机/缺陷）；
- 配角工具人（随时降智配合主角）；
- 人物弧光没落点（开局终局一样）。
