# 书名/标题 · 技巧（原创）

## 书名要对齐"开书承诺"
书名要让人在点开前就知道：**什么题材 + 给什么爽感 + 主角是谁**。三要素缺一个就改。

## 起名套路（取 2-3 个候选）
- **冲突前置型**：把最抓人的冲突/反转写进书名（"退休刑警竟是真凶"）。
- **身份反差型**：落差越大越爽（"豪门弃子 / 满级大佬重生 / 赘婿"）。
- **悬念钩子型**：留一个读者非要点开的问句（"我死后，他们跪着道歉"）。
- **数字/量词型**（节奏题材）：增强期待（"十天内…"）。

## 章节标题
- 短（4-8 字），带钩或带反差，能暗示本章冲突但不剧透结局。
- 全文章节标题风格统一；前 3 章标题尤其要"立"（黄金三章的一部分）。

## 反例
- 大而无当（"命运""岁月"）、纯抒情无信息、与承诺无关的炫辞——一律不用。
