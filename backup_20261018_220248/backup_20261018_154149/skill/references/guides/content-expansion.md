# 扩充 · 字数不足时怎么加（不注水）（原创）

## 必要性测试
字数不够时，先问：**这一章有没有"必须发生却没发生"的冲突/代价/细节？** 有→加它；没有→别硬撑，说明该章规划偏松，改规划。

## 有效扩充方向（由强到弱）
1. **加对抗/阻力**：让事情没那么顺（多方介入、反将一军）。
2. **加代价/后果**：赢了也失去什么，立"胜利很贵"。
3. **加第二场景线**：并行的另一条线制造悬念（切视角，要切得有理由）。
4. **加信息密度**：把"发生了什么"写成"读者能看见的过程"（展示而非讲述）。
5. **加情绪/关系**：把冲突落到具体人物关系上（谁的什么被伤到）。

## 禁止注水
- 同一段背景讲三遍；无信息量的寒暄；排比抒情堆字；把一句话拆三段。
- 这些会被 Editor 与确定性引擎（爽点密度）一起打回。

## 扩充后必复查
- 新增内容不破坏因果链（"删掉它还成立"则多余）；
- 人物不降智配合；
- 新增伏笔登记进 `clue-ledger`。
