# 大纲 · 模板（原创）

大纲 = 故事引擎 + 承诺 + 结构 + 章节规划表。逐段填写。

## 1) 故事引擎（一句话）
_<主角> + <要什么> + <被什么挡住> + <代价>。例：退休刑警要洗刷栽赃，却发现自己才是真凶。_

## 2) 开书承诺（读者点开在期待什么）
- 题材卖点：__
- 情绪承诺：爽/燃/虐/暖/恐（主副）
- 兑现方式：读者会在第几章/哪个节点得到什么

## 3) 主题与主线
- 主题（一句话）：__
- 总主线 + 结局方向（结局必须兑现承诺）：__

## 4) 结构（选一种，标注每幕责任）
- 三幕 / 五幕 / 起承转合 / 网文"打脸升级"节奏，任选。
- 每幕：目标 · 冲突 · 转折 · 幕末钩子。
