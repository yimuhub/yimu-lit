# 标题创作指南（v3.0）

## 标题、简介、开篇必须讲同一个故事
标题招来的读者，开篇要看见标题承诺的核心体验。标题强调"吐槽宫女升职"，开篇就尽快展示宫女处境、吐槽人格与升职困局，不要很快转成毫无铺垫的别的救世故事。题材可升级转弯，但须逐步铺垫并保留原故事的主要吸引力。

## 拟标题原则
- **优先具体、易懂、有冲突或悬念**；避免只有空泛词堆叠。
- 可内部生成多个候选，比较**辨识度、题材信号、记忆度**，不要只选最夸张的。
- 标题要能概括：谁 / 什么困境 / 什么赌注（"谁—想要什么—代价"的信号）。
- 与题材定位一致：悬疑要有钩子感，轻喜要有错位感，古言要有处境感。

## 输出
每个候选标题附：
- **技巧**：用了哪种（反差/设问/点名人物处境/悬念前置/双关/数字/意象）。
- **理由**：为何辨识度与记忆度更高、如何对齐开篇体验。

> 生成 3-5 个，供作者/读者选择或自定义；选定后标题、简介、开篇三处要保持同一承诺。
